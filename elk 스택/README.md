ELK 스택
=============

1\. 정의
--------
```
데이터 수집, 저장, 분석 및 시각화를 위해 함께 쓰이는 3가지 오픈소스 소프트웨어(Elasticsearch, Logstash, Kibana)의 조합입니다. 
주로 대용량 로그 관리, 실시간 데이터 분석, 시스템 모니터링 및 검색 엔진 구축에 활용됩니다.
```

2\. 핵심 구성 요소
--------
```
구성 요소           역할                                                          비유
Logstash        "다양한 출처에서 데이터를 수집, 변환, 정제하여 전달하는 파이프라인"     원재료를 가공하는 공장 파이프라인
Elasticsearch   정제된 데이터를 저장하고 고속으로 검색·분석하는 분산 검색 엔진         엄청나게 빠른 스마트 창고/DB
Kibana          "Elasticsearch에 저장된 데이터를 **시각화(차트, 대시보드)**하는 UI"  데이터를 한눈에 보는 모니터링 화면
```

3\. 주요 동작 흐름 (Data Pipeline)
--------
```
1) Logstash: 서버 로그, 애플리케이션 데이터, DB 변경 사항 등을 수집하고 필터링(가공)합니다.
2) Elasticsearch: Logstash가 보낸 데이터를 JSON 형태로 인덱싱(색인)하여 저장합니다.
3) Kibana: Elasticsearch에 저장된 데이터를 쿼리하여 실시간 대시보드, 그래프, 지도 등으로 시각화합니다.
```

4\. 목표
--------
```
장애 발생 시 키워드 하나로 전체 트랜잭션을 추적(Tracing)할 수 있는 환경을 구축 한다.
```
