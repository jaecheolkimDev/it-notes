Elasticsearch 공부 노트
======================
검색, 데이터 분석에 최적화된 데이터베이스

1\. 정보 검색(Information Retrieval, IR)
--------------
Elasticsearch의 심장에는 Apache Lucene(루씬)이라는 오픈소스 검색 라이브러리가 내장되어 있습니다. 이 루씬이 바로 정보 검색(IR) 학문의 결정체입니다.
```
역색인 (Inverted Index): 전통적인 데이터베이스가 "1번 문서에 무슨 단어가 있지?"를 찾는다면, 루씬은 책 뒷면의 색인처럼 "이 단어는 몇 번 몇 번 
                        문서에 있지?"를 미리 구조화해 둡니다. 책을 처음부터 다 읽지 않고 뒤쪽의 '찾아보기'를 보고 바로 페이지를 펼치는 원리입니다.
텍스트 분석 및 자연어 처리 (NLP): 문장에서 조사나 어미를 잘라내고(Stemming/Lemmatization), 의미 없는 단어(Stopwords)를 걸러내며, 단어를 
                              최소 단위(Token)로 쪼개는 기술입니다.
랭킹 및 유사도 알고리즘 (Relevance Scoring): 검색어와 가장 관련이 깊은 문서를 먼저 보여주는 알고리즘입니다. 과거에는 TF-IDF 알고리즘이 쓰였고, 
                                         현재 Elasticsearch는 이를 발전시킨 BM25 알고리즘을 기본으로 사용하여 검색 결과의 순위를 매깁니다.
```

2\. 분산 시스템 및 가용성 (Distributed Systems) ── 대규모 확장의 뿌리
--------------
루씬은 훌륭한 검색 엔진이지만, 컴퓨터 한 대 안에서만 돌아가는 라이브러리였습니다. 데이터가 기하급수적으로 늘어나면 한 대로는 버틸 수 없죠.
이 문제를 해결하기 위해 컴퓨터공학의 분산 컴퓨팅 이론을 결합한 것이 바로 Elasticsearch입니다.
```
샤딩 (Sharding)과 복제 (Replication): 데이터를 여러 조각(Shard)으로 쪼개어 여러 컴퓨터(Node)에 나누어 저장하고, 하나의 컴퓨터가 고장 나도 
                                    서비스가 멈추지 않도록 복제본(Replica)을 유지하는 기술입니다.
합의 알고리즘 (Consensus Algorithm): 여러 대의 컴퓨터가 네트워크로 연결되어 있을 때, "누가 대장(Master) 노드가 될 것인가?", "현재 시스템 상태는 
                                   정상인가?"를 조율하는 분산 시스템의 핵심 프로토콜(예: 과거의 Zen Discovery, 현재의 Raft 기반 알고리즘)이 
                                   녹아있습니다.
```

3\. 데이터베이스 (Database Theory) ── 저장소로서의 뿌리
--------------
Elasticsearch는 검색 엔진이지만, 현대에는 NoSQL 데이터베이스의 한 종류(Document-store)로도 분류됩니다.
```
스키마리스 (Schemaless / Dynamic Mapping): 관계형 데이터베이스(RDB)처럼 테이블 구조를 엄격하게 미리 정의하지 않고, JSON 형태의 구조화된 문서를 
                                         그대로 던져 넣으면 시스템이 알아서 구조를 파악하고 저장합니다.
비정규화 (Denormalization): RDB처럼 테이블을 쪼개고 JOIN을 하는 것이 아니라, 검색 속도를 극대화하기 위해 하나의 문서 안에 필요한 정보를 최대한 다 
                           집어넣는 방식을 취합니다.
```

4\. 주요 활용 사례
--------------
```
1) **데이터 수집 및 분석**
    Elasticsearch는 대규모 데이터(ex. 로그 등)를 수집 및 분석하는 데 최적화되어 있다. 주로 Elasticsearch(데이터 저장), Logstash(데이터 수집 및 
    가공), Kibana(데이터 시각화)를 같이 활용해 데이터를 수집 및 분석한다.
2) **검색 최적화**
    Elasticsearch는 데이터가 많더라도 뛰어난 검색 속도를 가지고 있고, 오타나 동의어를 고려해서 유연하게 검색할 수 있는 기능을 가지고 있다. 쿠팡이나 
    배달의민족의 검색 기능도 전부 Elasticsearch를 활용해 구현되어있다. (네이버나 구글은 자체적인 검색 엔진을 구축해서 사용한다.)
```
