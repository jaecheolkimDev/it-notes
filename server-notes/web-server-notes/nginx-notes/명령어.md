명령어

1\. 
-----------------------
```
1) nginx -V     : Nginx의 버전과 함께 설치된 거의 모든 경로(설정 폴더, 로그 폴더 등)를 한눈에 보여줍니다.
    - prefix(설치 기본 경로)
    - conf(설정 파일 경로)
```

2\. 설정 파일 적용 후처리
-----------
```
1) Nginx 설정 파일 중 문법 에러가 있는 지 체크
    $ sudo nginx -t 

2) Nginx의 설정 파일이 바뀐 경우 아래 명령어를 입력해줘야 설정 파일이 반영된다.
    $ sudo nginx -s reload
```
