OAuth(Open Authorization)
=================
사용자의 비밀번호를 직접 노출하지 않고도, 한 애플리케이션이 다른 애플리케이션의 보호된 리소스(데이터)에 접근할 수 있도록 권한을 위임하는 
개방형 표준 프로토콜입니다. 
이는 사용자가 로그인 시 'Google로 로그인'이나 '카카오로 로그인'처럼 자신의 계정 정보를 다른 서비스에 제공하지 않고도, 
대신 '접근 토큰(Access Token)'을 받아 안전하게 데이터를 주고받는 방식으로 작동하며, 
권한을 세부적으로 제어하고 언제든 해지할 수 있는 장점이 있습니다.


0\. 용어
---------------
```
- 리소스 소유자 (Resource Owner)   : 사용자 본인.
- 클라이언트 (Client)             : 사용자 정보에 접근하려는 제3자 애플리케이션 (예: 영화 추천 앱).
- 인가 서버 (Authorization Server): 사용자의 신원을 확인하고 클라이언트에게 접근 권한을 부여하는 서버.
- 리소스 서버 (Resource Server)   : 사용자의 데이터(리소스)를 저장하고 있는 서버 (예: 구글 드라이브). 
```


1\. Spring Security OAuth2 기본 경로(Default Endpoint)
---------------
@EnableAuthorizationServer 어노테이션을 붙이는 순간, 라이브러리는 자동으로 몇 가지 표준 경로를 생성하고 활성화합니다.
개발자가 따로 컨트롤러를 만들지 않아도, 라이브러리 내부의 TokenEndpoint라는 클래스가 이 경로를 이미 점유하고 대기 중인 상태입니다.
```
/oauth/token: 토큰을 발급받는 주소 (지금 우리가 보고 있는 곳)

/oauth/authorize: 사용자 승인을 받는 주소

/oauth/check_token: 토큰이 유효한지 확인하는 주소

/oauth/confirm_access: 접근 승인 여부를 묻는 주소

```
