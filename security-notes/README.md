보안
=================
```
- 인증 : 사용자의 신원을 입증하는 과정. 누구인지 확인하는 과정. Authentication
- 인가 : 사이트의 특정 부분에 접근할 수 있는지에 권한을 확인하는 작업. Authorization
- 암호화, 보안, HTTPS, Session, Cookie …


```

1\. CSRF(Cross Site Request Forgery)
---------------
```
사이트간 위조 요청으로 사용자가 자신의 의지와 상관없이 해커가 의도한 대로 수정, 등록, 삭제 등의 행위를 웹사이트 요청하게 하는 공격을 말합니다.
```

2\. CORS(Cross-Origin Resource Sharing)
---------------
브라우저가 가진 '출입 보안 통제 시스템'입니다.
```
보안상 다른 도메인(출처)의 리소스 접근을 제한하는 동일 출처 정책(SOP)를 완화하여, 
브라우저가 특정 교차 출처 요청을 허용하도록 허가해 주는 HTTP 기반 보안 메커니즘

동작 방식   : 웹 애플리케이션(Origin A)이 다른 서버(Origin B)로 요청을 보낼 때, 
    브라우저는 안전한 요청인지 확인하기 위해 미리 OPTIONS 메서드로 preflight(사전) 요청을 보냅니다.
```

3\. XSS(Cross-Site Scripting, 교차 사이트 스크립팅)
---------------
```
1)개념    : 웹 취약점 중 하나로, 공격자가 웹 사이트에 악성 스크립트를 삽입하여 이를 열람하는 일반 사용자의 브라우저에서
           해당 스크립트가 실행되게 만드는 공격입니다.

2) 공격 원리    : 기본적으로 브라우저는 웹 서버가 보내주는 코드를 "믿을 만한 코드"라고 생각하고 그대로 실행합니다.
                공격자는 이 점을 악용하여 사용자의 쿠키(세션 토큰)를 탈취하거나, 가짜 로그인 창을 띄워 비밀번호를 훔치는 스크립트를 심어둡니다.
             
3) 주요 유형 (3가지)
유형                          설명                                          공격 방식
Stored XSS (저장형)        악성 스크립트가 서버 DB에 저장됨                     게시판 글에 <script>를 넣어두면, 글을 읽는 모든 사람의 
                                                                          브라우저에서 실행됨. 가장 위험함.
Reflected XSS (반사형)     URL 파라미터 등에 스크립트를 포함시켜 보냄            search.do?q=<script>... 처럼 조작된 링크를 클릭하게 
                                                                          유도하여 즉시 실행됨.
DOM-based XSS             클라이언트 측 스크립트(JS)가 데이터를 처리할 때 발생   서버를 거치지 않고 브라우저 내에서 브라우저 주소창
                                                                          (# 뒤의 값 등)을 읽어 화면을 그릴 때 발생.
                                                                          
4) XSS를 막는 3대 원칙
 4-1) 입력값 검증 (Input Validation)       : 서버로 들어오는 데이터에 위험한 태그가 있는지 체크하고 걸러냅니다.
 4-2) 출력값 이스케이핑 (Output Escaping)   : < → &lt;
                                           > → &gt;
                                           & → &amp;
        이렇게 치환하면 브라우저는 이를 '코드'가 아닌 '문자'로 인식합니다.
 4-3) CSP (Content Security Policy) 설정: 브라우저에게 "이 사이트에서는 신뢰된 서버의 스크립트만 실행해라"라고 엄격한 규칙을 주는 정책입니다.
```
