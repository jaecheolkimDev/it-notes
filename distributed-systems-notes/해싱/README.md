해싱
=================

2\. 해시값의 사용처
-----------
```
해시 값을 만드는 과정(수학적 함수)은 완전히 동일하며, 그 나온 해시값으로 "메모리 번지수를 정할 것인가(일반 해시)" 
아니면 "어느 서버에 저장할 것인가(분산 해싱)"의 차이입니다.
```

2\. 일반적인 해시 함수 (Hash Table)
-----------
```
1) 방식: "apple"이라는 문자열을 해시 함수에 넣으면 385202 같은 해시값이 나옵니다.
2) 사용: 이 숫자를 메모리 배열 크기(예: 10개)로 나누어(385202 % 10 = 2), 2번 메모리 칸에 데이터를 저장합니다.
```

2\. 분산 환경에서의 해싱 (Consistent Hashing 등)
-----------
```
1) 방식: 똑같이 "apple"을 해시 함수에 넣어 385202라는 해시값을 만듭니다.
2) 사용:
 - 일반 해싱: 해시값을 서버 개수로 나누어(385202 % 3 = 1), 1번 서버로 전달합니다.
 - 일관된 해싱: 해시값 385202를 원형 링(0 ~ $2^{32}-1$) 위에 점으로 찍고, 시계 방향으로 가장 가까운 서버 B에 데이터를 저장합니다.
```

2\. 일반적인 해시 함수 vs 분산 시스템의 해싱
-----------
```
구분          일반적인 해시 함수 (데이터 구조)             분산 시스템의 해싱 (일반/일관된 해싱)
목적          데이터의 빠른 검색/저장 위치 찾기             데이터를 저장할 서버(노드) 위치 찾기
변환 대상       단일 메모리 내 해시 테이블의 배열 인덱스     네트워크로 연결된 분산 서버 노드
결과값의 역할     메모리 주소(Index) 계산                데이터를 어느 서버로 보낼지 결정하는 라우팅 키
```
