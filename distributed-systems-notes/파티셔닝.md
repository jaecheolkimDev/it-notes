파티셔닝(Partitioning) 공부 노트
================

1\. 개념
-----------------------------
하나의 데이터베이스에서 특정 테이블을 여러개의 테이블로 물리적으로 분할하여 저장하는 방법입니다.
```
데이터베이스의 성능과 관리 효울성을 향상시키는데 유용합니다.
데이터가 많아질수록 쿼리 성능이 저하되기 때문에 파티셔닝을 통해서 해결을 할 수 있습니다.
실질적으로 접근이 필요한 데이터셋들이 제한적일 때 유용합니다.
```

2\. 종류
-----------------------------
```
1) Range 파티셔닝   : 지정된 열의 값을 기준으로 일정한 범위에 따라서 데이터를 분할합니다.
                    주로 날짜나 숫자 범위를 기준으로 데이터를 파티셔닝하는 데 사용됩니다.
2) Hash 파티셔닝    : 지정된 열의 해시 값을 기준으로 데이터를 균등하게 분할합니다.
                    주로 균등한 데이터 분포를 보장할 때는 해시 파티셔닝을 사용합니다.
```
