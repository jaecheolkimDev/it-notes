CDN(Content Delivery Network)
=================

1\. 개념
-------------------
사용자에게 가장 가까운 서버를 통해 컨텐츠를 전달하는 기술을 말합니다.
```
웹사이트나 동영상, 이미지와 같은 컨텐츠를 더 빠르고 안정적으로 제공하기 위해 사용됩니다.
CDN은 전세계에 분산된 서버 네트워크를 통해 컨텐츠를 빠르게 전달하는 시스템입니다.
쉽게 말해서 필요한 데이터를 가장 가까운 곳에서 제공해주는 시스템이라고 생각하면 됩니다.
물리적 거리가 멀면 전송 속도가 오래 걸린다.
```

2\. 필요한 이유
-------------------
```
1) 속도           : 물리적으로 가까운 서버에서 데이터를 제공하면 네트워크 레이턴시가 극적으로 줄어듭니다.
2) 서버 부하 분산   : CDN이 트래픽에서 처리할 수 있는 대부분을 처리해준다고 하면 origin 서버는 훨씬 적은 부하만을 처리하면 됩니다.
                    갑작스러운 트래픽 급증상황에서도 생명줄이 될 수 있습니다.
3) 가용성, 안정성   : 한 서버의 데이터센터에 문제가 생겨도 다른 서버가 즉시 대체할 수 있어 서비스가 중단없이 운영될 수 있습니다.
4) 비용 절감       : 원본 서버의 대역폭 사용량이 줄어들면 호스팅 비용도 감소합니다.
                    특히 이미지나 동영상 같은 대용량 컨텐츠를 많이 서비스한다면 비용 절감 효과가 더 커집니다.
```

3\. 캐시 무효화 (Invalidation)
-------------------
컨텐츠를 업데이트 했을 때 CDN의 캐시된 오래된 버전을 어떻게 갱신을 할까요?
```
1) 수동 Purge      : CDN 제공업체의 API나 대시보드를 통해서 특정 파일이나 전체 캐시를 강제로 삭제를 할 수가 있습니다.
                    긴급한 버그 수정이나 중요한 업데이트가 있을 때 사용할 수 있습니다.
2) TTL 기반 만료    : 각 컨텐츠에 적절한 만료 시간을 설정해두면 자동으로 갱신됩니다.
3) 버전 관리        : 파일명에 버전이나 해시 값을 포함시키면 됩니다.
```
