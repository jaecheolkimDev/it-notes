컴퓨터공학 관점에서 다루는 핵심 주제
================

1\. 분산 ID 생성 및 해싱 알고리즘
-----------------------------
```
1) 초당 수만 건의 요청이 들어올 때 중복 없는 유일한 키(Key)를 어떻게 생성할 것인가? (Base62, Hash, Snowflake Algorithm 등)
2) 해시 충돌(Collision)을 최소화하고 처리하는 알고리즘 최적화
```

2\. 대규모 데이터베이스 & 캐싱 (High Availability & Scalability)
-----------------------------
```
1) 읽기(Read) 비중이 쓰기(Write)보다 월등히 높은 특성(예: 100:1)을 고려한 Redis/Memcached 캐시 레이어 설계
2) 데이터가 수십억 건으로 늘어날 때 DB를 나누는 샤딩(Sharding) 및 분산 DB 구조
```

3\. 네트워크 & HTTP 프로토콜
-----------------------------
```
1) 301 Redirect vs 302 Redirect의 차이 이해 (브라우저 캐싱 활용을 통한 서버 부하 절감 vs 정확한 클릭 수 추적)
2) DNS 및 글로벌 CDN을 활용한 지연 시간(Latency) 최소화
```

6\. 보안 및 트래픽 제어
-----------------------------
```
악성 URL(피싱 사이트) 스크리닝 및 DDoS 방지를 위한 Rate Limiting(요청 제한 알고리즘)
```
