모니터링 공부 note
======================

1\. 랜처
-----------------------
```
다양한 환경에 흩어져 있는 쿠버네티스 클러스터들을 통합 관리하는 오픈소스 플랫폼
```


2\. Polestar
-----------------------
```
  - IT 시스템의 성능 및 장애를 실시간으로 감시.
  - 이는 서버, 데이터베이스(DB), 웹 애플리케이션(WAS) 등 다양한 IT 인프라의 성능 지표, 구성, 장애, 이벤트를 수집하고 분석하며, 
    대시보드를 통해 시각적으로 제공하는 통합 모니터링 솔루션입니다.
  - 관찰 대상 : CPU, RAM, Disk, OS 프로세스, 네트워크 장비
```

3\. JENNIFER
-----------------------
```
  - 웹 애플리케이션의 성능을 실시간으로 관리하고 최적화하는 APM(Application Performance Monitoring) 솔루션.
  - 이 솔루션은 애플리케이션의 성능 상태를 실시간으로 파악하고, 문제가 발생했을 때 신속하게 원인을 분석하여 안정적인 서비스 운영을 돕습니다.
  - 관점  : 사용자 요청이 들어와서 나갈 때까지의 과정을 봅니다.
   - 특정 URL(서비스)이 왜 느린지 찾을 때.
   - 액티브 서비스(Active Service) 수치를 보며 요청이 쌓이는지(Bottle-neck) 실시간으로 볼 때.
   - 소스 코드 수준에서 어느 메서드가 시간을 잡아먹는지 확인할 때.
```

4\. MaxGauge
-----------------------
```
- 데이터베이스 시스템의 가용성과 성능을 효율적으로 관리하는 전문 솔루션입니다. 
  실시간 모니터링, 상세 분석, SQL 튜닝 등의 기능을 통해 성능 문제를 신속하게 파악하고 해결하는 데 도움을 줍니다.
```

5\. 그라파나(Grafana)
-----------------------
```
  - 오픈소스 데이터 시각화 도구를 사용하여 서버, 애플리케이션, 네트워크 등 다양한 IT 시스템의 상태를 실시간으로 감시하고 분석하는 활동.
  - 프로메테우스(Prometheus)와 같은 다른 도구를 통해 수집된 데이터를 그라파나에서 시각화하여 한눈에 파악하고, 문제 발생 시 알람을 받을 수 있도록 설정할 수 있습니다. 
```
