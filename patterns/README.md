패턴 공부 노트
=================

1\. 종류
---------------
```
소프트웨어 디자인 패턴 (Design Patterns): 주로 코드 레벨의 문제를 해결합니다. 클래스나 객체 간의 관계를 어떻게 구성할지에 집중하죠. 
                                      (예: Singleton, Strategy, Observer)

아키텍처 패턴 (Architectural Patterns): 시스템의 구조적 설계 문제를 해결합니다. 여러 컴포넌트나 서비스 간의 상호작용, 배치, 데이터 흐름을 
                                      다룹니다. (예: MSA, Layered Architecture)
```
