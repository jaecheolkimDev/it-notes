```
패턴      의미                      설명
\r      Carriage Return (CR)    옛날 맥 OS나 **윈도우(Windows)**에서 줄바꿈 시 커서를 맨 앞으로 보낼 때 쓰는 문자
?       0번 또는 1번 발생         앞의 \\r이 있을 수도 있고, 없을 수도 있음을 뜻하는 수량자
\n      Line Feed (LF)          리눅스, 유닉스, 최신 맥 OS, 윈도우 등 거의 모든 시스템에서 새 줄로 바꿀 때 쓰는 문자
```
