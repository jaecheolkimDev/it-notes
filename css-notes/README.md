CSS 공부 note
======================

1\. 이벤트
--------------
1) hover
```
CSS hover 셀렉터의 정의 및 활용 용도
CSS에서 hover는 사용자가 마우스 포인터를 특정 요소 위로 가져갔을 때 해당 요소의 스타일을 변경할 수 있도록 해주는 가상 클래스(pseudo-class)입니다.
사용자 인터랙션에 반응하는 동적인 웹 디자인을 구현할 때 핵심적으로 사용됩니다.
1. 정의
: 기호를 사용하여 :hover 형식으로 표현하며, 선택자 뒤에 붙여 사용합니다.
```

2\. 레이아웃
--------------
1) flexbox
```
뷰포트나 요소의 크기가 불명확하거나 동적으로 변할 때에도 효율적으로 요소를 배치, 정렬, 분산할 수 있는 방법을 제공하는 CSS3의 새로운 레이아웃 방식이다.
```

3\. 여백
--------------
1) 상하좌우로 같은 크기의 여백 주기
```
<div style="padding:10px;"></div>
```
2) 상하좌우 서로 다른 여백 주기
```
<div style = "padding: 5px 1px 2px 3px;">(각각 위 오른쪽 아래 왼쪽 - 시계방향)</div>
```
