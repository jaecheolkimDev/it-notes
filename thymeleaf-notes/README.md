thymeleaf
=================

1\. 개요
-----------
```
타임리프(Thymeleaf)는 자바(Java) 기반의 서버 사이드 템플릿 엔진으로, 스프링 부트(Spring Boot)에서 HTML을 통해 데이터를 동적으로 표현하는 데 주로 사용됩니다. 
HTML 표준을 준수하며 서버 구동 없이도 브라우저에서 화면을 확인할 수 있는 '내추럴 템플릿' 방식이 큰 장점이며, 
SEO(검색 엔진 최적화)와 효율적인 백엔드-프론트엔드 연동을 지원합니다. 

단, 대규모 SPA(Single Page Application)나 복잡한 프론트엔드 로직이 필요한 경우, 
Thymeleaf 대신 React나 Vue.js와 같은 프론트엔드 프레임워크를 사용하기도 합니다. 
그러나 단순 웹 화면이 필요한 기업형 시스템에서는 여전히 주력으로 사용됩니다.

Thymeleaf(타임리프)는 자바 백엔드 개발, 특히 Spring Boot 환경에서 가장 인기 있는 서버사이드 템플릿 엔진으로 매우 많이 사용됩니다. 
JSP를 대체하여 퍼블리싱된 HTML을 그대로 활용할 수 있어 프론트엔드와 백엔드 협업이 용이하고, 유지보수가 쉬워 표준처럼 자리 잡았습니다.

* SPA(Single Page Application)  : 브라우저에 최초 1번만 페이지 전체를 로드하고, 이후에는 데이터만 변경하여 화면의 일부분만 동적으로 갱신하는 
                                  웹 앱 구현 방식입니다. 
                                  새로고침 없는 빠른 화면 전환으로 네이티브 앱과 유사한 사용자 경험을 제공하며, 
                                  주로 React, Vue, Angular 등의 프레임워크를 사용합니다.  
```

2\. 핵심 특징 및 장점
-----------
```
내추럴 템플릿 (Natural Templates): 템플릿 파일이 HTML 구조를 그대로 유지하여, 서버 없이 브라우저에서 직접 열어도 결과 화면을 미리 확인할 수 있습니다.
서버 사이드 렌더링 (SSR): 컨트롤러에서 전달받은 데이터를 HTML에 바인딩하여 완성된 HTML을 브라우저에 전달합니다.
스프링 통합: 스프링 프레임워크와 강력하게 통합되어, 편리한 데이터 바인딩 및 폼 처리를 지원합니다.
가독성 및 유지보수: HTML 태그 내에 th: 속성을 사용하여 가독성이 높고, 디자이너와 개발자 간 협업이 용이합니다. 
```

3\. 주요 문법
-----------
```
th:text: 태그 내 텍스트 내용을 변경합니다 (예: <span th:text="${data}">Default</span>).
th:value: input 태그 등의 값을 설정합니다.
th:each: 반복문(loop)을 처리합니다 (예: <tr th:each="user : ${users}">).
th:if / th:unless: 조건문(conditional)을 처리합니다.
th:action: 폼(form) 태그의 제출 주소를 설정합니다.
th:replace / th:insert: 다른 HTML 조각을 포함합니다.
```
