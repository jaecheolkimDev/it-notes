2\. JS 기반 소스 코드를 실행 파일(.exe 등)로 만들려면 일반적으로 Node.js 환경에서 사용되는 특정 도구를 사용
--------------------------------------
```
JavaScript는 브라우저나 Node.js 같은 런타임 환경에서 인터프리터 방식으로 실행되는 언어이기 때문에,
C++ 같은 컴파일 언어와는 달리 자체적으로 실행 파일을 생성하지는 않습니다. 
JS 소스만으로는 독립 실행 파일을 만들 수 없으며, 
Node.js 기반 도구나 데스크톱 프레임워크를 활용하여 JS 런타임 환경을 포함한 패키지 형태의 실행 파일을 생성해야 합니다.

주요 방법
1. Node.js 애플리케이션의 경우
- Node.js는 주로 서버 측 및 네트워킹 애플리케이션을 구축하는 데 사용되는 런타임 환경
    서버 측 애플리케이션이나 명령줄 도구 등 Node.js 기반 프로젝트는 pkg, nexe, 또는 Bun 같은 도구를 사용하여 단일 실행 파일로 패키징할 수 있습니다. 
    pkg: 프로젝트의 모든 종속성을 분석하고 Node.js 런타임과 함께 단일 실행 파일로 묶어줍니다. 대상 시스템에 Node.js가 설치되어 있지 않아도 실행할 수 있습니다.
    nexe: pkg와 유사한 기능을 제공하며, 조금 더 사용하기 쉽고 빌드 속도가 빠를 수 있습니다.
    Bun: Node.js의 대안으로 떠오르는 런타임으로, --compile 플래그를 사용하여 단일 실행 파일을 생성하는 기능을 지원합니다. 
2. 데스크톱 애플리케이션(GUI)의 경우
- 데스크톱 애플리케이션은 사용자 컴퓨터에 직접 설치되어 독립적으로 실행되는 소프트웨어
    HTML, CSS, JavaScript를 사용하여 데스크톱 애플리케이션을 만들 때는 Electron이나 NW.js 같은 프레임워크를 사용합니다. 이들은 Chromium 웹 엔진과 Node.js 런타임을 포함하는 형태로 앱을 패키징하며, 최종 결과물로 실행 파일을 생성할 수 있습니다. 
    Electron:
    웹 기술로 구축된 애플리케이션을 데스크톱 앱으로 만들어줍니다 (예: VS Code, Slack, Discord). electron-builder 또는 electron-packager 같은 도구를 사용하여 최종 배포용 실행 파일을 생성합니다. 
```
