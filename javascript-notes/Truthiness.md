Truthiness (참/거짓 평가 성질)
=================

1\. Truthy ('참으로 평가되는 값')
-----------
유효한 값이 담겨 있을 때입니다.
```
1) 객체/배열: { name: 'Kim' }, [1, 2, 3], {} (빈 객체), [] (빈 배열)
2) 문자열: 'hello' (비어있지 않은 문자열)
3) 숫자: 100, -1 (0이 아닌 숫자)
4) Boolean: true
```

2\. Falsy ('거짓으로 평가되는 값')
-----------
비어있거나 값이 없을 때입니다.
```
1) undefined (속성이 정의되지 않음)
2) null (값이 없음)
3) "" (빈 문자열)
4) 0 또는 NaN
5) false
```
