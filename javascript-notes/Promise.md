Promise(프로미스)
=====================

1\. 개념
-------------------
자바스크립트에서 비동기 작업(Asynchronous operation)의 최종 완료 또는 실패를 나타내는 아주 특별한 '객체(Object)'입니다.
```
자바스크립트는 싱글 스레드로 작동하기 때문에 API 호출, 타이머, 파일 읽기 같은 처리가 무거운 작업을 할 때 비동기 방식을 사용합니다. 과거에는 이를 위해 
콜백(Callback) 함수를 주로 사용했으나, 복잡해지면 코드의 가독성이 떨어지는 '콜백 지옥(Callback Hell)'에 빠지게 되었습니다. 이를 우아하게 해결하기 
위해 도입된 것이 바로 프로미스입니다.
```

2\. 3가지 상태 (States)
-------------------
프로미스는 생성되고 종료될 때까지 3가지 중 하나의 상태를 가집니다.
```
상태              의미              설명
Pending (대기)    작업 진행 중     비동기 처리 로직이 아직 완료되지 않은 초기 상태
Fulfilled (이행)  작업 성공       비동기 처리가 완료되어 프로미스가 결과 값을 반환한 상태
Rejected (거부)   작업 실패       비동기 처리가 실패하거나 오류가 발생한 상태
```

3\. 프로미스 만들기 (생성)
-------------------
```
new Promise() 클래스를 인스턴스화하여 프로미스를 만듭니다. 이때 인자로 콜백 함수를 받는데, 이 함수는 다시 resolve와 reject라는 두 개의 함수를 
매개변수로 받습니다.

resolve(): 비동기 작업이 성공했을 때 호출합니다. (상태를 Fulfilled로 변경)
reject(): 비동기 작업이 실패했을 때 호출합니다. (상태를 Rejected로 변경)
```

4\. 프로미스 사용하기 (소비)
-------------------
```
생성된 프로미스의 결과물은 .then(), .catch(), .finally() 메서드를 통해 받아서 처리합니다.
```

5\. 프로미스 체이닝 (Promise Chaining)
-------------------
```
프로미스의 큰 장점 중 하나는 .then() 메서드를 연속해서 연결할 수 있다는 점입니다. 이를 통해 비동기 작업을 순차적으로 실행할 수 있습니다.
```

6\. 더 진화한 형태: async / await
-------------------
```
프로미스 체이닝조차 코드가 길어지면 복잡해 보일 수 있습니다. 그래서 ES8(2017)에서 async와 await 문법이 도입되었습니다. 이 문법은 완전히 새로운 기술이 
아니라, 내부적으로는 프로미스를 기반으로 작동하면서 문법만 동기식 코드처럼 보이게 만들어 주는 '문법적 설탕(Syntactic Sugar)'입니다.

앞서 작성했던 질문의 코드처럼 비동기 함수 앞에 await를 붙이면, 해당 프로미스가 Fulfilled나 Rejected 상태가 될 때까지 코드 실행을 일시 정지하고 기다려 
줍니다.
```
