2\. 개발완료 후 적용할 것
-----------
```
- Google AdSense : 가장 쉬운 첫 수익, 광고 붙이기
- SEO(Search Engine Optimization, 검색엔진 최적화) - 가게를 목 좋은 곳으로, 무료 손님 유치
  - 구글은 '구글 서치 콘솔(Google Search Console)', 네이버는 '네이버 서치어드바이저(Naver Search Advisor)'라는 무료 도구를 제공합니다.
    이 도구들을 통해 당신의 사이트가 검색 엔진에서 어떻게 보이고 있는지 모니터링하고, 중요한 정보를 제출하며, 발생할 수 있는 문제들을 진단할 수 있습니다.
  - "사이트를 만들어두면 언젠가 구글이 알아서 찾아오겠지"라고 생각할 수 있습니다. 이는 사실이지만, 매우 느리고 비효율적인 방식입니다. 
    검색 엔진에 당신의 사이트를 직접 등록하고 사이트맵을 제출하는 것은 이 발견(크롤링)과 색인(인덱싱) 과정을 극적으로 가속화하는 행위입니다.
    이는 당신의 콘텐츠가 훨씬 더 빨리 검색 결과에 나타나 잠재 고객을 유치할 수 있게 해준다는 의미이며,
    이 간단한 행동이 당신의 비즈니스 성공 속도에 직접적인 영향을 미칩니다.
  - 이제 검색 엔진에 당신의 존재를 알렸으니, 그들이 당신의 사이트를 더 효율적으로 탐색할 수 있도록 지도와 규칙을 제공할 차례입니다.
    - 사이트맵 (Sitemap - 지도): XML 사이트맵은 당신 웹사이트에 있는 모든 중요한 페이지들의 목록을 담고 있는 파일입니다. 이는 크롤러에게 "우리 사이트에는 이런 페이지들이 있으니 빠짐없이 둘러봐 주세요"라고 알려주는 친절한 지도와 같습니다. 대부분의 현대적인 웹사이트 빌더(바이브코딩 포함)는 이 파일을 자동으로 생성해줍니다. 보통 `myprogram.com/sitemap.xml`과 같은 주소에서 찾을 수 있습니다.
      - 제출 방법: 구글 서치 콘솔과 네이버 서치어드바이저 양쪽 모두 '사이트맵' 또는 '요청 > 사이트맵 제출' 메뉴가 있습니다. 이 메뉴에 들어가 당신의 사이트맵 URL(`sitemap.xml`)을 입력하고 제출하면 됩니다.
    - RSS (Really Simple Syndication): '새 글 구독 알림'
      RSS는 내 사이트에 새로운 글이 올라올 때마다, 이 사실을 외부에 자동으로 알려주는 '새 소식 발행' 기능입니다. 사용자들이나 다른 서비스가 내 사이트의 RSS 피드를 '구독'하면, 새 글이 올라올 때마다 자동으로 정보를 받아볼 수 있습니다. 검색 엔진은 RSS를 통해 "아, 이 사이트는 꾸준히 새로운 콘텐츠가 올라오는 활발한 곳이구나!"라고 인식하여 더 자주 방문하게 됩니다.
    - Robots.txt (규칙서): `robots.txt`는 검색 엔진 크롤러에게 "이 부분은 들어오지 마세요"라고 알려주는 간단한 텍스트 파일입니다. 예를 들어, 회원들만 봐야 하는 페이지나 관리자 로그인 페이지 등은 검색 결과에 노출될 필요가 없습니다. 이 파일 역시 바이브코딩에서 자동으로 관리해줄 가능성이 높으며, 보통은 직접 수정할 필요가 없습니다. `myprogram.com/robots.txt` 주소로 접속하여 파일이 존재하는지만 확인해보면 충분합니다.
- Google Analytics - 내 고객을 읽는 눈, 데이터 분석
- 결제 시스템 구축 - 직접 돈 받기, 상품 판매의 시작(국내에서는 토스페이먼츠, 해외에서는 Stripe가 대표적입니다.)
  - 단건결제, 정기결제
  - 보안과 안전장치, https
  - 스케줄링
- 구독 모델 설계 - 단골손님 만들기, 월세 수익
- 내 사이트의 '간판' 달기: 도메인 구매와 연결
```

    - [Hugging Face 웹사이트](https://huggingface.co/)

    - [AI Hub 웹사이트](https://www.aihub.or.kr/)

    - (https://www.dacon.io/)

    - (https://www.reddit.com/)
    
다른 사이트 디자인 참조하는 사이트 [https://dribbble.com/](https://dribbble.com/)

Tweak CN은 ShadCN UI 컴포넌트 라이브러리의 테마를 매우 쉽고 직관적으로 커스터마이징할 수 있게 해주는 놀라운 웹사이트입니다. 코드를 한 줄도 작성하지 않고도 전문적인 디자인 시스템을 구축할 수 있습니다.
    코드 추출 및 적용:
        - 마음에 드는 디자인이 완성되면, 'Code' 탭으로 이동하여 생성된 CSS 코드를 전체 복사합니다.
        - 이 코드를 당신의 프로젝트에 `index.css` (또는 `globals.css`) 파일로 붙여넣습니다.
        - 이제 Cursor에게 이 CSS 파일을 기반으로 프로젝트를 빌드하라고 지시하면, 당신이 직접 디자인한 테마가 완벽하게 적용된 웹사이트가 만들어집니다.
        
- [React Bits](https://reactbits.dev/): 아름다운 애니메이션이 포함된 React 컴포넌트를 제공합니다.
- [Aceternity UI](https://ui.aceternity.com/): 독창적이고 세련된 UI 컴포넌트로 유명합니다.
- https://fonts.google.com/ : 수많은 스타일의 무료 폰트를 제공.
- https://www.latpeed.com/ : 무형의 컨텐츠 판매

4\. API 사이트
-----------
```
1. 공공 API
- 기상청 날씨 API: 동네별 날씨, 주간 예보 등 날씨 정보를 제공합니다.
- 한국환경공단 대기오염 API: 미세먼지, 초미세먼지 농도 등 대기 질 정보를 제공합니다.
- 서울시 열린 데이터 광장: 서울시의 버스 도착 정보, 공공자전거 '따릉이' 현황 등 생활 밀착형 데이터를 제공합니다.
2. 기업 API
- 지도 API: 네이버 지도, 카카오맵, 구글맵 등 지도와 길찾기, 장소 검색 기능을 내 앱에 넣을 수 있습니다.
- 소셜 미디어 API: 유튜브의 인기 동영상 목록을 가져오거나, 인스타그램의 내 게시물을 웹사이트에 표시할 수 있습니다.
- 번역 API: 네이버 파파고, 구글 번역 등의 번역 엔진을 사용하여 실시간 번역 기능을 만들 수 있습니다.
- 결제 API: 토스페이먼츠, 카카오페이 등을 연동하여 내 웹사이트에서 사용자가 물건을 구매하고 결제하게 만들 수 있습니다.
- AI API: OpenAI(ChatGPT), 네이버 클로바 등 거대 AI 모델의 기능을 빌려와 나만의 AI 서비스를 만들 수 있습니다.
```
