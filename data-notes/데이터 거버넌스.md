데이터 거버넌스
=================

1\. 데이터 거버넌스
-----------
데이터를 조직의 자산으로 관리하자
```
도서관에서 책을 관리하듯이 체계적으로 관리하자
```

2\. 필요한 이유
-----------
```
1) 데이터 품질 보장    : 잘못된 데이터로 의사결정을 하면 안된다.
2) 규제 준수          : 개인정보보호법 등 법적 요구사항을 지켜야 합니다.
3) 비용 절감          : 쓸모없는 데이터를 저장하는데 돈이 굉장히 많이 들어갑니다.
4) 협업 효율          : 팀마다 다른 정의를 쓰면 회의 시간이 늘어나고 판단에 차질을 빚게 됩니다.
5) 데이터 보안         : 사람마다 접근할 수 있는 데이터를 명확히 관리해야 합니다.
```

3\. 구성 요소
-------------------------
```
1) 데이터 카탈로그(Catalog)    : 회사의 데이터 목록을 보여줌. 회사의 모든 데이터 자산을 검색할 수 있게 해주는 시스템입니다.
2) 데이터 계보(Lineage)        : 어디서 태어나서 어떤 과정을 거쳐서 어디까지 왔는지를 추적을 합니다.
3) 데이터 품질(Quality)        : (GIGO) 정확성, 안정성, 일관성, 적시성, 유효성
4) 메타데이터 관리             : 데이터의 데이터 관리
5) 데이터 보안 및 접근제어       : MAC(Mandatory), RBAC(Role Based)
```
