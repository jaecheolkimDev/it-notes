data-analysis
=================

1\. 변경 데이터 캡처(CDC, Change Data Capture)
-----------
```
소스 데이터베이스에서 발생하는 데이터의 삽입(Insert), 갱신(Update), 삭제(Delete)와 같은 변경 사항을 실시간으로 감지하여 
타깃 시스템으로 즉시 복제하거나 동기화하는 기술 및 패턴입니다. 
이는 시스템 전체의 데이터 무결성을 유지하며, 별도의 타깃 DB를 생성해 운영 DB의 부하를 최소화하면서 
실시간 데이터 분석 및 마이그레이션을 가능하게 합니다. 

핵심 특징 및 장점
 - 실시간 데이터 동기화: 데이터가 변경되는 즉시 타깃 시스템에 반영하여 데이터의 신선도를 유지합니다.
 - 운영 부하 최소화: 대부분의 CDC 솔루션은 운영 데이터베이스의 변경 로그를 기반으로 데이터를 추출하므로 성능 영향을 최소화합니다.
 - 데이터 일관성 보장: 복잡한 ETL(Extract, Transform, Load) 과정 없이 원본과 동일한 순서로 데이터를 전송하여 데이터 무결성을 보장합니다.
 - 다양한 활용 사례: 데이터 웨어하우스, 클라우드 마이그레이션, 마이크로서비스 간 데이터 동기화에 필수적으로 활용됩니다. 

주요 구성 요소 및 작동 원리
 - 캡처(Capture): 원천 DB의 트랜잭션 로그를 읽어 데이터 변경 사항을 식별합니다.
 - 전송(Transport): 캡처된 데이터를 타깃으로 전송합니다.
 - 적용(Apply): 타깃 시스템(DB, Kafka 등)에 데이터를 저장합니다. 

CDC는 운영 중인 시스템의 중단 없이(Zero-downtime) 데이터 이전이 필요한 경우나, 실시간 데이터 분석이 필수적인 금융/통신 산업 등에서 
많이 활용되고 있습니다.  
```
