직렬화(Serialization)
=================

2\. 정의
-----------
```
복잡하게 얽혀 있는 메모리 상의 객체를 어디서든 주고받고 저장할 수 있는 일직선 형태의 데이터(스트림)로 포장하는 작업
```

3\. 직렬화를 하는 핵심 이유
-----------
```
서로 다른 시스템 간에 데이터(객체)를 교환할 수 있게 해줍니다.
```

3\. 객체를 그대로 전달할 수 없는 이유
-----------
```
프로그램이 실행되는 동안 객체는 컴퓨터 메모리(RAM)에 존재합니다. 메모리 속 객체는 연속된 공간에 한 덩어리로 존재하는 것이 아니라, 여러 
주소값(참조/Pointer)으로 연결된 복잡한 구조를 가집니다.
1) 메모리 한계       : 메모리는 전원이 꺼지면 사라지는 휘발성 영역입니다.
2) 주소값의 불일치     : 객체가 가진 주소값은 해당 프로그램(프로세스) 내부에서만 유효합니다. 이 상태 그대로 파일로 저장하거나 다른 
                      컴퓨터로 보내면 상대방은 객체를 복원할 수 없습니다.
```

3\. 직렬화를 사용하는 핵심 목적
-----------
```
1) 데이터 지속성 (Persistence)    : 메모리의 객체를 파일(JSON, XML, 바이트 파일 등)이나 DB에 저장해 두고, 프로그램이 종료된 후에도 
                                  나중에 불러와(역직렬화) 사용할 수 있습니다.
2) 네트워크 통신 (Network Transmission)   : Client와 Server 간 데이터 주고받기, 또는 서로 다른 서버(MSA 구조 등) 간에 객체 
                                          상태를 주고받을 때 스트림 형태(JSON/Protobuf 등)로 변환해 전송합니다.
3) 프로세스 간 통신 (IPC)          : 하나의 기기 안에서도 서로 다른 프로세스끼리 객체 데이터를 공유할 때 사용합니다.
4) 캐싱 (Caching)                 : Redis, Memcached 같은 외부 인메모리 캐시 시스템에 객체를 저장해 두고 빠르게 불러올 때 
                                   직렬화를 거칩니다.
```

3\. 주요 직렬화 형태 비교
-----------
```
구분              대표 방식                           장점                                  단점                                      주요 용도
문자열 형태          "JSON, XML"                     "사람이 읽기 쉬움, 언어 간 호환성 높음"    데이터 크기가 상대적으로 큼                 "REST API, 웹 통신, 설정 파일"
이진(Binary) 형태   "Java Serialization, Protobuf"  "변환 속도 빠름, 데이터 크기 작음"       "사람이 읽을 수 없음, 버전 호환성 관리 필요"     "네트워크 RPC, 내부 IPC, 캐시 저장"
```

3\. 대표적인 JSON 직렬화 사례
-----------
```
Java 객체를 Jackson이나 Gson 같은 라이브러리를 사용해 JSON 텍스트로 바꾸는 작업
```

3\. 객체 직렬화 (Object Serialization) vs DB 격리 수준의 직렬화 (Serializable)
-----------
 - 프로그래밍의 직렬화   : "데이터 구조를 일자로 늘어놓는 것(Format Transformation)"
 - DB의 직렬화        : "작업을 일자로 줄 세워 실행하는 것(Sequential Execution)"
```
구분  객체 직렬화 (Object Serialization)                           DB 격리 수준의 직렬화 (Serializable)
대상  메모리 상의 객체(Object) 데이터                               동시에 실행되는 트랜잭션(Transaction)들
목적  객체를 저장하거나 네트워크로 전송하기 위해                     여러 트랜잭션이 동시에 실행될 때 데이터 정합성을 완벽히 보장하기 위해
개념  복잡한 객체 구조를 1차원 바이트/문자열 스트림으로 펼침         여러 트랜잭션을 마치 한 번에 하나씩 순차적(직렬)으로 실행하는 것처럼 처리
비유  입체 프라모델을 상자에 넣기 위해 부품별로 펼쳐서 포장하는 것      은행 창구에서 줄을 서서 한 명씩 순서대로 업무를 보는 것
```

3\. 역직렬화(Deserialization)
-----------
