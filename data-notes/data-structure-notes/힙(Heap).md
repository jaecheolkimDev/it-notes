힙 트리 (Heap Tree) 또는 그냥 힙 (Heap)
=================

1\. 정의
-----------
```
완전 이진 트리라는 틀(뼈대) 위에 힙 성질(반정렬 규칙)을 얹은 것 자체를 힙(Heap) / 힙 트리(Heap Tree)라고 부릅니다.
```

2\. 구조적 조건
-----------
```
완전 이진 트리 (Complete Binary Tree)
```

3\. 반정렬이란?
-----------
약한 정렬 (Weakly Ordered / Partially Ordered Structure)
```
전체가 완전히 정렬된(Strongly Ordered) 상태가 아닌, 부모-자식 간의 부분적인 대소 관계만 유지한다는 의미입니다.
```

4\. 힙 순서 속성 (Heap-Order Property)
-----------
```
트리의 각 노드가 자신의 자식들보다 항상 우선순위가 높게 배치되는 정렬 규칙을 뜻합니다.
```

5\. 반정렬을 만들어내는 '힙 성질(Heap Property)'이란?
-----------
힙 성질은 트리 내 모든 부모-자식 노드 간에 적용되는 대소 관계 규칙입니다. 이 규칙에 따라 두 가지로 나뉩니다.
```
1) 최대 힙 성질 (Max-Heap Property)
 - 모든 부모 노드의 값이 자식 노드의 값보다 크거나 같다 (Parent >= Child).
 - 트리 내에서 가장 큰 값이 루트 노드에 위치합니다.
2) 최소 힙 성질 (Min-Heap Property)
 - 모든 부모 노드의 값이 자식 노드의 값보다 작거나 같다 (Parent <= Child).
 - 트리 내에서 가장 작은 값이 루트 노드에 위치합니다.
```
