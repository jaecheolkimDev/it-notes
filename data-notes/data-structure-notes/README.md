데이터 구조
=====================

1\. 직렬화
-------------------
```
직렬화(Serialization)      : 프로그램 내부의 객체(Object)나 데이터를 다른 환경에서 사용하기 좋도록 변환하는 과정입니다.
                            이는 서로 다른 시스템 간에 데이터를 교환할 수 있게 해주며,
                            컴퓨터가 이해하는 이진 데이터(Binary)를 사람이 읽기 쉬운 텍스트(Human-readable)로 바꿈.
역직렬화(Deserialization)   : 이후 다시 원래 객체로 복원하는 과정.
```
