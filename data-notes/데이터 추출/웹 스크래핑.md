웹 스크래핑(Web Scraping)
=============

4\. 정의
--------
```
특정 웹페이지에 접속하여 구조화된 HTML/CSS 문서를 파싱한 뒤, 원하는 특정 데이터(가격, 상품명, 게시글, 이미지 등)만을 추출하여 
저장하는 기술입니다.
```

5\. 웹 크롤러 vs 웹 스크래핑
--------
```
웹 크롤러가 웹을 '탐색'하며 페이지를 모으는 '길잡이'라면, 
스크래핑은 수집된 페이지에서 필요로 하는 '알맹이'를 뽑아내는 추출 작업입니다.
```

6\. 핵심 기술 및 도구
--------
수집 대상 웹사이트의 성격(정적/동적)에 따라 주로 활용되는 도구와 기술 스택이 달라집니다.
```
구분                  정적 스크래핑 (Static Scraping)           동적 스크래핑 (Dynamic Scraping)
대상                  서버가 완제품 HTML을 응답하는 사이트          JavaScript(React/Vue 등)로 화면을 그리는 CSR 사이트
특징                  속도가 매우 빠르고 서버 리소스 소모가 적음    실제 브라우저를 띄워 렌더링되므로 속도가 상대적으로 늦음
주요 도구 (Python)      "Requests, BeautifulSoup, lxml"         "Selenium, Playwright, Puppeteer"
주요 도구 (Java/JS)     "Jsoup (Java), Cheerio (Node.js)"       "Playwright Java, Puppeteer"
```

4\. 웹 스크래핑 파이프라인 (처리 과정)
--------
```
1.대상 탐색 및 분석 (Inspect):
 - 개발자 도구(F12)를 통해 목표 데이터가 위치한 HTML 태그의 구조, CSS Selector 또는 XPath 규칙을 파악합니다.
2.웹 페이지 요청 (Fetch):
 - HTTP 클라이언트(예: axios, Requests)나 Headless 브라우저를 통해 대상 URL에 GET 요청을 전송하여 문서를 받아옵니다.
3.데이터 추출 및 파싱 (Parse):
 - 파서(Parser)를 사용해 수집한 DOM 구조에서 CSS Selector나 XPath 표현식을 기반으로 필요한 텍스트, 이미지 URL, 테이블 데이터 등을 정교하게 추출합니다.
4.데이터 정제 (Clean):
 - 추출된 Raw Text에서 불필요한 공백, 특수문자, HTML 태그를 제거하고 숫자/날짜 형식으로 변환합니다.
5.데이터 저장 (Store):
 - 정제된 데이터를 CSV, JSON 파일이나 RDB(MySQL), NoSQL(MongoDB) 등 데이터베이스에 저장합니다.
```

5\. 스크래핑 구현 시 맞닥뜨리는 주요 과제
--------
```
1) 구조 변경 감지 (DOM Fragility): 대상 사이트의 UI 업데이트로 태그 ID나 Class명이 바뀌면 파싱 로직이 손상됩니다. 속성값보다는 
                                 상위 구조 기반의 유연한 Selector 설정이 필수적입니다.
2) 차단 메커니즘 (Anti-Scraping Techniques):
 - Cloudflare, Akamai 등의 WAF(Web Application Firewall) 탐지
 - IP 기반 Request Rate Limit 및 CAPTCHA 발동
 - 브라우저 핑거프린팅(Headless 모드 탐지)
3) 법적·윤리적 문제: 무단 데이터 스크래핑은 저작권 침해, 영업방해, 이용약관(ToS) 위반 이슈를 유발할 수 있으므로 상업적 이용 시 사전에 
                  허용 범위 확인이 중요합니다.
```
