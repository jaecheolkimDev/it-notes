알고리즘
======================

1\. 정렬 알고리즘
--------------
```
1. 기본 정렬 알고리즘 (시간 복잡도: $O(n^2)$)        : 데이터 양이 적을 때 유용하며, 구조가 단순하여 구현하기 쉽습니다.
    ① 선택 정렬 (Selection Sort)
        원리: 전체 원소 중 최솟값을 찾아 맨 앞에 있는 원소와 자리를 바꾸는 과정을 반복합니다.
        특징: 데이터 양이 많아질수록 성능이 급격히 떨어집니다.
    ② 삽입 정렬 (Insertion Sort)
        원리: 각 숫자를 적절한 위치에 삽입하는 방법입니다. 두 번째 원소부터 시작하여 앞의 원소들과 비교하며 제자리를 찾아갑니다.
        특징: 데이터가 이미 거의 정렬되어 있는 상태라면 어떤 알고리즘보다도 빠릅니다.
    ③ 버블 정렬 (Bubble Sort)
        원리: 인접한 두 원소를 비교하여 자리를 바꾸는 과정을 반복합니다. 큰 값이 정렬 배열의 맨 뒤로 밀려나가는 모습이 거품이 일어나는 것 같다고 해서 붙여진 이름입니다.
        특징: 구현은 가장 쉽지만, 스와프(자리 바꾸기) 연산이 너무 많아 효율성은 가장 떨어집니다.
2. 고급 정렬 알고리즘 (시간 복잡도: $O(n \log n)$)       : 대용량 데이터를 처리할 때 주로 사용되는 효율적인 알고리즘입니다.
    ① 퀵 정렬 (Quick Sort)
        원리: 하나의 기준값(피벗, Pivot)을 정한 뒤, 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 나누는 과정을 분할 반복(재귀)합니다.
        특징: 평균적으로 가장 빠른 속도를 자랑하여 실무에서 가장 많이 쓰입니다. 단, 피벗을 잘못 선택해 최악의 경우 $O(n^2)$이 될 수 있습니다.
    ② 병합 정렬 (Merge Sort)
        원리: 배열을 원소가 하나가 될 때까지 반으로 쪼갠 뒤, 다시 합치면서(병합) 정렬하는 방법입니다 (분할 정복).
        특징: 퀵 정렬과 달리 최악의 경우에도 항상 $O(n \log n)$을 보장합니다. 대신 합치는 과정에서 추가적인 메모리 공간이 필요합니다.
    ③ 힙 정렬 (Heap Sort)
        원리: 완전 이진트리의 일종인 '힙(Heap)' 자료구조를 이용하는 정렬 방식입니다. 최댓값이나 최솟값을 빠르게 찾아내 정렬합니다.
        특징: 병합 정렬처럼 항상 $O(n \log n)$을 보장하며, 추가적인 메모리 공간도 필요하지 않아 효율적입니다.
```

999\. 자바의 정렬
--------------
```
- Arrays.sort() : dual-pivot-Quicksort 알고리즘 , 평균시간복잡도 O(nlogn) , 최악시간복잡도 O(n^2)
- Collections.sort() : Timsort - 2개의 정렬에서 좋은것만 차용함 - hybrid stable sorting 알고리즘 
    - 합병정렬 최악의 경우 O(nlogn) 
    - 삽입정렬 최선의 경우 O(n)
- 객체 정렬
    - Comparable : 클래스에서 implements를 통해서 정렬기준을 만듬.
    - Comparator : 아무 클래스나 상관없이 개별소스에서 정렬기준을 임시로 생성해서 사용함.
```
