외판원 순회 문제(TSP, Traveling Salesperson Problem)
===========================================

1\. 정의
--------------------
```
$N$개의 도시와 도시 간 이동 비용이 주어졌을 때, 한 도시에서 출발하여 모든 도시를 정확히 한 번씩 방문하고 다시 출발 도시로 돌아오는 
최단 경로를 찾는 문제
```

2\. 특징
--------------------
```
NP-난해(NP-Hard) 문제로, $N$이 커질수록 경우의 수가 폭발적으로 증가
```

3\. 출발점
--------------------
```
사이클(순회)을 이루므로 어느 도시에서 출발해도 최단 거리는 동일
```

4\. $N$의 크기별 해결 접근법
--------------------
코딩 테스트나 알고리즘 문제에서는 $N$의 범위에 따라 접근 방식이 달라집니다.
```
1) $N \le 10 \sim 11$ (완전 탐색 / 백트래킹)
 - 가능한 모든 순열을 탐색: 시간 복잡도 $O(N!)
 - $DFS + 백트래킹으로 가지치기(Pruning)하여 해결
2) $N \le 16 \sim 20$ (DP + 비트마스킹)
 - 표준적인 문제 풀이 방식: 시간 복잡도 $O(N^2 \cdot 2^N)$
 - 메모이제이션으로 중복 연산을 제거하여 계산량을 대폭 감소
3) $N > 20$ (근사 알고리즘 / 그리디 / 유전 알고리즘)
 - 다항 시간 내 최적해를 구하기 어려우므로 최적에 가까운 해(Approximate Solution)를 찾음
```

5\. 비트마스킹(Bitmasking)을 쓰는 이유
--------------------
```
방문한 도시의 목록을 boolean[] 배열로 다루면 DP 배열의 인덱스로 사용할 수 없습니다. 도시 방문 여부를 2진수 비트로 표현하면 
정수 하나로 깔끔하게 상태를 나타낼 수 있습니다.
 ex) 도시가 4개일 때: 1011(2) = 1번, 2번, 4번 도시 방문 완료
```

6\. DP 테이블 정의
--------------------
dp[current][visited]
```
1) current: 현재 위치한 도시 번호
2) visited: 지금까지 방문한 도시들의 비트마스크 집합
3) 값: 현재 상태에서 출발해 남은 도시들을 모두 방문하고 출발 도시로 돌아가는 최소 비용
```
