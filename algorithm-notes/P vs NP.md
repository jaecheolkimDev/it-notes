P vs NP
======================

1\. 핵심 질문 (세계 7대 수학 난제)
--------------
우리가 쉬운 답 검증법을 알고 있다면, 그에 대응하는 쉬운 문제 해결 알고리즘도 반드시 존재하는가?
```
답을 검증하는 것은 쉽지만, 직접 푸는 것은 본질적으로 훨씬 더 오래 걸리고 어려운 문제들이 분명히 존재한다고 보고 있음.
```

1\. P 문제 (Polynomial)
--------------
"결정론적 컴퓨터로 다항 시간(Polynomial time) 안에 쉽게 풀 수 있는 문제"
```
의미: 현실적인 시간 안(컴퓨터가 아주 빠르게)에 정답을 찾아낼 수 있는 정렬된 알고리즘이 존재하는 문제입니다.
특징: 보통 $O(n)$, $O(n^2)$, $O(n^3)$ 등의 다항 시간 복잡도를 가집니다.
예시: 알고리즘 알고 계시는 정렬(Sorting), 이진 탐색(Binary Search), 최소 신장 트리(MST) 찾기 등이 이에 해당합니다.
```

2\. NP 문제 (Nondeterministic Polynomial)
--------------
"비결정론적 컴퓨터로 힌트(답)가 주어졌을 때, 이게 정답인지 다항 시간 안에 확인(Verification)할 수 있는 문제"
```
의미: 직접 풀기에는 컴퓨터로 수백 년이 걸릴지 모르지만, 누군가 "이게 답이야"라고 가져왔을 때 그게 맞는지 틀린지 검산하는 것은 빠르게
     (다항 시간 안에)할 수 있는 문제입니다.
주의: 'P가 아닌 문제(Not P)'가 아닙니다! 모든 P 문제는 당연히 검산도 빠르기 때문에 P 문제는 NP 문제에 포함(P ⊂ NP)됩니다. 컴퓨터 
      과학의 최대 난제 중 하나가 바로 "정말 풀기 쉬운 문제(P)와 검산만 쉬운 문제(NP)가 같은 집합일까? ($P = NP?$)" 하는 질문입니다.
예시: 스도쿠(직접 풀긴 어렵지만 채점은 쉬움), 암호 해독.
```

9\. NP-완전(NP-Complete)
--------------
NP 문제들 중에서도 "가장 어려운 문제들의 집합"입니다.
```
NP-완전이 되려면 다음 두 가지 조건을 모두 만족해야 합니다.
 1) NP 문제이어야 함
 2) NP-난제(NP-Hard)이어야 함
```

3\. NP-Hard 문제 (NP-난해)
--------------
"적어도 NP 문제만큼, 혹은 그보다 훨씬 어려운 문제들의 집합"
```
의미: "이 문제를 풀 수 있으면 모든 NP 문제를 다 풀 수 있다"고 할 정도로 악명 높은 난이도의 문제들입니다. 중요한 점은, NP-Hard 문제는 
    답을 주었을 때 맞는지 확인하는 것조차 다항 시간 안에 불가능할 수 있습니다. (즉, NP 집합에 속하지 않을 수도 있습니다.)
예시: 그 유명한 외판원 순회 문제(TSP, Traveling Salesperson Problem), 배낭 문제(Knapsack Problem)
```

4\. 비교
--------------
```
분류         직접 풀기 (다항 시간 내)          답 검산하기 (다항 시간 내)      특징
P           가능 (쉬움)                     가능 (쉬움)                   이미 효율적인 알고리즘이 많음
NP          모름 (어려울 수 있음)            가능 (쉬움)                   '검산'이 쉽다는 것이 핵심
NP-Hard     불가능 혹은 모름 (매우 어려움)     모름 (검산마저 어려울 수 있음)   NP 문제들을 이 문제로 변형해서 풀 수 있음

```

5\. 환원, Reduction
--------------
```
다항 시간 환원(Polynomial-time Reduction): A라는 문제를 풀기 위해, 이 문제를 B라는 문제의 형태로 '변형'해서 B 알고리즘으로 해결하는 
                                         기법입니다. 
                                         이때 변형하는 데 걸리는 시간이 아주 짧아야(다항 시간) 합니다.
NP-Hard의 정의: 어떤 문제 $X$가 NP-Hard가 되려면, "모든 NP 문제를 다항 시간 안에 $X$ 문제로 환원(변형)할 수 있어야 한다"는 조건이 
               붙습니다. 즉, 
               $X$만 풀 줄 알면 모든 NP 문제를 다 마스터하는 셈이 되므로 가장 어려운 보스 몬스터 같은 존재가 되는 것입니다.
```

6\. 결정론적 튜링 머신(Deterministic Turing Machine, DTM)
--------------
```
1) "현재 상태"와 "읽고 있는 기호"가 주어졌을 때 다음에 해야 할 행동이 단 하나로 명확하게 정해져 있는 기계를 의미합니다.
2) 동작 규칙이 완전하게 결정되어 있습니다. 동일한 입력값과 동일한 상태에서는 언제 실행해도 항상 정확히 똑같은 과정을 거쳐 똑같은 
   결과를 냅니다.
```

7\. 비결정론적 튜링 머신(NTM)
--------------
```
한 상태에서 다음으로 넘어갈 수 있는 경로가 여러 개 존재하여, 동시에 여러 경로를 탐색하는 것처럼 동작하는 가상의 모델입니다.
```

8\. P vs NP
--------------
P: 현실 컴퓨터(DTM)로 빠르게 풀 수 있는 문제
NP: 가상 컴퓨터(NTM)로 빠르게 풀 수 있는 문제 (현실에서는 DTM으로 다항 시간 안에 검증할 수 있는 문제)
```
구분          "P (결정론적 튜링 머신, DTM)"                           "NP (비결정론적 튜링 머신, NTM)"
탐색 방식       순차 탐색 (일직선)매 순간 단 하나의 상태로만 진행          병렬/초능력 탐색 (트리 구조)매 순간 가능한 모든 경로로 
                                                                  동시에 분기
쉽게 비유하면     미로에서 벽을 따라 한 길씩 직접 걸어가며 출구를 찾는 사람   미로 갈림길마다 분신술을 써서 모든 길로 동시에 달려가는 사람
현실 비유       직접 문제를 푸는 과정(수도쿠 문제를 순서대로 계산해서 풀기)  답을 맞는지 확인하는 과정(누군가 적어준 수도쿠 정답이 맞는지 
                                                                  체크)
걸리는 시간      현실적인 컴퓨터로 빠르게 해를 구함                       초능력(분신술)으로 단 한 경로라도 해에 도달하면 성공
```
