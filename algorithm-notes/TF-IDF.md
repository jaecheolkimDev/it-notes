TF-IDF(Term Frequency - Inverse Document Frequency)
======================

1\. 개념
--------------
단어의 빈도(Frequency)와 희소성(가중치)을 결합하여 각 단어가 특정 문서 내에서 얼마나 중요한지를 점수로 매기는 알고리즘입니다.
```
단순히 단어가 많이 나온다고 해서 무조건 중요한 것이 아니라, "이 문서에서만 특별하게 자주 나오는가?"를 판단하는 것이 핵심입니다.
```

1\. TF (Term Frequency, 단어 빈도)
--------------
```
개념: 하나의 특정 문서 안에서 특정 단어가 얼마나 자주 등장하는지를 나타내는 값입니다.
특징: 당연히 문서 내에 단어가 많이 나올수록 중요도가 올라갑니다.
```

1\. IDF (Inverse Document Frequency, 역문서 빈도)
--------------
```
개념: 해당 단어가 전체 문서 군(Corpus)에서 얼마나 드물게 등장하는지를 나타내는 가중치입니다.
특징: 모든 문서에 흔하게 등장하는 단어(예: '그리고', '하지만', '을/를' 등)는 핵심어가 아닐 확률이 높으므로 감점(가중치 축소)을 줍니다. 
    반대로 특정 문서에만 집중적으로 등장하는 단어는 가점(가중치 확대)을 받습니다.
```
