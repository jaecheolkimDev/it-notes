P 문제
======================

1\. P 문제 (Polynomial)
--------------
"다항 시간(Polynomial time) 안에 쉽게 풀 수 있는 문제"
```
의미: 현실적인 시간 안(컴퓨터가 아주 빠르게)에 정답을 찾아낼 수 있는 정렬된 알고리즘이 존재하는 문제입니다.
특징: 보통 $O(n)$, $O(n^2)$, $O(n^3)$ 등의 다항 시간 복잡도를 가집니다.
예시: 알고리즘 알고 계시는 정렬(Sorting), 이진 탐색(Binary Search), 최소 신장 트리(MST) 찾기 등이 이에 해당합니다.
```

2\. NP 문제 (Nondeterministic Polynomial)
--------------
"힌트(답)가 주어졌을 때, 이게 정답인지 다항 시간 안에 확인(Verification)할 수 있는 문제"
```
의미: 직접 풀기에는 컴퓨터로 수백 년이 걸릴지 모르지만, 누군가 "이게 답이야"라고 가져왔을 때 그게 맞는지 틀린지 검산하는 것은 빠르게(다항 시간 안에) 
     할 수 있는 문제입니다.
주의: 'P가 아닌 문제(Not P)'가 아닙니다! 모든 P 문제는 당연히 검산도 빠르기 때문에 P 문제는 NP 문제에 포함(P ⊂ NP)됩니다. 컴퓨터 과학의 최대 난제 
     중 하나가 바로 "정말 풀기 쉬운 문제(P)와 검산만 쉬운 문제(NP)가 같은 집합일까? ($P = NP?$)" 하는 질문입니다.
예시: 스도쿠(직접 풀긴 어렵지만 채점은 쉬움), 암호 해독.
```

3\. NP-Hard 문제 (NP-난해)
--------------
"적어도 NP 문제만큼, 혹은 그보다 훨씬 어려운 문제들의 집합"
```
의미: "이 문제를 풀 수 있으면 모든 NP 문제를 다 풀 수 있다"고 할 정도로 악명 높은 난이도의 문제들입니다. 중요한 점은, NP-Hard 문제는 답을 주었을 때 
     맞는지 확인하는 것조차 다항 시간 안에 불가능할 수 있습니다. (즉, NP 집합에 속하지 않을 수도 있습니다.)
예시: 그 유명한 외판원 순회 문제(TSP, Traveling Salesperson Problem), 배낭 문제(Knapsack Problem)
```

4\. 비교
--------------
```
분류         직접 풀기 (다항 시간 내)          답 검산하기 (다항 시간 내)      특징
P           가능 (쉬움)                     가능 (쉬움)                   이미 효율적인 알고리즘이 많음
NP          모름 (어려울 수 있음)            가능 (쉬움)                   '검산'이 쉽다는 것이 핵심
NP-Hard     불가능 혹은 모름 (매우 어려움)     모름 (검산마저 어려울 수 있음)   NP 문제들을 이 문제로 변형해서 풀 수 있음

```

5\. 환원, Reduction
--------------
```
다항 시간 환원(Polynomial-time Reduction): A라는 문제를 풀기 위해, 이 문제를 B라는 문제의 형태로 '변형'해서 B 알고리즘으로 해결하는 기법입니다. 
                                         이때 변형하는 데 걸리는 시간이 아주 짧아야(다항 시간) 합니다.
NP-Hard의 정의: 어떤 문제 $X$가 NP-Hard가 되려면, "모든 NP 문제를 다항 시간 안에 $X$ 문제로 환원(변형)할 수 있어야 한다"는 조건이 붙습니다. 즉, 
               $X$만 풀 줄 알면 모든 NP 문제를 다 마스터하는 셈이 되므로 가장 어려운 보스 몬스터 같은 존재가 되는 것입니다.
```
