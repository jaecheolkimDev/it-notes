이진 탐색 트리(BST, Binary Search Tree)
======================

1\. 삭제 3가지 경우
--------------
```
1) 자식 노드가 없는 경우 (리프 노드 삭제)
 - 해당 노드를 메모리에서 그냥 제거하고, 부모 노드와의 연결을 끊습니다.
2) 자식 노드가 1개만 있는 경우
 - 삭제할 노드를 제거하고, 자신의 자식 노드를 자신의 부모 노드와 직접 연결합니다.
3) 자식 노드가 2개 모두 있는 경우
 - 삭제하려는 노드의 자리를 대체할 후계자 노드를 찾아서 BST의 성질이 유지되도록 해준다.
```
