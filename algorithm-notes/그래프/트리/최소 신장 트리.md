최소 신장 트리(Minimum Spanning Tree, MST)
======================

2\. 정의
--------------
```
신장 트리 중 간선 가중치의 합이 최소가 되는 트리입니다.
```

3\. 대표 활용 사례
--------------
```
도로망/통신망/전력망 설치 시 최소 비용으로 모든 지역 연결하기, 파이프라인 관로 설계 등
```

4\. 최소 신장 트리를 구하는 대표적인 알고리즘 2가지
--------------
MST를 찾는 알고리즘은 탐욕 알고리즘(Greedy Algorithm) 방식을 사용하며, 가장 유명한 두 가지 방법이 있습니다.
```
1) 크루스칼 알고리즘 (Kruskal's Algorithm)
핵심 개념: 간선(Edge) 중심으로 접근합니다.
동작 방식:
 - 그래프의 모든 간선을 가중치 오름차순(작은 순)으로 정렬합니다.
 - 가중치가 가장 작은 간선부터 순서대로 선택합니다.
 - 선택한 간선이 순환(Cycle)을 만드는지 확인합니다. (주로 Union-Find 알고리즘 활용)
 - 순환을 만들지 않는 간선만 트리에 추가하고, 선택된 간선의 수가 $N-1$개가 되면 종료합니다.
적합한 경우: 간선의 수가 적은 희소 그래프(Sparse Graph)에 유리합니다.

2) 프림 알고리즘 (Prim's Algorithm)
핵심 개념: 정점(Vertex) 중심으로 접근합니다.
구성 요소 : MST 집합{초기값 : 각 정점까지의 최소값(무한대) / 이전 정점(null)}, visited_정점, unvisted_정점
동작 방식:
 ① 'unvisited_정점'에 모든 정점을 담아둔다.
 ② 처음으로 시작할 하나의 정점을 선택해서 'visited_정점'으로 옮긴다.
 ② 'visited_정점'에 옮겨진 정점의 주위를 탐색해서 'MST 집합'의 최소값과 그에 맞는 이전정점으로 값을 바꿔준다.
 ③ 'unvisted_정점'에서 'visited_정점'으로 하나 옮기고 주위를 탐색한다.
 ⑤ 진행하면서 연결된 최소값이 찾아지면 'MST 집합'의 값들을 변경해준다.
 ⑥ 모든 정점이 'MST 집합'에 포함될 때까지 이를 반복합니다. (우선순위 큐/최소 힙 활용)
적합한 경우: 간선의 수가 많은 밀집 그래프(Dense Graph)에 유리합니다.
```

5\. 크루스칼 vs 프림
--------------
```
구분          크루스칼 (Kruskal)          프림 (Prim)
기준          간선(Edge) 위주             정점(Vertex) 위주
시간 복잡도      O(ElogE)                O(ElogV) (우선순위 큐 사용 시)
구현 방식       간선 정렬 + Union-Find      우선순위 큐(Min Heap)
```

6\. 다익스트라 vs 프림
--------------
```
구분          다익스트라 (Dijkstra)                    프림 (Prim)
목적          최단 경로 (Shortest Path)               최소 신장 트리 (MST)
최적화 대상    시작점부터 특정 정점까지의 총 누적 거리       현재 트리에 정점을 추가하는 단일 간선의 비용
기준          "d[u]+w(u,v) (누적 가중치)"              "w(u,v) (단일 간선 가중치)"
시작점         특정 시작점 하나가 반드시 지정됨            임의의 정점에서 시작 (결과는 동일)
음수 가중치     불가능 (벨만-포드 등 사용 필요)            불가능 (기본 알고리즘 기준)
```
