최대 유량(Maximum Flow) 문제
======================

1\. 정의
--------------
```
그래프의 간선을 단순한 '거리'나 '비용'이 아니라, "한 번에 보낼 수 있는 최대 용량(Capacity)"을 가진 통로로 해석하는 문제 유형입니다.
```

2\. 핵심 개념
--------------
```
1) 소스(Source, $S$)         : 유량이 시작되는 출발점
2) 싱크(Sink, $T$)           : 유량이 모이는 도착점
3) 용량(Capacity, $c(u, v)$) : 정점 $u$에서 $v$로 보낼 수 있는 최대 유량
4) 유량(Flow, $f(u, v)$)     : 실제로 간선을 통해 흐르고 있는 양
```

3\. 목표
--------------
```
소스($S$)에서 보내서 싱크($T$)에 도착할 수 있는 전체 유량의 최대 합을 구하는 것입니다.
```

4\. 지켜야 하는 3가지 규칙 (제약 조건)
--------------
```
1) 용량 제한   : 흐르는 유량은 간선의 용량을 초과할 수 없습니다. ($f(u, v) \le c(u, v)$)
2) 유량 보존   : 출발점($S$)과 도착점($T$)을 제외한 모든 중간 정점에서는 들어오는 유량의 합과 나가는 유량의 합이 같아야 합니다.
3) 유량 대칭성  : $u$에서 $v$로 유량이 흐르면, 반대 방향으로는 음의 유량이 흐르는 것으로 간주합니다. ($f(u, v) = -f(v, u)$)
```

5\. 직관적인 비유
--------------
```
1) 파이프 네트워크: 각 파이프마다 흘려보낼 수 있는 물의 최대 양(용량)이 정해져 있을 때, 수도꼭지(소스)에서 하수구(싱크)까지 시분당 최대 몇 리터의 물을 보낼 수 있는가?
2) 물류/교통망: 여러 도로 구간마다 시간당 최대로 통과할 수 있는 차량 수가 정해져 있을 때, A 도시에서 B 도시로 시간당 이동시킬 수 있는 최대 차량 수는 얼마인가?
```

6\. 대표적인 해결 알고리즘
--------------
```
1) 포드-풀커슨 (Ford-Fulkerson)     : DFS를 이용해 유량을 더 보낼 수 있는 경로(증가 경로)를 찾아 유량을 흘려보내는 기본 개념
2) 에드몬드-카프 (Edmonds-Karp)      : 포드-풀커슨 알고리즘을 BFS 기반으로 구현하여 시간 복잡도를 $O(V \cdot E^2)$로 보장하는 방식
3) 디닉 알고리즘 (Dinic's Algorithm): 레벨 그래프와 blocking flow 개념을 도입하여 $O(V^2 \cdot E)$에 해결하는 훨씬 빠른 알고리즘
```

7\. 실전 활용 (이분 매칭)
--------------
```
최대 유량 알고리즘은 단순히 물이나 차량을 보내는 문제 외에도, 이분 매칭(Bipartite Matching) 문제를 해결하는 데 강력하게 활용됩니다.
(예: $N$명의 작업자와 $M$개의 할 일이 있을 때, 최대 몇 명에게 일을 1개씩 배정할 수 있는가?)
```
