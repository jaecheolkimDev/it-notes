포드-풀커슨(Ford-Fulkerson) 알고리즘
======================

1\. 정의
--------------
이 알고리즘의 핵심은 "유량을 더 보낼 수 있는 경로를 계속 찾아서 보내고, 잘못 보낸 유량은 취소(음의 유량)할 수 있게 한다"입니다.
```
네트워크 유량 문제에서 소스(Source)에서 싱크(Sink)로 보낼 수 있는 최대 유량을 구하는 가장 기본적인 탐욕적(Greedy) 알고리즘입니다.
```

2\. 핵심 용어 및 개념
--------------
```
1) 잔여 용량 (Residual Capacity, $c_r(u, v)$)  : 간선에 추가로 더 흘려보낼 수 있는 남은 용량 ($c(u, v) - f(u, v)$)
2) 증가 경로 (Augmenting Path)                 : 소스에서 싱크까지 잔여 용량이 $0$보다 큰 간선들로만 이루어진 경로
3) 역간선 (Reverse Edge)                      : 원래 간선의 반대 방향으로 존재하는 가상의 간선. 유량을 취소(철회)할 수 있는 기회를 제공합니다.
```

3\. 역간선(Reverse Edge)이 필요한 이유
--------------
탐욕적(Greedy)으로 경로를 선택하다 보면 처음에 비효율적인 경로로 유량을 흘려보내는 실수를 할 수 있습니다.
```
1) 만약 $u \to v$ 방향으로 유량 $f$를 보내면, 반대 방향인 $v \to u$로 용량이 $f$인 역간선을 생성(또는 잔여 용량 추가)합니다.
2) 나중에 다른 경로가 $v \to u$ 역간선을 통해 유량을 보내게 되면, 이는 "기존에 $u \to v$로 보냈던 유량을 취소하고 다른 길로 돌아가게 만드는 효과"를 
   냅니다.
3) 역간선 덕분에 처음에 잘못된 경로를 선택했더라도 최적의 최대 유량을 찾아낼 수 있습니다.
```

4\. 알고리즘 동작 순서
--------------
```
1) 모든 간선의 유량 $f(u, v)$를 $0$으로 초기화합니다.
2) 증가 경로 탐색: 잔여 용량이 남은 간선들만 이용해서 소스($S$)에서 싱크($T$)로 가는 경로(증가 경로)를 찾습니다. (주로 DFS 사용)
3) 유량 결정: 찾은 경로 상의 간선들 중 가장 작은 잔여 용량(병목 값, Bottleneck)을 구합니다.
4) 유량 갱신:
    경로 상의 모든 정방향 간선에는 병목 값을 더합니다 ($f(u, v) += bottleneck).
    경로 상의 모든 역방향 간선에는 병목 값을 뺍니다 ($f(v, u) -= bottleneck).
5) 소스에서 싱크로 가는 증가 경로가 더 이상 없을 때까지 2~4 과정을 반복합니다.
```

5\. 시간 복잡도
--------------
$O(E \cdot f_{max})$ ($E$: 간선 수, $f_{max}$: 최대 유량 값)
```
DFS로 증가 경로를 찾을 때 매번 유량이 최소 $1$씩 증가한다고 가정하면, 최대 유량 $f_{max}$번 만큼 탐색을 반복할 수 있습니다.
```

6\. 단점
--------------
```
유량의 크기 $f_{max}$에 의존하므로, 간선 가중치가 매우 크다면 탐색 횟수가 폭증할 수 있습니다.
DFS로 경로를 찾을 때 최악의 경우 1씩 주고받는 과정을 수천~수만 번 반복하는 핑퐁 현상이 발생할 수 있습니다.
```

7\. 보완
--------------
```
포드-풀커슨의 이러한 단점을 보완하기 위해 DFS 대신 BFS를 사용하여 항상 가장 짧은 간선 수의 증가 경로를 찾는 방식이 바로 
에드몬드-카프(Edmonds-Karp) 알고리즘($O(V \cdot E^2)$)입니다.
```
