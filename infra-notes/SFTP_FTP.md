SFTP/FTP 클라이언트 프로그램 공부 노트
======================

1\. 종류
--------------
```
WinSCP 또는 FileZilla 설치 (GUI 방식)
```

2\. PuTTY에서 접속하기   : 로컬에서 PuTTY를 실행합니다. (최신 버전)
--------------
```
   Host Name (or IP address): 127.0.0.1 입력
   Port: VirtualBox에서 설정한 호스트 포트인 2222 입력
   Connection type: SSH 선택
   [Open] 클릭
   보안 경고 창이 뜨면 [Accept]를 누르고, 가상 머신의 계정과 비밀번호를 입력하여 로그인합니다.
```
