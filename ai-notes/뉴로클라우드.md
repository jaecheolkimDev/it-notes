뉴로클라우드(Neurocloud)
======================

6\. 정의
--------------
```
네이버클라우드(NAVER Cloud)가 제공하는 고객 전용 완전 관리형 하이브리드 클라우드 서비스입니다.
```

6\. 유사성
--------------
```
1) AWS의 Outposts
2) MS Azure의 Stack
3) Google Cloud의 Anthos/Distributed Cloud
```

6\. 주요 특징 및 구조
--------------
```
1) 고객 전용 물리 인프라 구축     : 고객사의 전산실이나 데이터센터 내부에 네이버클라우드의 인프라 장비(랙)를 직접 설치하여 전용 
                                클라우드 환경을 조성합니다.
2) 원격 완전 관리형 운영         : 하드웨어 관리, OS 업데이트, 클라우드 플랫폼 모니터링 및 패치 등 제반 관리를 네이버클라우드가 
                                원격으로 직접 수행하므로, 인프라 운영 부담을 줄일 수 있습니다.  
3) 강력한 데이터 보안 및 규제 준수 : 민감한 사내 데이터가 외부 네트워크로 유출되지 않고 고객의 물리적 공간 내부에서 처리·저장되므로, 
                                금융·공공·제조 분야의 엄격한 데이터 망분리 및 컴플라이언스를 만족합니다.  
4) 기존 Legacy 시스템과의 연동   : 사내망(On-Premise)에 위치하므로 기존에 운용 중이던 사내 데이터베이스나 레거시 시스템과 
                                저지연(Low Latency)으로 유연하게 연동됩니다. 
```

6\. 제공 형태
--------------
```
1) Rack 타입              : 고객이 이미 보유한 데이터센터나 전산실 내부 공간에 네이버클라우드가 전용 랙과 하드웨어, 스토리지, 
                            네트워크 장비를 설치하여 제공합니다.  
2) Rack + 데이터센터 타입  : 별도의 전산 공간이 없는 기업을 위해 컨테이너 방식의 전용 모듈형 데이터센터(공냉식 시설 포함)와 인프라 
                            장비를 함께 구축해 줍니다.  
```

6\. Neurocloud for HyperCLOVA X (AI 특화형)
--------------
네이버의 초대규모 AI 모델인 HyperCLOVA X를 사내 폐쇄망 환경에서 안전하게 활용할 수 있도록 최적화된 라인업입니다.
```
1) 사내 데이터 보호    : 기업 고유 데이터를 AI 학습 및 추론에 활용하더라도 외부 퍼블릭 클라우드로 전송되지 않고 사내 뉴로클라우드 
                        인프라 안에서 처리됩니다.  
2) 특화 AI 모델 구축  : 기업 전용 도메인 지식을 학습시킨 맞춤형 LLM을 구축 및 운영할 수 있도록 지원합니다.
```

6\. 주요 활용 사례
--------------
```
도입 기관/기업                    주요 목적 및 효과
금융권 (IBK기업은행, 한국은행 등)   금융 보안 규제(망분리)를 준수하면서 클라우드 자원을 유연하게 생성·테스트하고, 자체 대규모 
                                언어모델(LLM) 환경 구축
공공기관 및 지자체                  데이터 역외 유출 방지 및 보안 요건을 만족하는 공공용 하이브리드 클라우드 인프라 확보
제조/대기업                      공장 시설 내 저지연 데이터 처리가 필요한 스마트 팩토리 인프라 및 핵심 R&D 자산 보호
```
