멀티 에이전트(Multi-Agent) 또는 멀티 에이전트 시스템(MAS, Multi-Agent System)
======================

1\. 개념
--------------
혼자서 기획, 개발, 디자인, 마케팅을 다 하는 1인 기업이 아니라 각 분야의 전문가들이 모여 있는 ‘팀(Team)’ 구조로 AI를 운영하는 것입니다.
```
하나의 거대한 인공지능이 모든 일을 처리하는 것이 아니라, 특정 목표나 전문 분야를 가진 여러 개의 AI 에이전트(Agent)들이 서로 협력하고 소통하며 
복잡한 문제를 해결하는 시스템을 의미합니다.
```

2\. 작동 방식
--------------
멀티 에이전트 시스템에서는 각 에이전트가 고유한 역할(Role), 페르소나, 그리고 사용할 수 있는 도구(Tool)를 부여받습니다.
```
역할 분담: 예를 들어 소프트웨어를 개발하는 프로젝트라면 다음과 같이 에이전트를 구성할 수 있습니다.
    요구사항 분석 에이전트: 사용자의 질문을 분석해 기능 목록을 만듦.
    코딩 에이전트: 기능 목록을 바탕으로 실제 소스 코드를 작성함.
    리뷰 에이전트: 작성된 코드에 버그가 없는지 검토하고 피드백을 줌.
협력과 피드백: 코딩 에이전트가 코드를 짜서 리뷰 에이전트에게 보내면, 리뷰 에이전트는 감시자 역할을 하며 "이 부분에 보안 취약점이 있으니 수정해줘"라고 
            요청합니다. 이 과정이 인간의 개입 없이 AI들끼리 자동으로 오고 갑니다.
```

3\. 주요 장점
--------------
```
1) 복잡한 작업 수행 가능     : 하나의 LLM(대형 언어 모델)에게 "내 비즈니스 아이디어를 바탕으로 앱을 개발하고 마케팅 플랜까지 짜줘"라고 하면 답변의 
                        퀄리티가 떨어지거나 중간에 길을 잃기 쉽습니다. 하지만 이를 쪼개어 전문가 에이전트들에게 맡기면 훨씬 정교한 결과물이 나옵니다.
2) 할루시네이션(환각 현상) 감소: 에이전트끼리 서로의 결과물을 검증(Cross-checking)하고 교정하는 단계를 거치기 때문에, AI가 거짓말을 하거나 오류를 내는 
                            확률이 크게 줄어듭니다.
3) 확장성(Scalability)     : 새로운 기능이 필요하면 해당 능력을 가진 에이전트를 팀에 추가하기만 하면 되므로 시스템 확장이 유연합니다.
```

4\. 대표 프레임워크
--------------
```
CrewAI, AutoGen(마이크로소프트), LangGraph 등이 있으며, 개발자들은 이를 활용해 자신만의 AI 팀을 빌드합니다.
```
