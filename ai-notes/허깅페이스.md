Hugging Face(허깅페이스)
======================

1\. 오픈소스 AI 커뮤니티 플랫폼
--------------
```
전 세계 AI 개발자들과 연구원들이 가장 많이 방문하고 사용하는 "AI 업계의 깃허브(GitHub)"이자 오픈소스 AI 커뮤니티 플랫폼입니다.

"누구나 자유롭게 AI 모델을 올리고, 다운받고, 테스트해 볼 수 있는 거대한 AI 시장이자 놀이터"라고 보시면 됩니다.
```

2\. 허깅페이스의 3대 핵심 메뉴
--------------
웹사이트(huggingface.co)에 들어가면 전 세계 모든 오픈소스 AI가 이곳에 모여 있다는 것을 알 수 있습니다.
```
Models (모델 허브): 메타의 Llama(라마), 구글의 Gemma(젬마) 같은 거대 언어 모델(LLM)부터, 이미지 생성 AI(Stable Diffusion), 음성 인식, 
                    임베딩 모델 등 수십만 개의 AI 모델이 오픈소스로 무료로 공유되어 있습니다. 누구나 무료로 다운로드해서 내 컴퓨터나 서버에 올릴 
                    수 있습니다.

Datasets (데이터셋 허브): AI를 학습시키거나 테스트할 때 필요한 고품질의 데이터셋(텍스트, 이미지, 오디오 등)이 수만 개 넘게 모여 있는 저장소입니다.

Spaces (스페이스): 코드를 내 컴퓨터에 다운받지 않아도, 다른 개발자가 만든 AI 모델을 웹 브라우저에서 마우스 클릭만으로 직접 데모 테스트해 볼 수 있는 
                    공유 웹 호스팅 공간입니다.
```

3\. transformers 라이브러리
--------------
```
허깅페이스가 지금의 위치에 있게 된 일등 공신은 그들이 만든 오픈소스 라이브러리인 transformers입니다.

원래 서로 다른 AI 모델(구글, 페이스북, 오픈AI 계열 등)을 가져다 쓰려면 코드가 제각각이라 아주 복잡했습니다. 하지만 허깅페이스가 이것을 전 세계 
표준처럼 단 몇 줄의 코드로 통일해 버렸습니다.
이 라이브러리 덕분에 전 세계 AI 개발 장벽이 획기적으로 낮아졌습니다.
    
    Python
        from transformers import pipeline
        
        # 허깅페이스에 있는 수많은 감정 분석 모델 중 하나를 코드 2줄로 가져와서 바로 실행!
        classifier = pipeline("sentiment-analysis")
        result = classifier("허깅페이스 진짜 편하고 좋네!")
        print(result) # [{'label': 'POSITIVE', 'score': 0.999}]

```

4\. RAG 파이프라인과의 연결고리
--------------
```
RAG와 어떻게 연결되는지 매칭해 보면 AI 생태계 지도가 완성됩니다.
허깅페이스에서 내 서비스에 딱 맞는 '임베딩 모델'과 '오픈소스 LLM(예: Upstage Solar 계열 등)'을 고르고 다운로드합니다.
다운로드한 임베딩 모델로 회사 문서를 숫자로 바꿔 Chroma나 Pinecone 같은 벡터 DB에 저장합니다 (R).
프롬프트를 조립해서 (A) 다운로드한 LLM 모델에 던져 답변을 만듭니다 (G).
이 전체 과정이 잘 굴러가는지 LangSmith로 모니터링합니다.
```

5\. AI 계의 거대한 앱스토어이자 플랫폼
--------------
```
전 세계의 오픈소스 AI 모델과 데이터셋이 모여 있는 AI 계의 거대한 앱스토어이자 플랫폼이며, 
코드 몇 줄로 모든 AI를 쉽게 다룰 수 있게 해주는 라이브러리를 제공하는 AI 개발의 중심지입니다.

최근에는 AI 모델뿐만 아니라 딥러닝 연산을 가속화하는 다양한 오픈소스 도구와 클라우드 서빙 서비스까지 제공하면서 전 세계 AI 개발 환경을 리드하고 
있습니다.
```
