옵티마이저(Optimizer)
======================

4\. 정의
--------------
```
가중치(Weight)와 편향(Bias) 같은 모델의 매개변수(Parameter)를 조절하여, 손실 함수(Loss Function)의 값을 최소화하는 최적의 
매개변수를 찾아가는 알고리즘입니다.

비유) 인공지능 학습을 "안개가 자욱한 산(손실 함수)에서 가장 지대가 낮은 골짜기(최적의 정답)를 찾아 내려가는 과정"에 비유한다면, 
     옵티마이저는 하산하는 전략이나 이동 수단에 해당합니다.
```

5\. 주요 역할 및 핵심 개념
--------------
```
1) 경사하강법(Gradient Descent): 손실 함수의 기울기(Gradient)를 구한 뒤, 기울기가 낮아지는 반대 방향으로 매개변수를 업데이트합니다.
2) 학습률(Learning Rate, $\eta$): 한 번에 얼마나 큰 걸음으로 이동할지 결정하는 하이퍼파라미터입니다.
 - 너무 크면: 최적점을 지나쳐 발산할 수 있습니다.
 - 너무 작으면: 최적점에 도달하는 데 시간이 너무 오래 걸립니다.
```

6\. 옵티마이저의 발전 흐름 및 분류
--------------
옵티마이저는 기존 알고리즘의 한계(속도, 국소 최솟값 갇힘 등)를 극복하며 발전해 왔습니다.
```
SGD (기본 경사하강법)
 ├── 관성(Momentum) 추가 계열 ──────────────► Momentum ──┐
 └── 학습률 적응(Adaptive Rate) 계열 ──► Adagrad ──► RMSprop ┴─► Adam (통합형)
                                                                 └──► AdamW (개선형)
```

6\. 기본 경사하강법 계열
--------------
```
SGD (Stochastic Gradient Descent, 확률적 경사하강법)
 - 전체 데이터 대신 일부 데이터(Batch/Mini-batch)만 사용하여 기울기를 계산하고 업데이트합니다.
 - 장점: 계산량이 적고 빠른 업데이트가 가능합니다.
 - 단점: 진동(Oscillation) 현상이 심해 최적점 도달 속도가 느리며, 국소 최솟값(Local Minimum)이나 안장점(Saddle Point)에 
        갇히기 쉽습니다.
```

6\. 관성(Momentum) 기반 계열
--------------
```
1) Momentum
 - 이전 단계의 기울기 방향을 기억해 관성(가속도)을 부여합니다.
 - 장점: 지그재그 흔들림을 줄이고, 국소 최솟값을 관성으로 탈출할 수 있습니다.
2) NAG (Nesterov Accelerated Gradient)
 - 관성 방향으로 미리 이동한 지점의 기울기를 계산하여 속도를 조절하는 예측형 관성 방식입니다.
```

6\. 학습률 적응(Adaptive Learning Rate) 계열
--------------
```
1) Adagrad
 - 많이 변화한 매개변수의 학습률은 낮추고, 적게 변화한 매개변수의 학습률은 높입니다.
 - 단점: 학습이 진행될수록 학습률이 0에 수렴하여 더 이상 학습되지 않는 문제가 발생합니다.
2) RMSprop
 - Adagrad의 학습률 급감 문제를 해결하기 위해 지수 이동 평균(EMA)을 도입하여 최근 기울기 변화량을 중심으로 반영합니다.
```

6\. 복합 및 최신 계열
--------------
```
1) Adam (Adaptive Moment Estimation)
 - Momentum(관성)과 RMSprop(학습률 적응)의 장점을 결합한 현재 가장 대표적이고 널리 사용되는 옵티마이저입니다.
 - 기울기의 1차 모멘트(평균)와 2차 모멘트(분산)를 함께 활용합니다.
 - 대부분의 일반적인 문제에서 무난하고 뛰어난 성능을 보입니다.
2) AdamW
 - Adam에 Weight Decay(가중치 감쇠) 처리를 올바르게 결합하여 일반화(Generalization) 성능 및 과적합 방지 효과를 크게 개선했습니다. 
   (LLM 및 최신 딥러닝 트랜스포머 모델 학습의 표준)
```

6\. 주요 옵티마이저 요약 비교
--------------
```
옵티마이저   주요 특징                       장점                          단점/주의사항
SGD         무작위 샘플 기반 기울기 계산        가볍고 단순함                 "진동 심함, 안장점에 갇힘"
Momentum    이전 기울기의 관성 반영           "진행 방향 가속, 진동 감소"       하이퍼파라미터 증가
RMSprop     최근 기울기 변화 반영 학습률 조절     변동성이 큰 데이터에 효과적     하이퍼파라미터 튜닝 필요
Adam        Momentum + RMSprop 결합       "빠른 수렴, 범용성 우수"         특정 상황에서 일반화 성능 감소 가능
AdamW       Adam + 올바른 Weight Decay     최고 수준의 일반화 성능 제공    트랜스포머/LLM 학습 표준
```

6\. 상황별 옵티마이저 선택 가이드
--------------
```
1) 우선 선택 / 표준: 무슨 옵티마이저를 써야 할지 모를 때는 Adam 또는 AdamW를 기본으로 사용합니다.
2) 컴퓨터 비전(CNN 계열): 가끔 미세한 튜닝 성능 향상을 위해 SGD + Momentum이 사용되기도 합니다.
3) 자연어 처리 및 최신 트랜스포머(LLM): AdamW가 사실상 표준으로 사용됩니다.
```

6\. AI 옵티마이저 vs DB 옵티마이저 비교
--------------
```
구분      AI / 딥러닝 옵티마이저                                  DB 옵티마이저 (Query Optimizer)
핵심 목적   손실 함수(오차)를 최소화하는 최적의 가중치(Weight) 탐색     쿼리(SQL)를 가장 빨리 처리할 최적의 실행 계획(Execution Plan) 수립
최적화 대상  "인공신경망의 매개변수 (가중치, 편향)"                 "데이터 조회 경로 (인덱스 타기, 풀 스캔, 조인 순서 등)"
주요 기준   Loss(오차) 및 Gradient(기울기)                        "Cost(비용) (CPU 사용량, I/O 비용, 카디널리티 등)"
주요 방식   "경사하강법 기반 (Adam, SGD, RMSprop 등)"           "RBO(비용 기반), CBO(비용 기반 최적화) 등"
실행 시점   모델을 학습(Training)시키는 과정 내내                   작성된 SQL 문이 실행되기 바로 직전
```
