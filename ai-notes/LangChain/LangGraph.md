LangGraph
======================


1\. LangGraph
--------------
LangChain을 만든 회사(LangChain Inc.)에서 개발한, 복잡한 AI 에이전트(Agent)와 다중 에이전트(Multi-Agent) 시스템을 구축하기 위한 고급 프레임워크
```
```

2\. LangChain과 차이점
--------------
```
LangChain이 일직선상의 사슬(Chain)처럼 순차적으로 일을 처리하는 데 강점이 있다면, 
LangGraph는 "일을 하다가 되돌아가기도 하고, 조건에 따라 뺑뺑이(루프)를 돌기도 하는 복잡한 흐름"을 제어하기 위해 태어났습니다.
```

3\. 탄생 배경
--------------
```
"상태를 기억하고, 결과에 따라 이전 단계로 되돌아가거나(Loop), 조건에 따라 분기하는 복잡한 에이전트"를 만들려고 하니 
기존의 LangChain 구조로는 코드가 너무 복잡해지고 제어하기가 힘들었습니다. 이를 완벽하게 해결하기 위해 나온 것이 LangGraph입니다.
```

4\. 핵심 개념 (그래프 구조)
--------------
```
1) 노드 (Nodes): 에이전트가 수행하는 '구체적인 행동이나 작업'입니다. (예: 인터넷 검색하기, 글 작성하기, 코드 검수하기) Python 함수 형태로 정의됩니다.
2) 엣지 (Edges): 노드와 노드를 연결하는 '이동 경로'입니다. 다음 단계로 그냥 넘어가는 일반 엣지도 있지만, "결과물이 통과(Pass)면 완료 노드로 가고, 
                실패(Fail)면 수정 노드로 가라"와 같은 '조건부 엣지(Conditional Edges)'가 핵심입니다.
3) 상태 (State): 그래프 전체를 공유하는 '중앙 메모리'입니다. 에이전트들이 대화한 기록, 조사한 데이터, 현재 작업 단계 등의 데이터를 상태(State)에 
                저장하고, 모든 노드가 이 상태를 읽고 업데이트하며 협업합니다.
```

5\. 핵심 장점
--------------
```
1) 루프(Loop)와 사이클(Cycle)의 완벽한 지원: AI가 스스로 만족할 만한 결과가 나올 때까지 [생성 ➡️ 검수 ➡️ 보완 ➡️ 재검수] 과정을 무한히 반복하도록 
                                        정교하게 제어할 수 있습니다.
2) 지속성 (Persistence / 내장 메모리): 작업 도중 에이전트의 상태를 자동으로 저장(체크포인트)합니다. 덕분에 중간에 에러가 나도 처음부터 다시 할 필요 없이 
                                    멈춘 지점부터 재시작할 수 있고, 사용자가 중간에 개입(Human-in-the-loop)하여 AI의 생각을 교정해 줄 수도 있습니다.
3) 다중 에이전트(Multi-Agent) 최적화: "기획자 AI", "개발자 AI", "QA AI"를 각각 노드로 만들고, 이들이 서로 의견을 주고받으며 하나의 완벽한 결과물을 
                                    만들어내는 협업 시스템을 구축하기에 가장 좋습니다.
```
