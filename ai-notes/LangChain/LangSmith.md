LangSmith(랭스미스)
======================

1\. LLMOps(LLM 운영 및 관리) 플랫폼
--------------
```
LLM(대형 언어 모델)을 활용한 애플리케이션이나 AI 에이전트를 만들 때 사용하는 대표적인 LLMOps(LLM 운영 및 관리) 플랫폼입니다. 
유명한 오픈소스 LLM 프레임워크인 LangChain(랭체인)을 만든 회사에서 제공하는 서비스이기도 합니다.

RAG 파이프라인(문서 검색 ➡️ 프롬프트 조립 ➡️ AI 답변 생성)을 코드로 짜서 실행했을 때 내부에서 정확히 어떤 일이 일어나는지 엑스레이(X-ray)처럼 
투명하게 들여다볼 수 있게 해주는 도구라고 이해하시면 됩니다.
```

2\. 추적 및 디버깅 (Observability & Tracing)
--------------
```
RAG나 복잡한 체인(Chain)을 구성하면 "사용자 질문 ➡️ 임베딩 ➡️ 벡터 DB 검색 ➡️ 프롬프트 결합 ➡️ LLM 호출"까지 수많은 단계가 한 번에 일어납니다. 
만약 결과가 이상하게 나오면 대체 어디가 고장 났는지 알기 어렵습니다.

LangSmith는 이 모든 과정을 시각적인 트리 구조(Trace)로 보여줍니다.

각 단계별 어디서 문제가 생겼는지, 각 단계별로 시간이 얼마나 걸렸는지(Latency), 토큰은 몇 개나 썼고 비용은 얼마인지 실시간으로 추적해 줍니다.

```

3\. 테스트 및 자동 평가 (Evaluation)
--------------
``` 
AI의 답변은 정해진 정답(예: 숫자나 딱 맞는 글자)이 없는 경우가 많아 잘 만들어졌는지 검증하기 어렵습니다. LangSmith는 이를 해결하기 위해 테스트 
데이터셋 관리 및 자동 평가 기능을 제공합니다.

개발자가 프롬프트나 모델을 수정했을 때, 기존보다 성능이 좋아졌는지 나빠졌는지 수십~수백 개의 테스트 케이스를 돌려 사이드 바이 사이드(Side-by-side)로 
결과와 품질을 비교할 수 있습니다.

LLM-as-a-judge (판사로서의 LLM): 다른 똑똑한 LLM(예: GPT-4)을 판사로 세워, 우리 서비스가 내놓은 답변이 기준에 부합하는지 자동으로 채점하게 만들 
                                 수도 있습니다.
```

4\. 프롬프트 허브 (Prompt Hub)
--------------
```
코드 안에 하드코딩되어 있던 복잡한 프롬프트들을 LangSmith 웹 대시보드에서 따로 모아 버전 관리를 할 수 있습니다. 코드 수정과 배포 없이도 웹에서 
프롬프트를 고치고 테스트한 뒤 바로 서비스에 반영할 수 있어 협업하기가 매우 편해집니다.
```

5\. 프로덕션 모니터링 (Monitoring)
--------------
```
서비스를 실제 출시(Production)하고 나면, 사용자들이 AI와 어떤 대화를 나누는지, 에러율은 얼마나 되는지, 오늘 쓴 비용은 얼마인지 모니터링해야 합니다. 
LangSmith는 대시보드를 통해 실시간 사용량과 사용자들의 피드백(좋아요/싫어요 등)을 한눈에 시각화해 줍니다.
```

6\. LLM 개발 필수 백오피스 프로그램
--------------
```
눈에 보이지 않는 AI 시스템의 내부 동작(RAG, 에이전트 등)을 투명하게 시각화하여, 디버깅·테스트·비용 모니터링·프롬프트 관리를 한곳에서 해결해 주는 
LLM 개발 필수 백오피스 프로그램입니다.

보통 Python이나 TypeScript 코드 상단에 환경변수 몇 줄만 적어두면 자동으로 연동되기 때문에, RAG 시스템을 고도화할 때 개발자들이 무조건 켜놓고 
시작하는 치트키 같은 도구입니다.
```
