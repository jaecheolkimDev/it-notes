2\. 핵심 기능
--------------
```
1) 컴포넌트 (Components): LLM을 다루기 위한 추상화된 도구들을 제공합니다. (예: 프롬프트 템플릿, 모델 연결, 출력 형식 지정 등)
2) 체인 (Chains): 여러 개의 컴포넌트나 AI 작업을 사슬(Chain)처럼 연결합니다. 예를 들어 
                  [사용자 질문] -> [데이터베이스 검색] -> [AI가 요약] -> [답변 출력]의 과정을 하나의 체인으로 묶어 실행할 수 있습니다.
3) 데이터 연결 (Data Connection): PDF, 메모장, SQL 데이터베이스, 웹사이트 등 외부 데이터를 AI가 읽고 이해할 수 있도록 가져오고 
                                분할하여 저장(Vector DB)하는 과정을 도와줍니다. (RAG 패턴 구현의 핵심)
4) 에이전트 (Agents): AI가 스스로 판단하여 "이 질문은 인터넷 검색이 필요해", "이 질문은 계산기를 써야겠어"처럼 어떤 도구(Tool)를 사용할지 결정하고 
                    행동하게 만듭니다.
5) 메모리 (Memory): 대화의 흐름을 기억하게 하여, 이전 대화 내용을 바탕으로 답변할 수 있도록 돕습니다.
```

3\. 주요 장점
--------------
```
1) 모델 독립성 (Flexibility): OpenAI(ChatGPT), Anthropic(Claude), Google(Gemini) 등 다양한 AI 모델을 지원합니다. 
                            코드 몇 줄만 바꾸면 AI 모델을 쉽게 교체할 수 있습니다.
2) 복잡한 워크플로우 구현: AI에게 단순히 한 번 물어보는 것이 아니라, 순차적으로 생각을 프로세싱해야 하는 복잡한 비즈니스 로직을 쉽게 짤 수 있습니다.
3) 풍부한 생태계: 파이썬(Python)과 자바스크립트/타입스크립트(JavaScript/TypeScript)를 모두 지원하며, 전 세계 수많은 개발자들이 오픈소스로 
                참여하고 있어 업데이트가 매우 빠릅니다.
```

4\. 주요 생산물
--------------
```
1) 기업 내부 문서 기반 QA 챗봇: 회사의 규정집이나 매뉴얼(PDF 등)을 학습시켜 직원들이 질문하면 답변해 주는 시스템
2) 데이터 분석 및 보고서 자동 생성: DB에서 데이터를 뽑아 AI에게 분석을 시키고 보고서 양식으로 출력하는 도구
3) AI 에이전트: 사용자의 메일을 읽고, 중요도를 분류한 뒤, 자동으로 답장 초안까지 작성해 주는 비서 서비스
```

5\. 로컬 AI + 랭체인 시작하기
--------------
```
1) Python 설치
2) Ollama로 AI 모델 다운로드 받기
    $ ollama run llama3
3) 파이썬 프로젝트 폴더 및 가상환경 만들기
    - 가상환경 생성 (폴더 이름은 .venv)
        $ python -m venv .venv
    - 윈도우에서 가상환경 활성화
        $ .venv\Scripts\activate
4) 필수 라이브러리 설치하기
    $ pip install langchain langchain-community
5) 랭체인 코드 작성 및 실행
    $ python app.py
```

6\. 랭체인 숙련도 올리기
--------------
```
1단계: LCEL (LangChain Expression Language)과 프롬프트 템플릿
    실제 개발에서는 사용자 입력값에 따라 질문이 변해야 하겠죠? 랭체인은 이를 위해 프롬프트 템플릿을 제공하고, 자바의 스트림(Stream) 연산자나 기능적 
    체이닝처럼 | (파이프) 기호를 사용해 컴포넌트를 엮는 LCEL 방식을 씁니다.
    * **학습 포인트:** 데이터를 정제하고 모델에 흘려보내는 파이프라인(`|`) 개념 익히기
2단계: 대화의 맥락 기억하기 (Memory & Chat History)
    LLM은 원래 단발성(Stateless)입니다. 앞의 질문을 기억하지 못하죠. 자바에서 로그인 세션(Session)이나 Redis를 활용해 상태를 유지하듯, 랭체인에서는 
    `ChatHistory` 컴포넌트를 사용해 과거 대화 내역을 배열(List) 형태로 보관했다가 다음 질문 때 AI에게 함께 넘겨줍니다.
    * **학습 포인트:** AI와 카카오톡처럼 주고받는 대화형 챗봇의 백엔드 로직 구현하기
3단계: RAG (Retrieval-Augmented Generation, 검색 증강 생성)
    **자바 개발자에게 가장 익숙하면서도 실무에서 90% 이상 쓰는 패턴입니다.** 
    AI는 최신 정보나 회사 내부 문서(DB, PDF 등)를 모릅니다. 사용자가 질문을 던지면, 백엔드에서 관련 문서를 DB(Vector DB)에서 조회(Retrieve)해 온 뒤, 
    그 내용을 질문과 함께 AI에게 넘겨 답변을 받아내는 기술입니다.

* **자바 아키텍처와 매칭하기:**
  * **Repository / DAO 역할:** `VectorStore` (텍스트를 벡터로 저장하는 DB)
  * **Service 로직 역할:** `Retriever` (질문과 유사한 문서를 찾아오는 객체)

파이썬 코드로 구조를 먼저 이해해 보고 싶으신가요, 아니면 익숙한 자바(Spring Boot) 환경에서 AI 코드를 짜는 법을 바로 보고 싶으신가요?
```
