AI MCP 공부 노트
======================


1\. MCP(Model Context Protocol, 모델 컨텍스트 프로토콜)
--------------
AI 모델(LLM)이 외부 데이터나 도구(API, 데이터베이스, 파일 시스템 등)와 안전하고 일관되게 소통할 수 있도록 해주는 오픈소스 오픈 표준 프로토콜입니다.


2\. 필요성
--------------
```
과거 방식 (파편화): Claude용 커넥터, ChatGPT용 커넥터, Cursor IDE용 커넥터를 각각 따로 개발해야 했습니다. 서비스가 $N$개고 AI 모델이 $M$개라면 
                    총 $N \times M$개의 커넥터를 일일이 다 만들어야 하는 끔찍한 비효율이 발생했죠.
MCP 방식 (표준화): 마치 스마트폰, 노트북, 충전기가 USB-C 규격 하나로 통일된 것처럼, 데이터 소스나 도구를 MCP 서버(MCP Server) 표준에 맞춰 한 번만 
                개발해 두면, Claude, ChatGPT, Cursor 등 MCP 클라이언트(MCP Client) 규격을 따르는 모든 AI 모델이 복잡한 추가 개발 없이 바로 
                그 도구를 가져다 쓸 수 있습니다. ($N + M$ 구조로 단순화)
```

3\. 핵심 요소
--------------
MCP 규격을 활용하면 AI 모델에게 크게 세 가지 형태의 능력을 규격화해서 전달할 수 있습니다.
```
1) 프롬프트 (Prompts): AI에게 줄 수 있는 사전 정의된 템플릿(슬래시 명령어 같은 것)을 표준화된 방식으로 제공합니다.
2) 리소스 (Resources): 로컬 파일, DB 데이터, API 응답 등 AI가 답변을 생성할 때 참고해야 하는 '읽기 전용 데이터'를 안전하게 모델에게 전달합니다.
3) 도구 (Tools): AI가 직접 실행할 수 있는 '함수나 액션'을 제공합니다. (예: "이 코드를 직접 실행해 줘", "DB에 데이터를 업데이트해 줘" 등)
```
