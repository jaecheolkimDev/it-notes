1\. 갱신형 vs 비갱신형
--------------
```
구분              갱신형                                 비갱신형
초기 보험료      매우 저렴함                              비교적 비쌈
보험료 변동      "갱신 주기(예: 3년, 5년)마다 인상됨"        만기까지 처음 낸 보험료 그대로
납입 기간       보장을 받는 만기까지 평생 납입               정해진 기간(예: 20년)만 납입
총 납입 보험료    장기 유지 시 비갱신형보다 많아질 수 있음     총액이 확정되어 있어 예측 가능함
```
