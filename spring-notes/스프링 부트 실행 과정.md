스프링 부트(Spring Boot)의 실행 과정
=================

1\. 실행 과정
------------------
핵심은 @SpringBootApplication 어노테이션과 SpringApplication.run() 메서드입니다.
```
1) 애플리케이션 시작 준비
2) 스프링 컨테이너(ApplicationContext) 생성 및 초기화
3) 내장 웹 서버 실행의 3단계로 진행됩니다.
```

2\. @SpringBootApplication 어노테이션의 핵심 역할
------------------
이 어노테이션 하나가 실행에 필요한 3개 핵심 어노테이션을 합쳐놓은 종합 선물세트입니다.
```
1) @SpringBootConfiguration: 클래스를 스프링의 설정 파일(Configuration)로 지정합니다.
2) @EnableAutoConfiguration: 스프링 부트의 ‘자동 설정(Auto-Configuration)’ 핵심 기능입니다. META-INF/spring.factories 
                            또는 최근 버전의 META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration
                            .imports 파일에 정의된 수많은 자동 설정 클래스들을 불러와 빈(Bean)을 자동으로 등록합니다. 
                            (예: spring-boot-starter-web 패키지가 있으면 Tomcat과 MVC 설정을 자동으로 완료)
3) @ComponentScan           : 메인 클래스가 위치한 패키지를 시작점으로, 그 하위 패키지에 있는 @Component, @Service, 
                            @Repository, @Controller 등을 탐색하여 스프링 빈으로 등록합니다.
```

3\. SpringApplication.run() 실행 단계별 흐름
------------------
main 메서드가 실행되면 다음과 같은 일들이 순차적으로 일어납니다.
```
1) 내장 웹 서버 타입 확인 (WebApplicationType 결정)
 - 클래스패스에 존재하는 라이브러리를 확인해 애플리케이션 타입을 결정합니다.
 - Tomcat/MVC 패키지가 존재하면 SERVLET, WebFlux가 존재하면 REACTIVE, 둘 다 없으면 NONE으로 결정합니다.
2) 이벤트 리스너 및 초기화 리스너 구동
 - 애플리케이션 구동 과정에서 발생하는 이벤트를 처리할 리스너들을 준비합니다.
3) 환경 변수 및 설정 데이터 로드 (Environment 준비)
 - application.properties 또는 application.yml 설정 파일을 읽어와 시스템 환경변수와 함께 Environment 객체로 결합합니다.
4) 스프링 컨테이너(ApplicationContext) 생성
 - 앞서 결정된 웹 애플리케이션 타입에 맞는 컨테이너를 생성합니다. (일반 Servlet 기반 웹인 경우 
   AnnotationConfigServletWebServerApplicationContext 생성)
5) 빈(Bean) 탐색 및 등록 (Component Scan & Auto Configuration)
 - 메인 클래스의 @ComponentScan을 수행하여 프로젝트 내의 빈들을 등록합니다.
 - @EnableAutoConfiguration을 통해 조건을 충족하는(Conditional) 자동 설정 빈들을 컨테이너에 등록합니다.
6) 내장 웹 서버(Tomcat) 구동
 - 웹 애플리케이션 타입이 SERVLET인 경우, 컨테이너 리프레시(refreshContext) 과정에서 내장 톰캣(Tomcat)을 생성하고 
   포트(기본 8080)를 열어 실행시킵니다.
 - 이제 외부 요청을 받을 준비가 완료됩니다.
7) ApplicationRunner / CommandLineRunner 실행
 - 애플리케이션 구동 직후 실행해야 할 로직이 포함된 러너 빈들이 있다면 실행을 마무리하고 진입점 준비를 끝냅니다.
```

4\. 요약
------------------
```
main() 실행 ➔ SpringApplication.run() 호출 ➔ 환경변수/yml 로드 ➔ 스프링 컨테이너 생성 
➔ Component Scan 및 Auto Configuration으로 빈 등록 ➔ 내장 Tomcat 구동 ➔ 요청 수신 대기
```
