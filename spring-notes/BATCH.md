1\.개념

```
Chunk(청크)   : 대용량 데이터를 한 번에 처리하지 않고, 특정 개수(Chunk Size)만큼 묶어서 처리하는 트랜잭션/커밋 단위를 의미합니다.
```



2\. 정합성이 어긋나는 경우
------------------
```
공유 자원: 스레드 안전(Thread-safe)하지 않은 공유 객체(ItemReader, ItemWriter, ItemProcessor 내 변수 등)를 사용할 경우 데이터가 꼬이게 됩니다.
 => lock을 걸거나.
 => 분리해서 처리할 수 있는것끼리 분리.
```
