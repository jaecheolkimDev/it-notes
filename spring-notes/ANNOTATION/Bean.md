Bean 등록 Annotation
=================

1\. 빈을 "등록"하는 어노테이션 (내가 빈을 만들 때)
------------------
스프링 컨테이너에 "이 클래스를 빈으로 관리해줘"라고 등록하는 어노테이션들입니다.
```
1) 컴포넌트 스캔 대상 (자동 등록계열)
    @ComponentScan을 만났을 때 자동으로 빈 등록이 되는 어노테이션들입니다. 내부적으로 모두 @Component를 내포하고 있습니다.
    @Component: 가장 기본적이고 범용적인 빈 등록 어노테이션입니다.
    @Service: 비즈니스 로직을 수행하는 서비스 레이어 클래스에 사용합니다.
    @Repository: 데이터 접근 레이어(DAO, 리포지토리) 클래스에 사용합니다. (DB 예외를 스프링 예외로 변환해주는 기능 내포)
    @Controller / @RestController: Spring MVC에서 웹 요청을 처리하는 컨트롤러 클래스에 사용합니다.
    @Configuration: 스프링 설정 정보를 담고 있는 클래스에 사용합니다. 이 클래스 자체도 빈으로 등록됩니다.

2) 자바 설정 클래스 내에서 수동 등록
    @Bean: @Configuration이 붙은 클래스 안에서 메서드 단위로 사용합니다. 반환되는 객체를 스프링 빈으로 등록합니다. 
            주로 외부 라이브러리 객체를 빈으로 등록할 때 씁니다.
```

2\. 빈을 "찾아서 등록(스캔)"하는 어노테이션 (지시자 역할)
------------------
직접 빈이 되지는 않지만, 스프링에게 "어디서 빈을 찾아야 하는지" 혹은 "특정 조건일 때만 빈을 등록하라"고 지시하는 어노테이션입니다.
```
@ComponentScan: 지정한 패키지 경로를 뒤져서 위의 @Component 계열 어노테이션이 붙은 클래스들을 찾아 빈으로 등록합니다.
@EnableJpaRepositories: 지정한 패키지에서 JpaRepository 인터페이스를 찾아 동적 프록시(구현체)를 생성하고 빈으로 등록합니다.
@Import: 다른 @Configuration 클래스나 일반 클래스를 현재 설정에 강제로 포함시켜 빈으로 등록되도록 유도합니다.
@ConditionalOn... 계열 (스프링 부트 전용):
    특정 조건이 맞을 때만 빈을 등록하라고 지시합니다.
    예: @ConditionalOnProperty (특정 프로퍼티 값이 일치할 때만 빈 등록)
    예: @ConditionalOnBean (특정 빈이 이미 등록되어 있을 때만 나도 빈으로 등록)
```

3\. 빈이 등록되어 있어야 "쓸 수 있는" 어노테이션 (주입받을 때)
------------------
스프링 컨테이너에 등록이 완료된 빈을 꺼내서 내 클래스의 멤버 변수에 꽂아 넣을 때(의존성 주입) 사용하는 어노테이션입니다.
※ 일반 클래스를 new 연산자로 직접 생성해 놓으면 그 클래스 내부의 어노테이션이 작동하지 않는다.
```
@Autowired: 스프링이 관리하는 빈 중에서 타입(Type)이 일치하는 빈을 찾아 자동으로 주입해 줍니다. (가장 많이 사용)
@Qualifier: 같은 타입의 빈이 2개 이상 존재할 때, 어떤 이름을 가진 빈을 주입해야 할지 콕 집어서 지정합니다. (@Autowired와 함께 사용)
@Resource: 타입이 아니라 이름(Name)을 기준으로 빈을 찾아 주입합니다. (자바 표준 어노테이션)
@PersistenceContext: JPA의 EntityManager를 주입받을 때만 사용하는 전용 어노테이션입니다.
@Value: 빈을 주입하는 것은 아니지만, application.properties 등의 설정 값을 빈의 필드에 주입해 줍니다.
@Transactional  : 트랜잭션 및 AOP 관련
@PostConstruct, @PreDestroy    : 빈의 생명주기(Lifecycle) 콜백
@BeforeStep, @AfterStep     : Spring Batch 전용
@ExceptionHandler       : Spring MVC 전용
```

999\. 대원칙
------------------
"스프링의 마법(@Autowired, @Value, @Transactional 등)은 스프링 컨테이너라는 울타리 안(Bean)에서만 일어난다."
```
내가 아무리 클래스 내부에 주입 어노테이션을 화려하게 적어놨어도, 그 클래스를 호출할 때 MyService service = new MyService(); 
형태로 자바 코드로 직접 객체를 생성해 버리면 그 안의 어노테이션들은 전부 무용지물이 됩니다. 꼭 스프링에게 주입받아(@Autowired) 
사용해야 합니다.
```
