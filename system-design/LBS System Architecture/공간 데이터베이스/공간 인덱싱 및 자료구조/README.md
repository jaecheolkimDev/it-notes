공간 인덱싱 및 자료구조
======================

1\. 정의
--------------
```
대규모 지리 공간 데이터에서 위치 기반 검색(주변 차량, 매장 찾기 등)을 효율적으로 처리하기 위해 가장 대표적으로 사용되는 기법
```

1\. Spatial Hashing & Geohash
--------------
```
1) 개념: 2차원의 위도·경도 좌표를 1차원의 문자열 또는 정수로 변환하여 Grid(격자) 형태로 공간을 나누는 방식입니다.
2) 특징: 위치 좌표를 해시 값으로 변환하므로 O(1) 수준의 빠른 검색 speed를 제공합니다.
3) 주요 활용: Redis(GEO 명령어), Uber(H3 Spatial Index), 실시간 주변 차량/배달원 검색.
```

1\. R-Tree (Rectangle Tree)
--------------
```
1) 개념: 공간 객체들을 최소 경계 사각형(MBR, Minimum Bounding Box)으로 감싸 트리 구조로 계층화하는 방식입니다.
2) 특징: 점(Point) 데이터뿐만 아니라 선(Line), 면(Polygon) 등 복잡한 지형 데이터를 검색하기에 적합합니다.
3) 주요 활용: PostGIS, MySQL Spatial Index, GIS 전용 데이터베이스.
```

1\. Quadtree (쿼드트리)
--------------
```
1) 개념: 2차원 공간을 4개의 균등한 영역(북서, 북동, 남서, 남동)으로 재귀적으로 분할하는 트리 구조입니다.
2) 특징: 데이터 밀도가 높은 도심 지역은 세밀하게 나누고, 데이터가 적은 지역은 크게 나누어 메모리를 효율적으로 관리합니다.
3) 주요 활용: 지도 타일링 시스템, 게임 맵 엔진, 동적 공간 분할.
```

1\. 사례
--------------
```
실시간 위치 변화가 많은 차량 호출 서비스(예: 우버, 카카오T)의 경우, 위도·경도를 육각형 또는 사각형 격자로 나누어 관리하는 
Spatial Hashing 계열(H3, Geohash)이 가장 보편적으로 쓰입니다.
```
