프록시 패턴(접근 제어)
=================
프록시 패턴은 접근 제어에 초점을 맞춘 패턴입니다.
```
실제 객체를 직접 호출하는 대신, 그 객체를 대신하는 '대리인(Proxy)'을 내세워 타깃에 대한 접근을 제어하거나 부가 작업을 수행합니다.

핵심 개념: 타깃 객체에 직접 접근하지 못하게 막고, 프록시가 요청을 가로채서(Intercept) 처리합니다.

트랜잭션에서의 적용:
    클라이언트가 Service를 호출할 때, 실제 서비스 객체가 아닌 프록시 객체를 주입받습니다.
    프록시는 트랜잭션 처리가 필요한지 판단하고, 필요하다면 트랜잭션을 실행한 뒤 실제 서비스 객체에 일을 시킵니다.
    이 과정에서 클라이언트는 자신이 프록시와 대화하는지 실제 객체와 대화하는지 알 필요가 없습니다.
```
