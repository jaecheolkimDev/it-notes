어댑터 패턴(Adapter Pattern)
=================
이름 그대로 우리가 일상생활에서 쓰는 '돼지코'나 '변환 젠더'와 같은 역할을 하는 디자인 패턴입니다.

1\. 개념
-----------
```
서로 다른 인터페이스를 가진 두 클래스가 있을 때, 코드의 수정 없이 이들을 함께 동작할 수 있도록 중간에서 연결해주는 도구라고 이해하면 쉽습니다.
```

2\. 왜 사용하는가? (핵심 목적)
-----------
```
호환성 문제 해결: 소스 코드를 수정할 수 없는 외부 라이브러리나 기존 레거시 코드를 현재 시스템의 인터페이스에 맞춰 쓰고 싶을 때 사용합니다.

결합도 낮추기: 클라이언트가 구체적인 구현 클래스 대신 어댑터 인터페이스에 의존하게 함으로써 코드의 유연성을 높입니다.
```
