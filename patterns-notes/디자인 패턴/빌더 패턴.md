빌더 패턴
=====================

- 개념 : 객체를 생성하는 방식 중 하나
- 유용성 : 필드(속성)가 많거나 복잡한 객체를 생성할 때 유용함.
- 특징 :
  - 가독성 향상
  - 안전한 객체 생성 : 생성 시점에 필요한 모든 필수 값이 누락되지 않도록 보장할 수 있음.
  - 유연성 및 불변성
  - 복잡한 생성자 문제 해결
- 객체간 의존성을 줄이기 위해 객체의 생성과 데이터 주입만 담당하는 Factory Class를 정의하고 개발 코드 부분에서는 생성된 객체를 가져다 사용함으로서 의존성을 줄이는 방식입니다.
