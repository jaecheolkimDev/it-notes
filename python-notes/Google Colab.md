구글 코랩(Google Colaboratory, 이하 Colab)
=================

1\. 정의
-----------
```
구글이 제공하는 클라우드 기반의 파이썬(Python) 개발 환경입니다.
```

2\. 주요 특징
-----------
```
1) 무료 GPU / TPU 제공
 - 고성능 그래픽 카드(GPU)나 딥러닝 전용 프로세서(TPU)를 무료로 사용할 수 있어, 일반 컴퓨터로 수행하기 힘든 인공지능 모델 학습이 
   가능합니다.
2) 설치 없는 간편함 (Jupyter Notebook 기반)
 - 브라우저 상에서 바로 코드를 실행할 수 있으며, 코드, 설명(텍스트), 시각화 그래프를 한 문서에 같이 기록할 수 있습니다.
3) 구글 드라이브 연동
 - 작업한 파일(.ipynb)을 구글 드라이브에 자동 저장할 수 있으며, 팀원들과 구글 문서처럼 손쉽게 공유하고 공동 편집할 수 있습니다.
4) 사전 설치된 주요 라이브러리
 - TensorFlow, PyTorch, Pandas, NumPy 등 데이터 분석 및 AI 개발에 필요한 주요 패키지가 기본으로 설치되어 있어 바로 활용 
   가능합니다.
```

3\. 주요 제약 사항
-----------
```
1) 세션 시간 제한
 - 무료 버전은 일정 시간 동안 작업이 없거나, 일정 연속 사용 시간(보통 12시간 내외)이 지나면 연결이 끊기고 데이터(메모리 상의 변수, 
   임시 파일 등)가 초기화됩니다.
2) 자원 할당 변동성
 - 사용자 수나 구글 서버 상태에 따라 제공되는 GPU 성능이나 사용 시간이 제한될 수 있습니다. (필요시 Colab Pro 등 유상 요금제 이용 가능)
```

4\. 사용 추천 대상
-----------
```
1) 파이썬이나 데이터 분석을 입문/공부하는 학습자
2) 내 컴퓨터의 사양이 낮아 GPU 환경이 필요한 사용자
3) 코드를 팀원들과 손쉽게 공유하며 협업하고 싶은 사람
```
