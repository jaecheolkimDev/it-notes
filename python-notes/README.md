python
=================


1\. .py 파일
----------------------------------------
```
.py 파일은 일반적으로 Python 스크립트 파일을 나타냅니다.
이러한 파일은 일련의 파이썬 코드를 포함하고 있고, 해당 코드를 실행할 수 있습니다.
```

2\. .ipynb 파일
----------------------------------------
```
.ipynb 파일은 Jupyter Notebook 파일을 나타냅니다.
Jupyter Notebook은 대화형 컴퓨팅 환경을 제공하는 오픈 소스 웹 응용 프로그램입니다.
이를 사용하여 코드, 텍스트, 그림 등을 포함한 문서를 작성하고 실행 가능한 코드를 포함하는 것이 가능합니다.
코드 셀과 텍스트 셀로 나뉘어져 작성이 가능합니다.
```

3\. 가상환경(venv)
----------------------------------------
파이썬 프로젝트를 할 때는 라이브러리 꼬임을 방지하기 위해 **가상환경(venv)**을 만드는 것이 기본이자 필수입니다.
```
1) 가상환경 생성 (폴더 이름은 .venv)   : $ python -m venv .venv
2) 윈도우에서 가상환경 활성화           : $ .venv\Scripts\activate
```

4\. 버전 확인
----------------------------------------
```
$ python --version
```

5\. pip
----------------------------------------
파이썬으로 작성된 패키지(소프트웨어 라이브러리)를 설치하고 관리해 주는 패키지 매니저(Package Manager)입니다.
```
1) install  : 패키지 설치하기
    install --upgrade   : 패키지 업데이트하기
2) list     : 설치된 패키지 목록 확인하기
3) uninstall    : 패키지 삭제하기

```
