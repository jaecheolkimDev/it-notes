python
=================

1\. .py 파일
-----------
```
.py 파일은 일반적으로 Python 스크립트 파일을 나타냅니다.
이러한 파일은 일련의 파이썬 코드를 포함하고 있고, 해당 코드를 실행할 수 있습니다.
```

4\. 버전 확인
-----------
```
$ python --version
```

5\. pip
-----------
파이썬으로 작성된 패키지(소프트웨어 라이브러리)를 설치하고 관리해 주는 패키지 매니저(Package Manager)입니다.
```
1) install  : 패키지 설치하기
    install --upgrade   : 패키지 업데이트하기
2) list     : 설치된 패키지 목록 확인하기
3) uninstall    : 패키지 삭제하기
```

6\. requirements.txt
-----------
파이썬 프로젝트에서 필요한 외부 라이브러리(패키지)들의 이름과 버전 정보를 정리해 둔 텍스트 파일입니다.
```
1) 현재 환경의 패키지 목록을 파일로 저장할 때     : pip freeze > requirements.txt
2) 파일에 적힌 패키지들을 한 번에 설치할 때      : pip install -r requirements.txt
```
