1\. 가상환경(venv)
-----------
파이썬 프로젝트를 할 때는 라이브러리 꼬임을 방지하기 위해 **가상환경(venv)**을 만드는 것이 기본이자 필수입니다.
```
1) 가상환경 생성 (폴더 이름은 .venv)   : $ python -m venv .venv
2) 윈도우에서 가상환경 활성화           : $ .venv\Scripts\activate
```

2\. Miniconda, Anaconda
-----------
파이썬(Python) 개발 환경을 쉽고 안전하게 관리할 수 있도록 도와주는 패키지 관리자이자 환경 관리 시스템입니다.
```
개발을 하다 보면 프로젝트마다 필요한 파이썬 버전이 다르거나, 사용하는 라이브러리의 버전이 충돌하는 경우가 자주 발생합니다. 
이때 컴퓨터 전체 시스템을 망가뜨리지 않고, 프로젝트별로 '독립된 방(가상환경)'을 만들어주는 역할을 합니다.
Conda를 사용하면 서로 다른 프로젝트가 간섭하지 않도록 완벽하게 분리된 가상 공간을 만들 수 있습니다.

두 프로그램은 모두 Conda라는 핵심 관리 시스템을 기반으로 작동하지만, 구성 파일의 무게와 목적에서 큰 차이가 있습니다.

구분      Miniconda (미니콘다)                        Anaconda (아나콘다)
개념      최소한의 기능만 갖춘 슬림한 버전              데이터 과학/머신러닝에 필요한 모든 것이 포함된 종합 선물 세트
포함 내역   "Conda, 파이썬, 아주 기본적인 패키지들"      "Conda, 파이썬 + 1,500개 이상의 과학/데이터 분석 라이브러리 + GUI 프로그램"
용량      약 50MB ~ 100MB 내외 (가볍고 빠름)          약 3GB ~ 5GB 이상 (무겁고 설치가 오래 걸림)
추천 대상   필요한 패키지만 직접 설치하고 싶은 개발자, 용량이 부족한 환경     데이터 분석, 머신러닝을 처음 시작하는 데이터 과학자/학생
```
