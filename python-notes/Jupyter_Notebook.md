Jupyter Notebook
=================


1\. .ipynb 파일
----------------------------------------
```
Jupyter라는 이름 자체가 데이터 과학에서 가장 많이 쓰이는 세 가지 언어의 앞 글자를 따서 만들어진 것입니다.

Julia (줄리아)
Python (파이썬)
ter (R)
```

2\. 매직 명령어(Magic Command)
----------------------------------------
% 기호는 '매직 명령어(Magic Command)'라고 부릅니다.
```
파이썬 자체의 문법이 아니라, Jupyter Notebook이나 IPython 환경에서 시스템이나 노트북 환경을 직접 제어하기 위해 제공하는 특별한 명령어입니다.

매직 명령어                  역할
%pwd                    현재 작업 중인 디렉토리(폴더) 경로를 보여줌
%ls                     현재 폴더에 있는 파일 목록을 보여줌
%time                   해당 줄의 코드가 실행되는 데 걸린 시간을 측정함
%matplotlib inline      노트북 안에서 그래프가 바로 보이도록 설정함
```

3\. '커널(Kernel)'을 통한 다국어 지원
----------------------------------------
```
Jupyter Notebook은 내부적으로 '커널(Kernel)'이라는 엔진을 교체하는 방식으로 작동합니다. 파이썬 코드를 실행할 때는 파이썬 커널을, 
다른 언어를 쓸 때는 해당 언어의 커널을 연결하는 구조입니다.

현재 Jupyter Notebook은 전 세계 개발자들이 만든 커널 덕분에 100개 이상의 프로그래밍 언어를 지원합니다.
```

4\. 장점
----------------------------------------
```
1) 코드, 실행 결과, 설명의 '한 몸'화 (가장 큰 장점)
코드 셀, 실행 결과(출력 데이터, 이미지, 그래프), 그리고 마크다운(설명글)이 한 페이지에 모두 담깁니다.
코드를 실행하면 그 직후에 결과가 바로 저장되므로, 한 달 뒤에 다시 열어도 "내가 이 코드로 어떤 결과를 얻었었지?"를 직관적으로 확인할 수 있습니다.

2) '인터랙티브(Interactive)'한 셀 단위 실행
첫 번째 셀에서 데이터를 한 번만 로드해 두면 메모리에 계속 유지됩니다. 그 이후에는 아래쪽 셀에서 데이터 가공 코드만 수십 번 수정해가며 가볍게 
실행할 수 있습니다.

3) LLM/랭체인(LangChain) 개발 시 특히 유용한 이유
LLM API를 호출하는 데는 시간과 비용(토큰 요금)이 듭니다. Jupyter를 쓰면 API를 호출해 데이터를 받아오는 셀은 딱 한 번만 실행해 두고, 그 아래 
셀에서 받아온 결과를 파싱하고 가공하는 코드만 비용 걱정 없이 무한히 수정·반복 실행할 수 있습니다.

4) 시각화 자료의 직관적 확인
데이터 분석이나 AI 모델의 성능을 평가할 때 표(DataFrame)나 그래프(차트)를 많이 그리게 됩니다. Jupyter Notebook은 코드를 실행하자마자 그 아래에 
Matplotlib나 Seaborn 같은 시각화 그래프가 팝업창이 아니라 노트북 웹 페이지 내에 직접 렌더링되어 나타납니다. 스크롤을 내리면서 흐름을 파악하기에 
최적화되어 있습니다.
```
