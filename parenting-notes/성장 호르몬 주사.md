성장 호르몬 주사 (키가 작아 고민일 때)
=================

1\. 개념
-----------
```
또래보다 키가 너무 작거나 성장 속도가 느릴 때 고려하는 주사입니다.
```

2\. 시작 가능 시기
-----------
```
만 4세 이후부터 시작할 수 있지만, 보통은 초등학교 저학년(만 6세~7세)에서 사춘기 이전에 시작하는 것이 가장 효과적입니다.
```

3\. 대상
-----------
```
또래 100명 중 3번째 미만으로 키가 작거나, 1년에 4cm 미만으로 자라는 경우 병원에서 정밀 검사(성장 호르몬 분비 수치, 성장판 검사 등) 
후 처방받아 맞게 됩니다.
```

4\. 특징
-----------
```
성장판이 열려 있어야 효과가 있기 때문에, 여아는 초등 고학년, 남아는 중등 이전에 검사를 받아보는 것이 좋습니다.
```
