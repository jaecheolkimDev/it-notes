성조숙증 치료 주사 (성장판이 너무 빨리 닫힐까 봐 걱정될 때)
=================

1\. 개념
-----------
```
사춘기 징후(여아 가슴 멍울, 남아 고환 크기 증가 등)가 너무 빨리 나타나서 성장판이 조기에 닫히는 것을 막기 위해 맞는 
주사(사춘기 지연 주사)입니다.
```

2\. 치료 시작 시기
-----------
```
건강보험 적용을 기준으로 여아는 만 9세 이전(초등학교 3학년 이전), 남아는 만 10세 이전(초등학교 4학년 이전)에 치료를 시작해야 
효과를 볼 수 있습니다.
```

3\. 특징
-----------
```
사춘기 발달을 잠시 늦춰서 성장판이 열려 있는 기간을 확보하고, 결과적으로 최종 키가 작아지는 것을 막아주는 역할을 합니다.
```
