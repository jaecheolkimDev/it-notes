<packaging>
======================

1\. 정의
----------------
```
프로젝트가 빌드된 후 어떤 형태로 묶일지 결정합니다. (jar, war, pom 등)
```

1\. 기본값
----------------
```
1) <packaging> 태그를 생략하면 기본값(Default)으로 jar를 적용합니다.
2) 만약 JAR가 아닌 다른 형태(WAR, EAR, POM 등)로 빌드해야 할 때만 명시해 주면 됩니다.
```
