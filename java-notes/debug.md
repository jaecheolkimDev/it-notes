로그 레벨
=================

1\. 개념
-------------------
```
로그 레벨이 INFO로 설정되어 있으면, 
 - INFO 레벨을 포함해 그보다 중요도(위험도)가 높은 상위 레벨의 로그들을 모두 볼 수 있습니다. 
 - 반대로 INFO보다 낮은 레벨의 로그는 출력되지 않고 무시됩니다.
```

2\. 로그 레벨 우선순위 (오른쪽으로 갈수록 높음)
-------------------
```
TRACE ➔ DEBUG ➔ INFO ➔ WARN ➔ ERROR
```

3\. 출력되지 않는 레벨
-------------------
```
DEBUG, TRACE: 주로 개발 단계나 상세한 디버깅을 위해 사용하는 낮은 레벨의 로그는 INFO 환경에서 숨겨집니다.
```

4\. 설정별 출력 범위
-------------------
```
설정된 로그 레벨   출력되는 로그 레벨 범위                   특징
TRACE           TRACE, DEBUG, INFO, WARN, ERROR     모든 로그를 다 봄 (가장 상세함)
DEBUG           DEBUG, INFO, WARN, ERROR            개발 환경에서 주로 사용
INFO            INFO, WARN, ERROR                   운영(PRD) 환경 표준 설정
WARN            WARN, ERROR                         경고와 에러만 확인
ERROR           ERROR                               시스템에 터진 에러만 확인
```
