JAVA Memory
=================

1\. 자바의 메모리 영역
-----------
자바 프로그램이 실행될 때 메모리는 스택(Stack) 과 힙(Heap) 으로 나뉘어 객체와 변수들이 관리된다.
이 두 영역은 메모리 관리, 생명주기, 접근 방식에서 큰 차이를 가진다.
```
1. 메서드 영역 : static 변수, 전역변수, 코드에서 사용되는 Class 정보 등이 올라간다.
   , 코드에서 사용되는 class들을 로더로 읽어 클래스별로 런타임 필드데이터, 메서드 데이터 등을 분류해 저장한다.
2. 스택(Stack) : 지역변수, 함수(메서드) 등이 할당되는 LIFO(Last In First Out) 방식의 메모리
3. 힙(Heap) : new 연산자를 통한 동작할당된 객체들이 저장되며, 가비지 컬렉션에 의해 메모리가 관리되어 진다.
```

================================================================================
|   구분     |          Stack (스택)           |           Heap (힙)           |
================================================================================
| 정의       | 지역 변수, 매개변수 저장        | new 객체(인스턴스) 저장       |
|------------|---------------------------------|-------------------------------|
| 관리 주체  | 스레드별 자동 관리 (LIFO)       | Garbage Collector(GC)가 관리  |
|------------|---------------------------------|-------------------------------|
| 저장 대상  | 기본형 변수, 객체의 참조 주소값 | 참조형 변수의 실제 객체 데이터|
|------------|---------------------------------|-------------------------------|
| 생명주기   | 메서드 종료 시 즉시 소멸        | 참조 해제 후 GC에 의해 삭제   |
|------------|---------------------------------|-------------------------------|
| 공유 여부  | 각 스레드마다 독립적            | 모든 스레드가 공유 가능       |
|------------|---------------------------------|-------------------------------|
| 속도/크기  | 매우 빠름 / 작음                | 상대적으로 느림 / 큼          |
|------------|---------------------------------|-------------------------------|
| 예외 발생  | StackOverflowError              | OutOfMemoryError              |
================================================================================
