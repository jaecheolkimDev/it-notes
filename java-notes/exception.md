Exception
=================

1\. e.printStackTrace()
-------------------
```
설명: 에러가 발생한 가장 구체적인 원인(근원 예외)부터 전체 호출 스택(Call Stack)을 콘솔에 출력합니다.
장점: 어떤 클래스의 몇 번째 라인에서 에러가 시작되었는지 한눈에 볼 수 있어 디버깅할 때 가장 먼저 사용해야 하는 기본 메서드입니다.
```

2\. e.getMessage()
-------------------
```
설명: 예외와 함께 전달된 에러 메시지(문자열)를 반환합니다.
사용: 로그를 남길 때 logger.error("에러 발생: " + e.getMessage()) 형태로 주로 사용합니다.
```

3\. e.getCause()
-------------------
```
설명: 해당 예외를 유발한 원인 예외(Cause Exception)를 반환합니다.
왜 중요할까요?: SAXParser가 내부적으로 IOException이 발생했을 때, 이를 그대로 던지지 않고 SAXException 등으로 감싸서(Wrapping) 던지는 경우가 
    많습니다. 이때 e.getCause()를 호출하면 실제 스트림이 왜 닫혔는지(NullPointerException, IOException 등) 진짜 원인을 찾아낼 수 있습니다.
```
