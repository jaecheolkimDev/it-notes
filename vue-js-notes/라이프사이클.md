vue.js 라이프사이클 공부 note
======================

1\. 개념
-----------------------
```
Vue.js의 라이프사이클은 컴포넌트가 생성되고(Create), DOM에 부착되고(Mount), 데이터가 변경되어 업데이트되고(Update), 
마지막으로 소멸(Destroy/Unmount)되는 전체 과정을 말합니다. (4가지 단계)

* 팝업은 v-if로 컴포넌트를 파괴하고 생성하는 작업을 해줘야지 동작한다.
```

2\. Creation 단계 (초기화)
-----------------------
컴포넌트가 생성되는 단계입니다. 서버 사이드 렌더링(SSR)에서도 실행되는 유일한 단계입니다.
```
1) beforeCreate: 가장 먼저 실행되는 훅입니다. 데이터(data)와 이벤트(events)가 아직 설정되기 전이라 this.message 같은 데이터에 접근하면 
                 undefined가 뜹니다.
2) created: 데이터와 이벤트가 활성화된 상태입니다. 하지만 템플릿이 DOM에 마운트되기 전이라 this.$el이나 $refs 같은 DOM 요소에는 접근할 수 없습니다.
   용도: 초기 데이터 요청(axios 호출 등)에 가장 많이 쓰입니다.
```

3\. Mounting 단계 (DOM 삽입)
-----------------------
컴포넌트를 실제 화면(DOM)에 붙이는 단계입니다.
```
1) beforeMount: 템플릿이 가상 DOM(Virtual DOM)으로 생성되었으나, 실제 브라우저 화면에 나타나기 직전입니다. 거의 사용되지 않습니다.
2) mounted: 가장 많이 쓰는 훅 중 하나입니다. 실제 HTML 요소가 화면에 그려진 상태입니다.
   용도: $refs 접근, 차트/지도 라이브러리 초기화, window 객체 이벤트 리스너 등록 등을 처리합니다.
```

4\. Updating 단계 (데이터 변경)
-----------------------
컴포넌트 내의 반응형 데이터가 변해서 화면을 다시 그릴 때 발생합니다.
```
1) beforeUpdate: 데이터는 변했지만, 화면이 다시 그려지기 직전의 상태입니다. 변경 전의 DOM 값을 읽어올 때 유용합니다.
2) updated: 데이터 변경이 DOM에 완전히 반영된 후입니다.
   주의: 여기서 데이터를 수정하면 업데이트 훅이 다시 호출되어 무한 루프에 빠질 수 있습니다.
```

5\. Destruction 단계 (소멸)
-----------------------
컴포넌트가 화면에서 사라질 때(예: v-if="false", 페이지 이동 등) 실행됩니다.
```
1) beforeDestroy: 컴포넌트가 사라지기 직전입니다. 인스턴스는 여전히 살아있어서 모든 기능에 접근 가능합니다.
   용도: 메모리 누수 방지를 위해 setInterval 해제, 전역 이벤트 리스너(window.addEventListener) 제거 등을 반드시 여기서 해야 합니다.
2) destroyed: 컴포넌트가 완전히 해체된 상태입니다. Vue의 모든 감시가 중단됩니다.
```
