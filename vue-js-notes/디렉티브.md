vue.js 디렉티브(Directives) 공부 note
======================

1\. 
--------------
디렉티브는 HTML 태그 안에 들어가는 v- 접두사가 붙은 특수 속성입니다.
브라우저는 v-if, v-for 같은 속성을 모르지만, Vue는 이 속성을 보고 "아, 이 태그는 이렇게 처리하라는 뜻이구나!" 하고 알아듣습니다.
즉, "HTML 요소에게 내리는 Vue 전용 명령"이라고 생각하면 됩니다.
```
1) v-이름:전달인자.수식어="값"
        이름(Name): 어떤 기능을 할지 결정 (예: if, on, bind, model)
        전달인자(Argument): : 뒤에 붙으며, 무엇을 대상으로 할지 지정 (예: v-on:click에서 click)
        수식어(Modifiers): . 뒤에 붙으며, 특별한 방식으로 실행 (예: .prevent, .stop)
        값(Value): = 뒤에 오는 자바스크립트 표현식 (데이터 변수나 함수 이름)

2) 디렉티브
        디렉티브        역할                                      예시
        v-bind      HTML 속성(id, src, class 등)에 데이터를 연결  :src="imagePath"
        v-model     입력창(input)과 데이터를 실시간으로 동기화      v-model="userName"
            => 양방향 바인딩
        v-if        조건에 따라 요소를 화면에 그릴지 말지 결정        v-if="isLoggedIn"
        v-show      렌더링은 하되 display: none 처리를 함
        v-for       리스트(배열) 데이터만큼 태그를 반복해서 생성       v-for="item in items"
        v-on        이벤트를 처리 (클릭, 키보드 입력 등)          @click="submit"

3) 이벤트명
        click       : 마우스를 클릭했을 때 실행함
        dblclick    : 마우스를 더블 클릭했을 때 실행함
        mouseover   : 마우스의 포인트가 요소 위로 올라왔을 때 실행함
        mouseout    : 마우스의 포인트가 요소 밖으로 벗어났을 때 실행함
        mousemove   : 마우스의 포인트가 이동했을 때 실행함
        mousedown   : 마우스의 버튼을 눌렀을 때 실행함
        mouseup     : 마우스의 버튼을 놓았을 때 실행함
        keydown     : 키보드의 키를 눌렀을 때 실행함
        keyup       : 키보드의 키를 놓았을 때 실행함
        keypress    : 키보드의 키를 눌렀다가 놓았을 때 실행함
        change      : 요소가 변경될 때 실행함
        submit      : <Form>이 제출될 때 실행함
        reset       : <Form>이 재설정될 때 실행함
        select      : <select>의 값이 선택되었을 때 실행함
        focus       : 태그에 포커스가 있을 때 실행함
        blur        : 태그에 포커스를 잃었을 때 실행함
        input       : 값이 변경되는 모든 순간(키보드 입력, 붙여넣기, 삭제 등)에 즉각적으로 반응합니다. 실시간 상태 변경에 가장 완벽한 이벤트입니다.
        
4) 이벤트 수식어 (Event Modifiers)    : Vue의 강점 중 하나로, 자바스크립트 내에서 event.preventDefault() 등을 직접 작성하는 대신 
                                      디렉티브 뒤에 점(.)을 붙여 간편하게 처리할 수 있습니다.
        .stop: 이벤트 전파를 중단합니다. (event.stopPropagation())
        .prevent    : 기본 동작을 방지합니다. (event.preventDefault())
        .capture    : 캡처 모드에서 이벤트를 감지합니다.
        .self       : 이벤트가 자식 요소가 아닌 요소 자신에게서 발생했을 때만 실행합니다.
        .once       : 이벤트를 딱 한 번만 실행합니다.
        .passive    : 기본 이벤트를 취소할 수 없게 함
        
5) 키 수식어 (Key Modifiers)    : 키보드 이벤트를 들을 때 특정 키를 지정하기 매우 편리합니다. (고유 키 값)
        .enter      13
        .tab        9
        .delete     8       “Delete” 와 “Backspace” 키 모두 해당
        .esc        27
        .space      32
        .up         33
        .down       34
        .left       37
        .right      39
        .ctrl       17
        .alt        18
        .shift      16      .meta
        
6) 마우스 버튼 수식어
        .left       : 마우스 왼쪽 버튼 클릭
        .right      : 마우스 오른쪽 버튼 클릭
        .middle     : 마우스 가운데 휠 버튼 클릭
```

2\. v-bind
--------------
```
props나 HTML 속성에 콜론(:, v-bind의 축약어)을 붙이는 것과 안 붙이는 것의 핵심 차이는 "JS 표현식(변수/숫자/보안값 등)으로 
평가하느냐" vs "단순 문자열(String) 그대로 전달하느냐"입니다.
```
