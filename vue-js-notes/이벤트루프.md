이벤트 루프(Event Loop) 공부 note
======================

1\. 작업 큐
--------------
```
자바스크립트의 작업 큐는 크게 두 가지로 나뉩니다.
    Microtask (마이크로태스크): Promise.then, Vue.nextTick 등이 여기에 해당하며, 현재 실행 중인 작업이 끝나자마자 가장 먼저 실행됩니다.
    Macrotask (매크로태스크): setTimeout, setInterval 등이 여기에 해당하며, 마이크로태스크들이 모두 처리된 후에 다음 차례에 실행됩니다.
따라서 팝업의 hide 메소드 안에서 setTimeout(..., 150)을 실행하면, 이 작업은 150ms 뒤에 실행될 매크로태스크로 예약됩니다. 
하지만 바깥 호출부의 nextTick은 마이크로태스크이므로, 150ms가 지나기도 훨씬 전에(현재 코드 실행 직후에) 바로 동작해 버립니다.
```
