======================

0\. 반응형
-----------------------
```
반응형이란, 데이터가 변경되었을 때 이를 감지하고 이에 반응하여 DOM이 자동으로 업데이트 되는 성질을 말한다. 즉, 데이터를 변경하면 화면이 변경되는 것이다.
문제점 : 
    1. vue2에서 배열의 특정 인덱스에 값을 직접 할당하는것은 감시(Observation) 대상이 아닙니다.
    2. 처음에 있던 대상이 아니라면 나중에 추가해도 이를 변화로 인식하지 못합니다.
    3. vue는 인스턴스가 생성될 때 데이터 객체를 조사하여 getter/setter를 주입합니다.

해결방안 : 
    1. this.$set을 사용 (Vue가 변화를 감지할 수 있도록 명시적으로 알려주는 방법입니다.)
    2. 배열 (배열의 주소값 자체를 바꿔버리면 Vue가 리스트 전체를 다시 렌더링하므로 가장 깔끔합니다.)
        - 메서드(splice)를 사용하기
        - 배열 전체를 새로 할당하기
            this.logData = this.logData.map(item => ({
              ...item,              // 스프레드 연산자 (객체의 내용을 펼쳐서 복사하는 문법)
              select: false
            }));
            
this.$forceUpdate()     : 강제 렌더링
```

1\. 선언적 프로그래밍(Declarative Programming)
-----------------------
```
Vue는 기본적으로 데이터가 변하면 UI가 자동으로 업데이트되는 선언적 프로그래밍(Declarative Programming)을 지양합니다. 
반면, $refs를 통해 DOM에 직접 접근하는 것은 명령적 프로그래밍(Imperative Programming) 방식에 가깝습니다.
```

7\. props
-----------------------
```
상하위 컴포넌트 관계
컴포넌트는 각각 고유한 유효 범위를 갖고 있기 때문에 직접 다른 컴포넌트의 값을 참조할 수 없다.
뷰 프레임워크 자체에서 정의한 컴포넌트 데이터 전달 방법을 따라하며,
가장 기본적인 전달 방법은 상위(부모) - 하위(자식) 컴포넌트간의 데이터 전달 방법이다.
부모에서 자식으로는 props 속성을 전달할 수 있다. 자식에서 부모로는 기본적인 이벤트만 전달할 수 있다.
* props에서 받을 파라미터의 타입을 정해놓으면 부모에서는 일치하는 타입만 보내야 한다.
```

-----------------------
```

```

9\. nextTick
-----------------------
nextTick은 Vue의 반응형 시스템에서 가장 중요한 핵심 개념 중 하나입니다.
간단히 정의하자면, nextTick은 데이터 변경 후 DOM 업데이트가 완료될 때까지 기다렸다가 실행되는 콜백 함수입니다.
```
Vue는 성능을 위해 데이터가 변할 때마다 즉시 DOM을 수정하지 않습니다. 대신, 여러 데이터 변경사항을 큐(Queue)에 모았다가 한꺼번에 처리합니다. 
이를 "비동기 업데이트 큐"라고 합니다.
예를 들어, 값을 1에서 100까지 반복문으로 바꾼다면, Vue는 100번 화면을 그리는 대신 마지막에 바뀐 '100'을 기준으로 딱 한 번만 DOM을 업데이트합니다. 
이 과정 때문에 데이터를 바꾸자마자 DOM에 접근하면, 아직 바뀌기 전의 상태를 보게 되는 것입니다.
```

10\. $set , $delete
-----------------------
```
VueJS를 사용하면서 객체 데이터나 배열 데이터를 사용하게 되면 새로운 속성 및 데이터가 추가되거나 삭제되는 것을 감지하지 못하는 경우가 자주 생긴다.
여기서 "값이 갱신되었다." 라고 요청을 하는 메서드인Vue.set / $set 와 Vue.delete / $delete 가 존재한다.

배열 : Vue.set(arr, index, value) // == this.$set(arr, index, value)
객체 : Vue.set(obj, key, value) // ==this.$set(obj,key,value)    
      Vue.delete(obj, key) // == this.$delete(obj, key)
      
Vue.set() 혹은 this.$set() 을 통해 배열이나 객체의 값이 갱신되었다 라고 요청하는 것이며
Vue.delete() 혹은 this.$delete() 를 통해 객체의 속성이 제거되었다 라고 요청하는 것이다.

```
