Network
=====================

1\. 네트워크 간에 이동하는 방향
-------------------
```
Inbound (인바운드): 밖에서 안으로 들어오는 신호. (포트 포워딩이 필요한 방향)
- 메시지가 클라이언트에서 서버로 향하는 것
ex) 첨부파일을 서버에 저장할 때(업로드)

Outbound (아웃바운드): 안에서 밖으로 나가는 신호. (일반적으로 항상 허용됨)
- 클라이언트의 요청을 처리하고 메시지가 서버에서 클라이언트로 다시 향하는 것
ex) 첨부파일을 다운로드 할 때
```
