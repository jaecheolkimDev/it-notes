2\. DHCP(Dynamic Host Configuration Protocol)
--------------------------------------
네트워크 안의 장치(PC, 스마트폰, 서버 등)에 IP 주소를 자동으로 할당하고 관리해주는 통신 규약입니다.
```
1) 사용 이유
 1-1) 중복 방지: 똑같은 IP를 두 명이 사용하는 충돌 사고를 막아줍니다.
 1-2) 효율성: 한정된 IP 자원을 꼭 필요한 사람에게만 빌려주고, 사용이 끝나면 회수합니다.
 1-3) 편의성: 사용자는 와이파이 비번만 치면 내부적으로 어떤 IP가 잡히는지 신경 쓸 필요가 없습니다.
 
2) 작동 과정
 2-1) Discover (탐색): 기기가 네트워크에 소리칩니다. "여기 IP 주소 줄 수 있는 DHCP 서버 있나요?"
 2-2) Offer (제안): DHCP 서버가 대답합니다. "네, 저 여기 있어요. 192.168.0.15 주소 어떠세요?"
 2-3) Request (요청): 기기가 확답합니다. "좋네요! 그 주소 제가 쓸게요. 장부에 적어주세요."
 2-4) Acknowledge (확인): 서버가 최종 승인합니다. "알겠습니다. 이제부터 그 주소는 당신 거예요. (임대 기간은 24시간입니다.)"
 
3) 관리하는 정보
 3-1) IP 주소: 장치의 고유 식별 주소
 3-2) 서브넷 마스크(Subnet Mask): 네트워크의 크기 정의
 3-3) 기본 게이트웨이(Default Gateway): 외부 인터넷으로 나가는 문(보통 공유기 주소)
 3-4) DNS 서버 주소: 도메인 네임을 IP로 변환해주는 서버 주소
 
4) 핵심 개념
 4-1) 임대 시간: 보통 24시간 등으로 설정되어 있으며, 이 시간이 지나면 주소를 반납해야 합니다.
 4-2) 갱신: 임대 시간의 절반(50%) 정도가 지나면 기기가 서버에 "저 이 주소 계속 써도 될까요?"라고 물어보고 기간을 연장합니다. 
           덕분에 우리가 PC를 켜둔 상태에서 IP가 갑자기 끊기는 일은 거의 없습니다.
```
