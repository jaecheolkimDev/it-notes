NAT 주소
=====================

1\. NAT(Network Address Translation, 네트워크 주소 변환)
--------------------------------------
내부 네트워크에서 사용하는 사설 IP 주소를 외부 인터넷에서 사용하는 공인 IP 주소로 변환하는 기술
IP 대 IP로 1:1 변환
```
1) 역사적 배경: 인터넷 초기 설계자들은 IPv4 주소 체계(약 43억 개)면 전 세계 모든 장치를 연결하고도 남을 줄 알았습니다.
              하지만 90년대 들어 인터넷이 폭발적으로 보급되면서 주소가 부족해지는 'IPv4 고갈 문제'가 닥쳤습니다.
2) 해결책의 등장: 이를 해결하기 위해 차세대 주소 체계인 IPv6가 제안되었지만, 전 세계의 모든 장비를 한꺼번에 바꾸는 것은 불가능했습니다.
                이때 시간을 벌기 위해 나온 기술 중 하나가 바로 NAT입니다.
3) 공식 정의: 1994년 RFC 1631 문서에서 처음으로 표준화되었습니다.

4) 작동 원리 (집에서 사용하는 와이파이 공유기가 바로 NAT의 가장 대표적인 장치입니다.)
 4-1) 사설 IP (Internal): 공유기 아래에 연결된 PC, 스마트폰 등은 192.168.x.x 같은 가짜 주소(사설 IP)를 부여받습니다. 
                         이 주소는 우리 집 안에서만 유효하며 인터넷 세상에서는 통하지 않습니다.
 4-2) 변환 (Translation): 우리 집 장치들이 네이버나 구글에 접속하려고 하면, 공유기가 출발지 주소를 '통신사가 부여한 진짜 주소(공인 IP)'로 
                         딱 바꿔서 내보냅니다.
 4-3) 관리: 공유기는 "어떤 사설 IP가 어떤 사이트에 요청을 보냈는지"를 표(NAT Table)에 기록해두었다가, 데이터가 돌아오면 
           다시 원래 주인(사설 IP)에게 전달해 줍니다.

5) 사용 이유
 5-1) IP 주소 절약: 하나의 공인 IP에 수백 대의 기기를 연결할 수 있습니다. 
                  회사 내부 서버들이 하나의 공인 IP를 공유하며 외부에 노출되는 구조를 자주 접하셨을 겁니다.
 5-2) 보안성 강화: 외부 인터넷에서는 내부 사설 IP를 알 수 없습니다. 
                 즉, 외부에서 내부 PC로 직접 연결하는 것이 기본적으로 차단되기 때문에 일종의 방화벽 역할을 합니다.
 5-3) 유연성: 내부 네트워크 설정을 바꿔도 외부 IP는 그대로 유지할 수 있어 관리가 편합니다.
```

2\. PAT (Port Address Translation)
--------------------------------------
하나의 공인 IP 주소를 여러 개의 사설 IP 장치들이 공유할 수 있게 해주는 기술입니다. 
NAT(Network Address Translation)의 가장 흔한 변종으로, 실제 우리가 사용하는 대부분의 공유기에서 작동하는 방식입니다.
일반적인 NAT은 IP 대 IP로 1:1 변환을 하지만, 
PAT은 'IP + 포트 번호'를 묶어서 관리합니다. 이를 통해 하나의 공인 IP로도 수천 개의 내부 연결을 구분할 수 있습니다.
```
1) 동작 방식: 내부 장치들이 외부(인터넷)로 데이터를 보낼 때, 라우터(공공 IP)는 자신의 포트 번호 중 하나를 골라 해당 장치와 연결합니다.
2) 사용 이유
 2-1) IP 주소 절약: 전 세계적으로 부족한 IPv4 주소를 극적으로 아낄 수 있습니다. (하나의 주소로 이론상 약 65,535개의 연결 가능)
 2-2) 보안: 외부에서는 내부의 사설 IP 주소를 알 수 없습니다. 
           외부에서 내부로 들어오는 직접적인 연결을 원천 차단하는 일종의 기본 방화벽 역할을 합니다.
           
3) PAT와 Port Forwarding의 차이점
구분  PAT (Port Address Translation)  Port Forwarding
방향  안에서 밖으로 (Outbound 중심)       밖에서 안으로 (Inbound 중심)
설정  공유기가 알아서 자동으로 처리        사용자가 수동으로 규칙을 정함
목적  여러 기기의 인터넷 동시 접속        외부에서 내 서버(스프링 등)에 접속 허용
```

3\. Port Forwarding(포트 포워딩)
--------------------------------------
외부 네트워크(인터넷)에서 공유기나 방화벽 뒤에 숨어있는 내부 네트워크의 특정 기기(서버, PC 등)에 접속할 수 있도록 전용 통로를 만들어주는 기술입니다.
```
일반적인 네트워크 환경(NAT)에서는 외부에서 내부로 들어오는 모든 요청을 보안상의 이유로 차단합니다.

하지만 특정 포트로 들어오는 요청은 내부의 IP로 연결해준다. (특정 포트에 대한 외부 접속 허용)

1) 주의사항
 1-1) 고정 IP 설정: DHCP에 의해 내 PC의 사설 IP가 바뀌면 포트 포워딩 규칙이 깨집니다. 
                  따라서 서버용 PC는 공유기 설정에서 IP를 고정해두는 것이 좋습니다.
 1-2) 보안 위험: 포트를 연다는 것은 대문을 열어두는 것과 같습니다. 
                불필요한 포트는 닫아두고, 연다면 반드시 비밀번호나 인증 설정을 강력하게 해야 합니다.
 1-3) 이중 NAT: 통신사 모뎀과 별도의 공유기를 같이 쓰는 경우, 양쪽 모두에서 포트 포워딩을 해줘야 하는 번거로움이 생길 수 있습니다.
```
