Vibe Coding 공부 노트
=================


1\. MVP(Minimum Viable Product)
----------------------------------------
```
최소 기능 제품
핵심 기능만 갖춘 초기 버전의 제품
시장 반응을 빠르게 얻기 위해 개발


30분 만에 MVP(Minimum Valuable Product) 만들기
Step 1: 문제 정의 (5분)
Step 2: 핵심 기능 정리 (5분)
Step 3: PRD 생성 후 Lovable에 요청 (20분)
```


2\. PRD(Product Requirements Document)
----------------------------------------
```
제품 요구사항 문서
= 건축 설계도
AI가 명확한 지시를 받을수록 더 좋은 결과물을 만들어냄
바이브코더를 위한 PRD 작성법은 다음과 같습니다.

🎯 PRD 필수 요소 5가지

1. 문제 정의 (Problem)
2. 해결책 (Solution)
3. 주요 기능 (Features)
4. 사용자 시나리오 (User Flow)
5. 성공 지표 (Success Metrics)
```

3\. MCP(Model Context Protocol)
----------------------------------------
```
Model Context Protocol (MCP). 이름은 어렵지만 개념은 아주 간단합니다. AI 에이전트를 위한 '만능 리모컨' 이라고 생각하면 가장 쉽습니다.

TV, 에어컨, 오디오를 각각 다른 리모컨으로 조작하려면 무척 번거롭겠죠? 만약 모든 기기를 조작할 수 있는 '만능 리모컨'이 있다면 어떨까요? 훨씬 편리할 겁니다.

- 나 (AI 에이전트): 리모컨을 사용하는 사람입니다.
- 만능 리모컨 (MCP): AI가 다양한 외부 도구들과 소통할 수 있도록 만들어진 '표준화된 조작 방식(프로토콜)'입니다.
- 각종 기기 (외부 도구): 데이터베이스(Supabase), 파일 시스템, 웹 브라우저 등 AI가 조작하고 싶은 대상들입니다.

Supabase
    ### 1단계: 방명록 '테이블' 만들기
    먼저 AI에게 방명록 글을 저장할 데이터베이스 공간을 만들라고 지시합니다.
    
    > [간단한 프롬프트 예시]
    "Supabase MCP 를 이용해서 데이터베이스 연동해줘" → 필요한 테이블 알아서 분석한 다음에 설정해줌.
    > [정확한 프롬프트 예시]
    "Supabase MCP를 사용해서 방명록 글을 저장할 'guestbook' 테이블을 만들어줘. 작성자 이름을 저장할 'author' 컬럼과, 메시지를 저장할 'message' 컬럼이 필요해."

    ### 2단계: 방명록 글 '작성' 기능 구현하기
    사용자가 글을 남길 수 있는 입력창과 버튼을 만들고, 버튼을 누르면 데이터가 저장되도록 요청합니다.
    
    > [간단한 프롬프트 예시]
    사용자가 글을 남길 수 있는 입력창과 버튼을 만들고, 버튼을 누르면 데이터가 저장되도록 해줘.
    > [정확한 프롬프트 예시]
    "작성자 이름과 메시지를 입력할 수 있는 폼(form)을 만들어줘. '글 남기기' 버튼을 누르면, Supabase MCP를 사용해서 'guestbook' 테이블에 입력된 이름과 메시지를 저장하는 기능을 구현해줘."

    ### 3단계: 방명록 목록 '불러오기' 기능 구현하기
    마지막으로, 저장된 모든 글을 화면에 보여주는 기능을 만듭니다.
    
    > [간단한 프롬프트 예시]
    저장된 모든 글을 화면에 보여주는 기능을 만들어줘.
    > [프롬프트 예시]
    "페이지가 열리면, Supabase MCP를 사용해서 'guestbook' 테이블에 저장된 모든 글을 가져와줘. 가장 최근에 작성된 글이 제일 위에 보이도록 정렬해서, 작성자와 메시지를 목록 형태로 화면에 표시해줘."
```
