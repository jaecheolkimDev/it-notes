NEST.JS
====================


1\. 기능
--------------------------------------
```
- Spring에서는 어노테이션만 가지고 처리할 수 있는 부분이 굉장히 많지만 Nest.js는 한계점이 존재한다.
  이 때문에 캐싱에 대한 처리를 일일이 로직으로 짜주어야 하는 경우가 많다.
- Vercel은 프론트엔드 개발자의 배포 과정을 단순화하고 최적화하는 데 주력
```

2\. 리눅스에서 Nest.js 프로젝트 만들기
--------------------------------------
```
$ npm i -g @nestjs/cli  : Nest CLI 설치
$ nest new my-server    : nest new {프로젝트명}
```
