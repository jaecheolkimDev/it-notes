JPA 메서드명 공부 노트
===========================================

1\. findBy
-----------------------
```
1) 명칭
2-1) OrderBy + 속성명 + 정렬방향(Asc/Desc)
2-2) Sort를 별도의 파라미터로 받는 방법도 있다. (다중조건도 가능하다.)
    ex) List<User> findByName(String name, Sort sort);
        List<User> users = userRepository.findByName("John", Sort.by(Sort.Order.desc("createDate")));
```
