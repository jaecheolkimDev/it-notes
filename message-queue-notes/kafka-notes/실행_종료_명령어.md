Kafka 실행/종료 명령어 공부 노트
====================


1\. Kafka 서버 실행/종료
--------------------------------------
```
1) 카프카 서버 실행
    $ bin/kafka-server-start.sh config/server.properties            : 포그라운드에서 실행 (서버 종료 : Ctrl+c)
    $ bin/kafka-server-start.sh -daemon config/server.properties    : 백그라운드에서 실행
    $ bin/kafka-server-start.sh -daemon config/server2.properties
    $ bin/kafka-server-start.sh -daemon config/server3.properties
2) 카프카 서버 로그 확인
    $ tail -f logs/kafkaServer.out                                  : 백그라운드에서 실행되고 있는 kafka 서버의 로그 확인하기
3) 카프카 서버 실행 중인지 확인하는 방법
    $ sudo lsof -i:9092                                             : 9092번 포트에서 실행 중인 프로세스 조회
4) 카프카 종료하기
    $ bin/kafka-server-stop.sh
```
