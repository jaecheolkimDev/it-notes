k3s
=================

1\. k8s 문제점
--------
```
1. 복잡한 설치 과정
    쿠버네티스를 입문하는 입장이거나 Devops 엔지니어가 되려는 사람이 아니라면 쿠버네티스를 직접 설치할 일은 극히 드물다. 
    심지어 Devops 엔지니어라고 할 지라도 최근에는 쿠버네티스를 직접 설치하는 일은 드물다. 
    왜냐하면 AWS 자체에서 쿠버네티스 서비스(EKS)를 제공하고 있기 때문이다. 
    
2. EC2 인스턴스를 3대 만들어야 한다는 비용적인 부담
    어떤 기술이든 자유롭게 막 써볼 수 있는 환경이 중요하다. 이렇게도 써보고 저렇게도 써봐야 빨리 익숙해진다. 
    하지만 비용이 부담스러워서 EC2에서 자유롭게 쿠버네티스를 활용하기가 망설여질 것이다.
```

2\. k3s 사용 이유
--------
```
쿠버네티스(k8s)의 경량 버전으로 설치가 간단하며, 컴퓨팅 리소스를 훨씬 적게 먹는다. 
k3s를 활용하면 위에서 얘기한 2가지 단점을 해결할 수 있다. 
```

3\. 개념
--------
```
실제 **운영 환경(Production)**에서도 쓸 수 있도록 쿠버네티스에서 불필요한 기능을 걷어내고 아주 가볍게 만든 '경량화 쿠버네티스'입니다.
```
