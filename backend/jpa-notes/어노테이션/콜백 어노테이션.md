콜백 어노테이션
======================

8\. 정의
--------------
```
JPA 생명주기(Lifecycle)에 따라 함께 자주 쓰이는 이벤트 어노테이션들입니다.
```

8\. 종류
--------------
```
어노테이션           실행 시점
@PrePersist     엔티티가 DB에 INSERT 되기 직전
@PostPersist    엔티티가 DB에 INSERT 된 직후
@PreUpdate      엔티티가 DB에 UPDATE 되기 직전
@PostUpdate     엔티티가 DB에 UPDATE 된 직후
@PreRemove      엔티티가 DB에서 DELETE 되기 직전
@PostRemove     엔티티가 DB에서 DELETE 된 직후
@PostLoad       엔티티가 DB에서 조회(SELECT)된 직후
```
