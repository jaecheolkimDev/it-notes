데이터베이스 초기화 전략
======================

1\. spring.jpa.hibernate.ddl-auto
--------------
```
JPA(Hibernate)가 애플리케이션을 실행할 때 Entity 매핑 정보를 기반으로 DB 스키마(테이블, 제약조건 등)를 어떻게 관리할지 결정하는 
설정입니다.
```

2\. 종류
--------------
```
- none          : 사용하지 않음
    none 설정 시 JPA/Hibernate가 여전히 수행하는 주요 영역
        1) 시퀀스 메타데이터 조회 및 Nextval 호출
         - 시퀀스 전략 사용 시, 저장 시점에 DB 시퀀스 객체의 존재 유무와 다음 번호를 조회합니다.
        2) 외래 키 및 테이블 매핑 검증
         - 엔티티 간 연관관계(@ManyToOne, @OneToMany) 설정 시, JPA는 내부적으로 어떤 컬럼으로 Join할지 매핑 구조를 검증하고 엔티티 메타데이터를 등록합니다.
        3) Dialect(방언)를통한 DB 호환성 확인
         - 설정된 DB Dialect에 따라 해당 DB가 시퀀스를 지원하는지, Identity(Auto-Increment)를 지원하는지 체크합니다.
- create        : 기존 테이블 삭제 후 테이블 생성
- create-drop   : 기존 테이블 삭제 후 테이블 생성. 종료 시점에 테이블 삭제
- update        : 변경된 스키마 적용
- validate      : 엔티티와 테이블 정상 매핑 확인
```
