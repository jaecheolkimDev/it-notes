비동기
=================

1\. @EnableAsync , @Async
------------------
```
Spring Framework에서 비동기 메소드 실행(Asynchronous Method Execution) 기능을 활성화할 때 사용하는 어노테이션입니다.

기본적으로 Spring의 메소드 호출은 동기(Synchronous) 방식으로 작동합니다. 즉, A 메소드가 B 메소드를 호출하면 B의 작업이 완료될 
때까지 A 메소드가 대기(Blocking)합니다.

하지만 @EnableAsync를 설정 클래스(@Configuration)에 붙이면, @Async 어노테이션이 붙은 메소드들을 별도의 스레드(Thread)에서 
비동기로 실행할 수 있게 됩니다.
```
