BEAN
=================

1\.개념
---------------
```
스프링 컨테이너에 의해 관리되는 객체(인스턴스)
```

2\. 라이프사이클
------------------
스프링 컨테이너 생성 -> 스프링 빈 생성 -> 의존관계 주입 -> 초기화 콜백(@PostConstruct) 
-> 사용 -> 소멸 콜백(@PreDestroy) -> 스프링 종료
```
인터페이스 InitializingBean 상속하여 afterPropertiesSet 메서드를 재정의하여 스프링 빈 생명주기를 관리하는 
방법이 있다.
    - afterPropertiesSet 메서드는 의존관계 주입을 모두 마친 직후에 호출된다.
    - 해당 클래스로 만든 객체(Bean)에 귀속되는 인터페이스입니다.
```

5\. 등록
------------------
```
@Component, @Service, @Repository, @Controller 등의 어노테이션이나 @Bean 메서드로 등록됨
```
