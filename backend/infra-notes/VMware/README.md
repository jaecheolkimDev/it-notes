VMware
======================

1\. 정의
--------------
```
컴퓨터 하드웨어 자원을 가상화하여 하나의 물리적 서버나 PC에서 여러 개의 운영체제(OS)를 동시에 실행할 수 있게 해주는 가상화 솔루션 
기업이자 소프트웨어입니다.

물리적 기계 위에 가상 머신(VM, Virtual Machine)을 생성하는 기술을 바탕으로 기업용 클라우드 인프라부터 개인 개발 환경까지 폭넓게 
활용됩니다.
```

1\. VMware의 핵심 원리: 하이퍼바이저 (Hypervisor)
--------------
가상화의 핵심은 하이퍼바이저라는 중간 관리 계층입니다. 하이퍼바이저는 물리 서버의 CPU, 메모리, 디스크 등의 자원을 조각내어 각 가상 
머신(VM)에 독립적으로 할당합니다.
```
하이퍼바이저는 동작 방식에 따라 크게 두 가지로 나뉩니다.
1) Type-1 (Bare-Metal)  : 하드웨어 바로 위에 가상화 전용 OS가 설치되는 방식입니다. 오버헤드가 적고 성능이 뛰어나 기업 서버 환경에 
                            주로 쓰입니다. (예: VMware ESXi)
2) Type-2 (Hosted)      : 기존 운영체제(Windows, macOS 등) 위에 일반 프로그램처럼 설치되는 방식입니다. 개인 개발자나 테스트 
                            환경에 적합합니다. (예: VMware Workstation, Fusion)
```

1\. 주요 제품군 및 특징
--------------
```
제품명                 구분의 종류                  주요 용도 및 특징
VMware ESXi         Type-1 하이퍼바이저           데이터센터 서버 하드웨어에 직접 설치되는 고성능 가상화 OS
VMware vCenter      통합 관리 중앙 플랫폼            여러 대의 ESXi 호스트 서버와 가상 머신을 한곳에서 관리·제어
VMware vSphere      기업용 가상화 패키지             ESXi와 vCenter 등을 묶은 enterprise급 클라우드 인프라 플랫폼
VMware Workstation  Type-2 (Windows/Linux)      PC 환경에서 개발 및 테스트용으로 여러 OS를 띄울 때 사용
VMware Fusion       Type-2 (macOS)              Mac에서 Windows나 Linux 환경을 실행할 때 사용
VMware Tanzu	    쿠버네티스 및 앱 현대화 플랫폼	기존 vSphere 인프라 위에서 컨테이너(Docker/K8s) 환경을 구동·관리·배포하는 클라우드 네이티브 솔루션
```

1\. VMware를 사용하는 주요 이유
--------------
```
1) 자원 효율성 증대: 하나의 물리 서버 운영률을 10~20%에서 70~80% 이상으로 극대화하여 서버 구매 및 유지 비용을 절감합니다.
2) 격리성 및 보안: 한 VM에 장애가 발생하거나 바이러스에 감염되어도 다른 VM이나 물리 시스템으로 전염되지 않습니다.
3) 스냅샷 및 복구: 특정 시점의 OS 상태를 스냅샷으로 저장해두면, 에러나 설정 오류가 발생했을 때 즉시 과거 상태로 복구할 수 있습니다.
4) 유연한 이동성 (vMotion): 서비스 중단 없이 가상 머신을 A 서버에서 B 서버로 실시간 이동(Live Migration)할 수 있습니다.

참고: 최근 IT 시장 트렌드에서는 가상 머신(VMware) 수준의 가상화 외에도, OS 커널을 공유하며 한층 가볍게 애플리케이션을 실행하는 
        도커(Docker)나 쿠버네티스(Kubernetes) 같은 컨테이너 가상화 기술을 VMware와 함께 혼용하는 추세입니다.
```
