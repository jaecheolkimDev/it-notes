chunkStrategy (청크 전략)
======================

1\. 정의
--------------
```
방대한 텍스트 데이터를 LLM이 읽고 임베딩(Embedding)하기 좋은 적당한 크기의 덩어리('청크')로 어떻게 나눌 것인가에 대한 규칙을 
말합니다.
```

1\. 종류
--------------
```
1) sentence-boundary-aware  : 
 - 문맥을 무시하고 글자 수로 무조건 자르는 것이 아니라, 문장의 경계(마침표, 물음표 등)를 인식하여 문장이 중간에 끊기지 않도록 나누는 
   전략입니다.
```
