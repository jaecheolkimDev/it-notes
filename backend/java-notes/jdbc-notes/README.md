JDBC 공부 note
======================


1\. 라이브러리
--------------
```
JDBC 연결을 가로채서(Proxy) 로그를 남기는 라이브러리
JDBC를 사용하는 모든 자바 애플리케이션(순수 자바, Java EE, Spring, Spring Boot 등)에서 사용할 수 있습니다. 

핵심 특징   :
    JDBC 드라이버 래퍼(Wrapper)   : 실제 DB 드라이버 위에 위치하여 SQL 문과 파라미터를 가로채서 로깅합니다.
    어플리케이션 코드 변경 없음     : 데이터 소스 설정(URL, Driver)만 변경하면 쿼리 로그를 볼 수 있습니다.
    사용 환경                    : 순수 자바 애플리케이션, Tomcat/WebLogic 등의 WAS 환경, Spring 프로젝트 모두 적용 가능. 

Log4jdbc    : JDBC 3.0/4.0/4.1 등을 지원하는 자바 드라이버
 - 구버전이거나 업데이트가 중단된 형태
P6Spy       : JDBC 드라이버를 인터셉트하는 오픈 소스 프레임워크로, spy.properties 설정을 통해 자바 프로그램 어디서든 동작합니다.
 - 최근 개발 환경(특히 스프링 부트 2.x, 3.x)에서는 log4jdbc 대신 p6spy를 사용하는 것이 일반적입니다.   
```
