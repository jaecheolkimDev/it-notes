2\. 객체와 클래스의 차이점
-----------
```
클래스(Class)          : 현실 세계의 객체의 속성과 동작을 추려내 필드와 메서드로 정의한 것으로 "아직 메모리가 할당되지 않은 상태"
객체(Object)          : 이 Class라는 설계도를 기반으로 실제 메모리가 잡힌 것
OOP(객체지향 프로그래밍) : 객체를 조합해 전체 프로그램을 완성해 나가는 방식
```
