JAVA Escape
=================

1\. Escape란?
-----------
백슬래시(\)
```
- 컴퓨터에게 어떤 글자가 "화면에 그냥 출력할 일반 글자"인지, 아니면 "줄바꿈이나 탭처럼 특별한 기능을 수행하는 명령"인지를 명확하게 구분해 주기 위해서 
  이스케이프(Escape) 문자가 존재합니다.
- 이스케이프 문자를 작성하는것을 '탈출(Escape)시킨다'고 표현합니다.
```

2\. 사용 사례
-----------
```
1) 문자열 안에서 따옴표(") 그 자체를 표현하기 위해
- 이때 백슬래시(\)를 사용하면 컴퓨터에게 "어이, 바로 뒤에 나오는 따옴표는 문자열 끝을 알리는 기호가 아니라, 그냥 평범한 따옴표 글자니까 그대로 출력해 줘!" 
  하고 신호를 줄 수 있습니다.
  
2) 눈에 보이지 않는 '기능'을 문자로 표현하기 위해
- 키보드로 엔터(Enter)를 치거나 탭(Tab) 키를 누르는 것은 눈에 보이지 않는 '기능'입니다. 소스 코드 안에서 줄바꿈을 코드에 그대로 적으면 자바는 이를 
  문자열로 인정하지 않고 에러를 냅니다.
```
