멀티스레드
=================

4\. 메인 스레드 (Main Thread)
-----------
```
1) 프로그램이 실행될 때 운영체제(OS)에 의해 가장 먼저 생성되는 최초의 스레드입니다.
2) main() 메서드나 프로그램의 진입점(Entry Point)을 실행하며, UI 이벤트 처리나 다른 작업자 스레드들을 생성하고 관리하는 중심 
    역할을 맡습니다.
```

4\. 나머지 스레드들
-----------
메인 스레드가 아닌 나머지 스레드들은 구현 방식이나 역할에 따라 주로 다음과 같이 부릅니다.
```
1) 작업자 스레드 (Worker Thread) 또는 백그라운드 스레드 (Background Thread)
 - 메인 스레드 외에 특정 작업을 수행하기 위해 별도로 생성된 스레드들을 통칭합니다.
 - 주로 메인 스레드가 멈추거나(Blocking) 느려지는 것을 막기 위해, 네트워크 요청, 파일 I/O, 무거운 연산 등 시간이 걸리는 
    백그라운드 작업을 처리합니다.
2) 종속성(Daemon)에 따른 구분
 - 데몬 스레드 (Daemon Thread): 주 스레드(메인 스레드 등)가 종료되면 작업 완료 여부와 상관없이 강제로 함께 종료되는 보조 
    스레드입니다.
 - 사용자 스레드 (User/Non-Daemon Thread): 메인 스레드가 종료되더라도 자신의 작업이 끝날 때까지 독립적으로 계속 살아있는 
    스레드입니다.
```
