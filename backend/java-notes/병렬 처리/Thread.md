자바 스레드(Thread)의 생성, 상태 제어 메서드, 그리고 synchronized를 활용한 동기화
=================

1\. 생성 방식
-----------
```
1) Thread 클래스 상속
2) Runnable 인터페이스 구현 (참고: Runnable은 상속이 아닌 '구현(implements)'합니다)

* 우선순위 (priority): 스레드의 실행 우선순위를 설정하여 CPU 자원 할당 가능성을 조정.
```

2\. 상태 제어 및 메서드
-----------
```
1) 블록 상태 (Blocked / Waiting): 특정 조건이 충족되거나 락(Lock)을 얻을 때까지 실행 대기(Runnable) 상태로 전환되지 못하는 상태.
2) yield(): 다른 스레드에게 execution 시간을 양보 (블록 상태로 들어가지는 않고 실행 대기 상태 유지).
3) sleep(): 지정된 시간 동안 스레드를 일시 정지(Waiting) 상태로 만들고 CPU 제어권을 OS에 반환.
4) join(): 지정한 스레드가 작업을 마칠 때까지 현재 스레드가 대기하여 실행 순서를 제어.
```

3\. 동기화
-----------
```
1) synchronized 키워드 / 블록:
 - 단일 JVM 내에서 공유 자원에 대한 동시 접근을 막는 락(Lock) 메커니즘.
 - 객체의 모니터 락(Monitor Lock)을 획득/해제하여 동기화 보장.
2) wait(), notify(), notifyAll():
 - 조건: 반드시 synchronized 블록/메서드 내부에서 호출되어야 함.
 - wait(): 락을 내려놓고 스레드를 일시 정지 상태로 만듦.
 - notify() / notifyAll(): 일시 정지 중인 스레드 하나 또는 전체를 다시 실행 대기 상태로 깨움.
```
