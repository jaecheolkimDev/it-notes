Set
=================

1\. 정의
-----------
```
"중복을 허용하지 않고, 순서가 유지되지 않는" 자료구조
```

2\. 데이터 추가 및 삭제
-----------
```
1) add(E e): 데이터를 추가합니다. (중복된 데이터가 없어서 성공하면 true, 이미 있어서 실패하면 false 반환)
2) remove(Object o): 특정 데이터를 삭제합니다. (삭제 성공 시 true, 없으면 false 반환)
3) clear(): Set 안의 모든 데이터를 삭제하여 비웁니다.
```

3\. 데이터 확인 및 크기
-----------
```
1) contains(Object o): Set 안에 특정 데이터가 들어있는지 확인합니다. (true / false)
2) isEmpty(): Set이 비어있는지 확인합니다.
3) size(): Set에 저장된 전체 데이터(원소)의 개수를 반환합니다.
```

4\. 데이터 꺼내기 (순회)
-----------
Set은 인덱스(방 번호)가 없기 때문에 get(0) 같은 방식으로 데이터를 꺼낼 수 없습니다. 대신 아래 방법들을 사용합니다.
```
1) iterator(): 데이터를 하나씩 꺼내기 위한 Iterator 객체를 반환합니다.
2) 향상된 for문: 실무에서 가장 편하게 쓰는 방식입니다.
```

5\. 집합 연산 명령어 (교집합, 합집합, 차집합)
-----------
수학의 집합 개념을 구현할 수 있는 유용한 메서드들입니다. 기존 Set의 데이터가 변경되므로 주의해서 사용해야 합니다.
```
1) addAll(Collection c) (합집합): 다른 컬렉션의 모든 데이터를 현재 Set에 추가합니다.
2) retainAll(Collection c) (교집합): 다른 컬렉션과 공통으로 가진 데이터만 남기고 나머지는 삭제합니다.
3) removeAll(Collection c) (차집합): 다른 컬렉션에 있는 데이터들을 현재 Set에서 모두 삭제합니다.
4) containsAll(Collection c) (부분집합 확인): 현재 Set이 다른 컬렉션의 모든 데이터를 포함하고 있는지 확인합니다.
```

6\. Set의 대표적인 3가지 종류와 차이점
-----------
어떤 객체로 생성하느냐에 따라 내부 동작(순서, 정렬)이 완전히 달라집니다.
```
JavaSet<String> hashSet = new HashSet<>();
Set<String> linkedHashSet = new LinkedHashSet<>();
Set<String> treeSet = new TreeSet<>();

구현 클래스          특징                          정렬 및 순서             추천 상황
HashSet         가장 기본적이고 대중적인 Set       순서 전혀 없음 ❌      성능이 가장 중요하고 순서가 상관없을 때
LinkedHashSet   중복은 제거하되 넣은 순서 기억       삽입 순서 유지 ⭕      중복은 없어야 하는데, 내가 넣은 순서대로 정렬되어야 할 때
TreeSet         이진 검색 트리 구조로 저장         값에 따라 자동 정렬 ⭕       오름차순/내림차순 등 데이터 정렬이 필요할 때
```
