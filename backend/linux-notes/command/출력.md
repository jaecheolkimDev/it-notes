리눅스 명령어 공부 note
======================

1\. cat : 파일 내용 출력 (짧은 내용에서 사용 권장)
--------------
```
#### cat — 파일 내용을 출력하거나 병합하는 명령어(입력파일·출력·파이프가 구성요소)
- 정의: `cat`은 입력파일, 출력(표준출력), 파이프 사용을 통해 파일 내용을 표시하는 명령어.

- 주요 옵션:
    - `-b`  : 각 행에 번호 붙여서 출력하기
    - `-n`  : 빈 행에 번호 붙여서 출력하기 
    
```

2\. tail : 로그 마지막 줄 실시간 출력
--------------
```
#### tail — 파일의 마지막 몇 줄을 출력하는 명령어(파일명·라인 수·옵션이 구성요소)
- 정의: `tail`은 파일명, 라인 수, 옵션(-f, -n 등)을 사용하여 파일의 마지막 부분을 출력하는 명령어.
    - 기본적으로 마지막 10줄을 출력.
    - 실시간 로그 확인 시 유용.

- 주요 옵션:
    - `-f`: 파일의 끝부분을 지속적으로 출력(로그 파일 모니터링에 사용).
    - `-n [숫자]`: 출력할 줄 수를 지정.
    - `-c [숫자]`: 출력할 바이트 수를 지정.

- 사용 예시:
    - `$ tail file.txt`: `file.txt`의 마지막 10줄 출력.
    - `$ tail -n 20 file.txt`: `file.txt`의 마지막 20줄 출력.
    - `$ tail -f log.txt`: `log.txt`의 실시간 업데이트 내용 출력.
    - `$ tail -300f log.txt`: `log.txt`의 실시간 업데이트 내용을 300줄 출력.
    
- 종료 방법 : ctrl + c
```

3\. less — 파일 내용을 한 화면씩 출력하며 탐색할 수 있는 명령어(파일명·탐색·옵션이 구성요소)
--------------
```
- 정의: `less`는 파일명, 탐색(앞/뒤로 이동), 옵션을 사용하여 파일 내용을 한 화면씩 출력하며 탐색할 수 있는 명령어.
    - `cat` 명령어와 달리, 대용량 파일을 효율적으로 탐색 가능.
    - 파일을 읽기 전용으로 열며, 수정은 불가능.

- 주요 탐색 키:
    - `Space`: 다음 화면으로 이동.
    - `b`   : 이전 화면으로 이동.
    - `Enter`: 한 줄씩 아래로 이동.
    - `k`   : 한 줄 위로 이동.
    - `q`   : 종료.
    - `G`   : 파일의 끝(End of file)으로 이동
    - `/`   : 특정 문자열 검색
        - n (Next): 다음 검색 결과(아래 방향)로 이동합니다.
        - N (Shift + n): 이전 검색 결과(위 방향)로 이동합니다.

- 주요 옵션:
    - `-N`: 각 줄의 번호를 표시.
    - `-S`: 긴 줄을 잘라내지 않고 가로 스크롤 가능.
    - `+/[검색어]`: 파일 열 때 특정 문자열 검색.
    - `-X`: 종료 시 화면을 지우지 않고 내용 유지.

- 사용 예시:
    - `$ less file.txt`: `file.txt`의 내용을 한 화면씩 출력.
    - `$ less -N file.txt`: 줄 번호를 표시하며 파일 내용 출력.
    - `$ less +/pattern file.txt`: `file.txt`에서 `pattern`을 검색하며 열기.
    - `$ less -S file.txt`: 긴 줄을 잘라내지 않고 가로 스크롤 가능.
    - `$ grep "에러코드" logfile.log | less`    : 특정 단어가 포함된 줄만 보고 싶을때
    - `$ less +G file.txt`      : 파일을 열자마자 마지막 페이지로 이동하고 싶을때
```
