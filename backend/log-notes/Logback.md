Logback
======================

1\. 정의
--------------
Logback은 자바(Java) 애플리케이션에서 가장 널리 사용되는 로그(Log) 기록 라이브러리입니다.
```
애플리케이션이 실행될 때 발생하는 다양한 정보(사용자 요청, DB 쿼리, 에러 메시지 등)를 콘솔이나 파일, DB 등에 체계적으로 
남겨주는 역할을 합니다.
```

1\. 특징
--------------
Log4j의 단점을 보완한 후속작
```
1) 빠른 속도와 높은 성능 : 이전 Log4j 대비 실행 속도가 향상되고 메모리 사용량이 줄었습니다.
2) 유연한 설정 지원    : 애플리케이션을 재시작하지 않고도 로깅 설정 파일의 변경 사항을 실시간으로 반영(Auto Reload)할 수 있습니다.
3) 로그 파일 자동 관리  : 날짜나 파일 크기 단위로 로그 파일 삭제 및 압축 저장(Rolling)을 손쉽게 설정할 수 있습니다.
```

1\. logback-spring.xml이란?
--------------
logback-spring.xml은 스프링 부트(Spring Boot) 환경에 특화된 Logback 설정 파일입니다.
```
1) 프로필(Profile)별 분기 설정 가능
    개발 환경(dev), 테스트 환경(test), 운영 환경(prod)에 따라 필요한 로그 수준이나 저장 위치를 다르게 지정할 수 있습니다.
2) application.yml / properties 변수 참조 가능
    application.yml에 정의된 설정값(예: 로그 저장 경로, 서비스 명 등)을 설정 파일 내에서 <springProperty> 태그로 불러와 
    사용할 수 있습니다.
```
