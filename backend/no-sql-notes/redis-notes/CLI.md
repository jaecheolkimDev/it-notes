redis-cli
===============

1\. 접속 방법
-----------
```
1) 기본 접속                       : redis-cli
2) 원격 서버 접속 (IP/포트가 다른 경우):
    - redis-cli -h [Redis_IP] -p [포트번호]
    - redis-cli -p [포트번호]
```

2\. 데이터베이스
-----------
Redis는 기본적으로 0번부터 15번까지 총 16개의 논리적인 데이터베이스(DB)를 가지고 있습니다. 
특정 번호의 DB로 이동하려면 SELECT 명령어를 사용하면 됩니다.
```
DB 이동: SELECT [DB번호]
    예: 1번 DB로 가고 싶다면? SELECT 1
```

3\. 조회
-----------
```
1) 키 찾기 (패턴 검색):    KEYS SCHD::7::202605070500
                        KEYS SCHD::*::202605070500

2) 데이터 내용 확인 (키가 존재할 경우):   SMEMBERS [찾은_키_이름]
                                    SMEMBERS SCHD::7::202605070500

3) 키의 남은 수명(TTL) 확인:            TTL [찾은_키_이름]
```
