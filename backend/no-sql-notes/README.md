NoSQL(Not Only SQL)
===============
테이블 관계를 고정하지 않고 문서, 키-값, 그래프 등 유연한 데이터 모델을 사용하여 대규모 비정형 데이터를 빠르게 처리하는 비관계형 데이터베이스입니다.

1\. 종류별 특징 및 비교
-----------
```
구분	        대표 주자	        특징	                        장점	                                단점
Key-Value	Redis, Memcached	키와 값으로만 이루어진 단순 구조	가장 빠름, 단순함	                    복잡한 쿼리(조건 검색) 불가능
Document	MongoDB	            JSON 형태로 데이터를 저장	    유연한 스키마, 복잡한 데이터 구조화 가능	Redis보다 느림, 메모리 사용량 높음
Wide-Column	Cassandra, HBase	행마다 칼럼 구성이 다를 수 있음	쓰기 성능 최강, 대규모 확장성	        설정과 운영이 매우 까다로움
Graph	    Neo4j	            데이터 간의 '관계'를 저장	    관계 추적(SNS 친구, 추천)에 최적	    범용적인 저장소로 쓰기 어려움
```
