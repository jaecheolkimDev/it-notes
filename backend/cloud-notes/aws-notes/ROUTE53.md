7\. DNS란?
-----------
```
DNS(Domain Name System) 서비스
 - 도메인을 발급하고 관리해주는 서비스
 - 문자를 IP 주소로 변환해주는 하나의 시스템(서버)

* IP 주소에는 HTTPS 적용을 할 수가 없다. 도메인 주소가 있어야만 HTTPS 적용을 할 수 있다.
* 각 서비스마다 구매할 수 있는 도메인의 종류가 다르다.(Route53, gabia, whois)
```


8\. Route53에서 도메인 구매
-----------
```
1. 도메인 등록 선택하고 시작하기
2. 도메인 검색하고 선택하기
3. 가격 확인하고 결제하기(이메일 정확하게 등록 필요)
4. 도메인 구매 잘 됐는 지 확인하기(호스팅 영역, 등록된 도메인)
```


9\. Route53의 도메인을 EC2에 연결하기
-----------
```
1. 호스팅 영역 메뉴에 들어가서 레코드 생성 버튼 누르기
2. 레코드 생성하기
 - 레코드 유형
      - A 레코드       : 도메인을 특정 IPv4 주소에 연결시키고 싶을 때 사용하는 레코드 유형이다. 
      - CNAME 레코드   : 도메인을 특정 도메인 주소에 연결시키고 싶을 때 사용하는 레코드 유형이다. 
       ex) www.naver.com을 적으면 여기로 이동.
 - 서브도메인
  - 구매한 도메인의 앞에 이름을 적으면 서브도메인이 된다.
   ex) {here}.naver.com
```
