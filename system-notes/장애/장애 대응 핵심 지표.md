장애 대응 핵심 지표
=================

1\. 정의
-----------
```
시스템의 안정성과 장애 대응 역량을 평가할 때 자주 쓰이는 핵심 지표(Metric)들입니다. 
장애를 감지하고, 원인을 찾고, 복구하기까지의 단계별 주요 용어
```

2\. 장애 대응 핵심 지표 요약
-----------
```
용어                                      주요 역할 및 의미                                          목표 방향
TTD(Time to Detect)                     장애가 발생한 순간부터 이를 감지할 때까지 걸린 시간               낮을수록 좋음
TTA(Time to Acknowledge)                장애가 감지된 후 담당자가 인지하고 조사를 시작할 때까지의 시간     낮을수록 좋음
TTM(Time to Mitigate)                   "장애 영향을 최소화(임시 조치, 우회 등)하는 데 걸린 시간"         낮을수록 좋음
TTR(Time to Resolve / Recover)          장애 발생 시점부터 완전히 정상 상태로 복구될 때까지의 시간         낮을수록 좋음
MTTR(Mean Time to Repair / Recovery)    여러 장애 사례 발생 시 평균 복구 시간                          낮을수록 좋음
MTBF(Mean Time Between Failures)        장애 복구 후 다음 장애가 발생하기까지의 평균 시간 (시스템 신뢰성)  높을수록 좋음
MTTF(Mean Time to Failure)              복구 불가능한 시스템이 고장 날 때까지 걸린 평균 시간              높을수록 좋음
```

3\. 주요 지표 상세 설명
-----------
```
1) TTD (Time to Detect, 감지 시간)
 - 개념: 장애 발생 시점부터 모니터링 시스템이나 사용자 제보를 통해 장애를 알게 된 시점까지의 시간입니다.
 - 핵심: 정교한 모니터링 및 알림(Alerting) 시스템을 구축하여 TTD를 줄이는 것이 장애 대응의 첫 단계입니다.
2) TTA (Time to Acknowledge, 인지 시간)
 - 개념: 장애 알림이 발생한 후, 담당 엔지니어가 해당 알림을 확인하고 작업(Investigation)을 시작했다고 승인하기까지의 시간입니다.
 - 핵심: 당직/온콜(On-call) 체계가 얼마나 잘 작동하는지 측정하는 지표입니다.
3) TTM (Time to Mitigate, 완화 시간)
 - 개념: 근본 원인을 찾지 못했더라도, 서킷 브레이커 작동, 롤백, 트래픽 우회 등을 통해 사용자에게 미치는 피해를 먼저 줄이는 데 걸리는 시간입니다.
 - 핵심: 서비스 가용성을 빠르게 확보하기 위해 완전한 해결(Resolve)보다 완화(Mitigate)를 우선시하는 현대 SRE(Site Reliability Engineering)에서 중요하게 여깁니다.
4) MTTR (Mean Time to Repair / Recovery, 평균 복구 시간)
 - 개념: 발생한 장애들을 완전히 해결하여 정상 상태로 돌려놓는 데 걸린 평균 시간입니다.계산식: $\text{MTTR} = \frac{\text{총 장애 복구 시간}}{\text{장애 발생 횟수}}$
 - 핵심: 장애를 아예 안 발생시키는 것은 불가능하므로, MTTR을 극도로 줄이는 것이 운영 안정성의 핵심 목표가 됩니다.
5) MTBF (Mean Time Between Failures, 평균 고장 간격)
 - 개념: 시스템이 정상적으로 작동한 시간의 평균으로, 시스템이 얼마나 안정적인지를 나타냅니다.계산식: $\text{MTBF} = \frac{\text{총 가동 시간}}{\text{장애 발생 횟수}}$
 - 핵심: MTBF가 길수록 시스템의 신뢰성(Reliability)이 높다는 것을 의미합니다.
```

4\. 장애 대응 흐름으로 보는 타임라인
-----------
```
장애 발생 -{TTD}-> 장애 감지 -{TTA}-> 조사 시작 -{TTM}-> 영향 완화 -{TTR}-> 완전 복구
MTBF는 장애가 완전히 복구된 시점부터 다음 장애가 발생할 때까지의 구간을 의미합니다.
```
