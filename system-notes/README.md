System 공부 노트
=================

1\. GMT(그리니치 표준시)
----------------------------------------
```
HTTP 표준 규격 (RFC 7231)
웹의 통신 규약을 정의하는 RFC 문서(표준 가이드라인)에 따르면, HTTP 헤더의 모든 날짜와 시간은 반드시 GMT 또는 UTC를 사용하도록 규정되어 있습니다.
    이유: 서버는 전 세계 어디에나 있을 수 있고, 클라이언트(사용자) 역시 전 세계 어디서 접속할지 모릅니다. 
         각자의 로컬 시간(KST, EST 등)을 사용하면 서로 시간이 맞지 않아 데이터의 유효성을 판단하기 매우 어려워집니다.
         
참고: 한국 시간(KST)과 계산법
     웹 개발자 도구에서 보이는 시간과 실제 한국 시간의 차이는 다음과 같습니다.
        KST = GMT + 9시간
```
