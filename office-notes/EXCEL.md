EXCEL
================

1\. 비교 차트
-----------------------------
```
1) 데이터 준비
    | 작업 항목 | AS-IS(초) | TO-BE(초) |
    | 1       | 120       | 30       |
    | 2       | 300       | 50       |
    | 3       | 150       | 20       |

2) 데이터 범위 선택
3) 삽입 > 차트 > 묶은 세로 막대형
4) 가독성 향상
 - 제목   : 성능 개선 결과 비교 (AS-IS vs TO-BE)
 - AS-IS : 짙은색(회색)
 - TO-BE : 강조색(파란/녹색)
```
