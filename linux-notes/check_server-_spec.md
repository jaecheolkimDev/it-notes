서버 스펙 확인
======================

1\. CPU 스펙 확인
-----------------------
```
$ lscpu                                             : 전체적인 CPU 요약 정보 확인
$ cat /proc/cpuinfo | grep 'model name' | uniq      : 물리 CPU 개수 및 상세 정보 확인
```

2\. 메모리(RAM) 용량 확인
-----------------------
```
$ free -h                                       : 기가바이트(GB) 단위로 쉽게 보기
$ sudo dmidecode -t memory | grep -i size       : 하드웨어 장착 상태 및 속도까지 확인 (Root 권한 필요)
```

3\. GPU 스펙 확인
-----------------------
```
$ nvidia-smi                : NVIDIA GPU 상태 및 VRAM 확인
$ lspci | grep -i nvidia    : 드라이버 미설치 시, 물리적인 GPU 장치 존재 여부 확인
```

4\. 디스크 용량 확인
-----------------------
```
$ df -h                     : 디스크 남은 용량 확인 (인간이 읽기 편한 포맷)
$ lsblk -d -o name,rota     : 디스크 종류 (SSD / HDD) 확인
```

5\. OS 및 커널 버전 확인
-----------------------
```
$ cat /etc/*release     : 리눅스 배포판 버전 확인 (Ubuntu, CentOS, RHEL 등)
$ uname -a              : 커널 버전 확인
```
