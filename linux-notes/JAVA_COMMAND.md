자바 명령어 공부 note
======================

1\. 리눅스 명령어 정리
-----------------------
1) jps  : Java 프로세스 ID와 함께 적용된 JVM 인자(Arguments)를 모두 보여줍니다.
```
    $ jps -v
```

2) 실행 중인 배치의 실제 JVM 옵션 확인
```
    $ jcmd [PID] VM.flags
```

3) JAVA버전에 따른 JVM 디폴트 옵션 확인
```
    $ java -XX:+PrintCommandLineFlags -version
```

2\. jar파일 실행 옵션 설정
-----------------------
java [JVM 옵션] -jar [파일명.jar] [애플리케이션 인자]
```
만약 JVM 옵션(예: -D)을 -jar 뒤에 적으면, JVM은 이를 옵션으로 인식하지 않고 단순한 문자열 인자로 취급하여 프로그램 내부로 넘겨버립니다. 
이 경우 메모리 설정이나 시스템 속성이 적용되지 않으므로 반드시 -jar 앞에 적어야 합니다.
```
