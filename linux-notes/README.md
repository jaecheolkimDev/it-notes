2\. 우분투(Debian 계열)와 레드햇(RHEL/CentOS 계열) 리눅스 비교
-----------------------
```
공통점: 리눅스 커널 기반으로 대부분의 기본 명령어 (ls, cd, grep, ps, top, vi 등)는 동일하게 사용 가능합니다.
차이점: 패키지 설치/관리가 가장 큰 차이점이며, 이는 apt vs yum/dnf 명령어와 .deb vs .rpm 패키지 파일에서 발생합니다.
선택: 서버용은 RHEL/CentOS 계열, 데스크톱 및 초보자에게는 Ubuntu가 일반적으로 선호됩니다. 
```

3\. 개념
-----------------------
```
옵션 : 일반적으로 short option은 하이픈 한 개(-)로 시작하고, long option은 하이픈 두 개(--)로 시작한다. 
 **여러 옵션을 같이 쓸 수 있다.** 
  - 하나의 명령어에서 여러 옵션을 함께 쓸 수 있다. (`ls -l -a`)
  - short option과 long option을 같이 쓸 수 있다. (`ls -l --all`)
  - 옵션끼리는 순서가 상관없다. (`ls -a -l` = `ls -l -a`)
  - short option은 묶어서 한 번에 쓸 수 있다. (`ls -a -l` = `ls -al` = `ls -la`)
  
경로
 - 절대 경로 : **루트 디렉터리를 기준으로** 파일 위치를 표현(경로가 `/`로 시작하면 무조건 절대 경로다.)
 - 상대 경로 : **현재 디렉터리를 기준으로** 파일 위치를 표현(경로가 `/` 이외의 문자로 시작한다.)
  - `.` : 현재 디렉터리 경로를 의미(= `./`)
  - `..` : 상위 디렉터리 경로를 의미
  
홈 디렉터리(~) : /home/{사용자명}
```

1) cd(change directory) : 디렉터리 이동
```
- 정의: `cd`는 **경로 입력**, **상대경로**, **절대경로**를 기반으로 현재 작업 디렉터리를 이동시키는 명령어.
- 사용 예시:
    - `$ cd /`: 리눅스 최상위(루트) 디렉토리로 이동하는 명령어
    - `$ cd ~`: 홈 디렉토리로 이동
    - `$ cd ..`: 현재 디렉터리 경로에서 상위 디렉터리(..)로 이동
    - `$ cd /var/log/apt`: /var/log/apt라는 곳으로 경로 이동
```

2) cp : 파일/디렉터리 복사
```
#### cp — 파일이나 디렉터리를 복사하는 명령어(원본·대상·옵션이 구성요소)
- 정의: `cp`는 **원본 파일**, **대상 파일**, **옵션(-r 등)**을 사용해 파일·디렉터리를 복사하는 명령어.
- 사용 예시:
    - $ cp a.txt ./box # 현재 디렉토리에 있는 a.txt 파일을 ./box 경로로 복사
    - $ cp a.txt b.txt # a.txt 파일을 현재 경로에 b.txt 파일로 이름을 바꿔 복사한다.
    - $ cp -r box box2 # box 디렉터리를 현재 경로에 box 디렉터리로 이름을 바꿔 복사한다.(디렉토리를 복사할 때 -r 옵션을 넣지 않으면 에러 발생)
```

3) mv : 파일/디렉터리 이동 및 이름변경
```
#### mv — 파일 이동 또는 이름 변경을 수행하는 명령어(원본·대상·동작이 구성요소)
- 정의: `mv`는 **원본**, **대상**, **동작(이동/이름변경)**을 기반으로 파일을 이동하거나 이름을 바꾸는 명령어.
```

4) rm(remove) : 파일/디렉터리 삭제
```
#### rm — 파일이나 디렉터리를 삭제하는 명령어(대상·옵션·영구삭제가 구성요소)
- 정의: `rm`은 **대상 파일**, **옵션(-r, -f)**, **영구삭제 동작**을 포함하여 파일을 삭제하는 명령어.
- 사용 예시:
    - $ rm jscode-file # 현재 디렉터리에 존재하는 jscode-file을 삭제
    - $ rm -r apps # apps 디렉터리 삭제
        (= --recursive)
    - $ rm -rf apps # 파일이든 디렉터리든 파일 종류에 상관없이 삭제할 수 있는 실전용 명령어
        -f : 강제 삭제 (액세스 권한이 없는 파일도 강제로 삭제하는 옵션). 파일을 삭제하려고 하는데 권한 때문에 가로막히는 경우가 종종 있다.
             그래서 편의상 이 옵션을 추가해서 삭제 명령어를 입력하는 경우가 많다. 
```

5) mkdir(make directory) : 디렉터리 생성
```
#### mkdir — 새 디렉터리를 생성하는 명령어(디렉터리명·옵션·계층구조가 구성요소)
- 정의: `mkdir`은 **디렉터리명**, **옵션(-p)**, **계층구조 생성**을 포함하여 디렉터리를 만드는 명령어.
- 사용 예시:
    - $ mkdir apps # apps라는 디렉터리 생성
```

- 정의: `touch`는 **파일명**, **타임스탬프 변경**, **출력(빈 파일 생성)**을 포함한 파일 생성/갱신 명령어.

9) tail
```
#### tail — 파일의 마지막 몇 줄을 출력하는 명령어(파일명·라인 수·옵션이 구성요소)
- 정의: `tail`은 **파일명**, **라인 수**, **옵션(-f, -n 등)**을 사용하여 파일의 마지막 부분을 출력하는 명령어.
    - 기본적으로 마지막 10줄을 출력.
    - 실시간 로그 확인 시 유용.

- 주요 옵션:
    - `-f`: 파일의 끝부분을 지속적으로 출력(로그 파일 모니터링에 사용).
    - `-n [숫자]`: 출력할 줄 수를 지정.
    - `-c [숫자]`: 출력할 바이트 수를 지정.

- 사용 예시:
    - `$ tail file.txt`: `file.txt`의 마지막 10줄 출력.
    - `$ tail -n 20 file.txt`: `file.txt`의 마지막 20줄 출력.
    - `$ tail -f log.txt`: `log.txt`의 실시간 업데이트 내용 출력.
    
- 종료 방법 : ctrl + c
```

10) ls(list) : 현재 디렉터리 내부에 있는 파일 조회
```
#### ls — 디렉터리의 내용(파일 및 하위 디렉터리)을 나열하는 명령어(옵션·경로가 구성요소)
- 정의: `ls`는 **옵션**과 **경로**를 사용하여 디렉터리 내 파일 및 디렉터리 목록을 출력하는 명령어.
    - 기본적으로 현재 디렉터리의 내용을 나열.

- 주요 옵션:
    - `-a`: 숨김 파일(점(.)으로 시작하는 파일 포함)을 표시.
    - `-l`: 파일의 상세 정보(권한, 소유자, 크기, 수정 시간 등)를 표시.
    - `-h`: 파일 크기를 사람이 읽기 쉬운 형식(예: KB, MB)으로 표시(단독 사용 불가, `-l`과 함께 사용).
    - `-R`: 하위 디렉터리의 내용까지 재귀적으로 나열.
    - `-t`: 수정 시간 기준으로 파일을 정렬.

- 사용 예시:
    - `$ ls`: 현재 디렉터리의 파일 및 디렉터리 목록 출력.
    - `$ ls -a`: 숨김 파일 포함 목록 출력.
        리눅스에서는 점(.)으로 시작하는 파일명을 가진 파일은 저절로 숨김 파일로 인식해 처리된다. (ex. .env, .gitignore 등)
    - `$ ls -l`: 파일의 상세 정보 출력.
        맨 앞 한 글자가 파일 종류를 나타낸다.(d:디렉터리, -:일반파일)
        drwx------
        -rw-r--r--
    - `$ ls -lh`: 사람이 읽기 쉬운 형식으로 파일 크기 표시.
    - `$ ls -R`: 하위 디렉터리까지 모든 내용 출력.
    - `$ ls -lt`: 수정 시간 기준으로 정렬된 파일 목록 출력.
    - `$ ls -ltr`: 가장 오래된 파일이 맨 위에 표시.
```


11) less
```
#### less — 파일 내용을 한 화면씩 출력하며 탐색할 수 있는 명령어(파일명·탐색·옵션이 구성요소)
- 정의: `less`는 **파일명**, **탐색(앞/뒤로 이동)**, **옵션**을 사용하여 파일 내용을 한 화면씩 출력하며 탐색할 수 있는 명령어.
    - `cat` 명령어와 달리, 대용량 파일을 효율적으로 탐색 가능.
    - 파일을 읽기 전용으로 열며, 수정은 불가능.

- 주요 탐색 키:
    - `Space`: 다음 화면으로 이동.
    - `b`: 이전 화면으로 이동.
    - `Enter`: 한 줄씩 아래로 이동.
    - `k`: 한 줄 위로 이동.
    - `q`: 종료.

- 주요 옵션:
    - `-N`: 각 줄의 번호를 표시.
    - `-S`: 긴 줄을 잘라내지 않고 가로 스크롤 가능.
    - `+/[검색어]`: 파일 열 때 특정 문자열 검색.
    - `-X`: 종료 시 화면을 지우지 않고 내용 유지.

- 사용 예시:
    - `$ less file.txt`: `file.txt`의 내용을 한 화면씩 출력.
    - `$ less -N file.txt`: 줄 번호를 표시하며 파일 내용 출력.
    - `$ less +/pattern file.txt`: `file.txt`에서 `pattern`을 검색하며 열기.
    - `$ less -S file.txt`: 긴 줄을 잘라내지 않고 가로 스크롤 가능.
```


12) TMOUT
```
#### TMOUT — 셸 세션의 자동 로그아웃 시간을 설정하는 환경 변수
- 정의: `TMOUT`은 **자동 로그아웃 시간(초)**을 설정하는 환경 변수로, 사용자가 지정된 시간 동안 아무 작업도 하지 않을 경우 셸 세션을 자동으로 종료합니다.
    - `TMOUT=0`: 자동 로그아웃을 비활성화.
    - `TMOUT=[숫자]`: 숫자(초)로 설정된 시간 동안 입력이 없으면 자동 로그아웃.

- 사용 방법:
    - `$ export TMOUT=300`: 5분(300초) 동안 입력이 없으면 자동 로그아웃.
    - `$ export TMOUT=0`: 자동 로그아웃 비활성화.

- 주의사항:
    - `TMOUT`은 현재 셸 세션에만 적용되며, 영구적으로 적용하려면 설정 파일(`~/.bashrc` 또는 `~/.bash_profile`)에 추가해야 합니다.
    - 예: `echo "export TMOUT=300" >> ~/.bashrc`

- 사용 예시:
    - `$ export TMOUT=600`: 10분 동안 입력이 없으면 자동 로그아웃.
    - `$ export TMOUT=0`: 자동 로그아웃 기능 비활성화.
```

13) echo
```
#### echo — 문자열을 출력하거나 변수 값을 표시하는 명령어(문자열·변수·옵션이 구성요소)
- 정의: `echo`는 **문자열**, **변수 값**, **옵션**을 사용하여 텍스트를 출력하거나 변수 값을 표시하는 명령어.
    - 쉘 스크립트에서 출력 결과를 확인하거나 변수 값을 표시할 때 주로 사용.

- 주요 옵션:
    - `-n`: 출력 후 줄 바꿈을 하지 않음.
    - `-e`: 백슬래시 이스케이프 문자를 해석.
        - `\n`: 줄 바꿈.
        - `\t`: 탭.
        - `\\`: 백슬래시 출력.
    - `--help`: 명령어 사용법을 표시.

- 사용 예시:
    - `$ echo Hello, World!`: "Hello, World!" 출력.
    - `$ echo -n "No newline"`: "No newline" 출력 후 줄 바꿈 없음.
    - `$ echo -e "Line1\nLine2"`: "Line1"과 "Line2"를 줄 바꿈하여 출력.
    - `$ echo $HOME`: 환경 변수 `HOME`의 값을 출력.
    - `$ echo "Today is $(date)"`: 현재 날짜를 포함한 문자열 출력.
```

## 1. top 명령어 개요
- **정의**: `top`은 CPU·메모리 등 시스템 자원 사용 현황과 프로세스 상태를 실시간으로 보여주는 명령어이다.

## 2. 기본 사용법
- **사용법**: `top` → 현재 실행 중인 프로세스와 시스템 자원 상태를 실시간으로 출력한다.

## 3. 화면 상단(System Summary)

- **uptime**: 시스템 가동 시간과 로그인한 사용자 수를 나타내는 정보이다.
- **load average**: 1·5·15분 평균 CPU 부하로, 실행 대기 중인 프로세스 수를 의미한다.
- **Tasks**: 전체 프로세스 수와 실행·대기·중지·좀비 상태의 구성 현황이다.
- **%Cpu(s)**: user·system·idle 등 CPU 사용 비율을 구성요소별로 나타낸다.
- **MiB Mem**: 전체·사용·여유·버퍼/캐시 메모리로 구성된 물리 메모리 상태이다.
- **MiB Swap**: 스왑 메모리의 전체 용량과 사용량을 나타내는 가상 메모리 정보이다.

## 4. 프로세스 목록(Process List)

- **PID**: 프로세스를 식별하는 고유한 프로세스 ID이다.
- **USER**: 해당 프로세스를 실행한 사용자 계정이다.
- **PR**: 커널이 관리하는 프로세스 우선순위 값이다.
- **NI**: nice 값으로, 우선순위 조정을 위한 사용자 지정 값이다.
- **VIRT**: 프로세스가 사용하는 전체 가상 메모리 크기이다.
- **RES**: 실제 RAM에서 사용 중인 물리 메모리 크기이다.
- **SHR**: 다른 프로세스와 공유 중인 메모리 크기이다.
- **S**: 프로세스 상태(R 실행, S 대기 등)를 나타낸다.
- **%CPU**: 해당 프로세스의 CPU 사용 비율이다.
- **%MEM**: 전체 메모리 대비 해당 프로세스의 사용 비율이다.
- **TIME+**: 프로세스가 CPU를 사용한 누적 시간이다.
- **COMMAND**: 실행 중인 명령어나 프로그램 이름이다.

## 5. 실행 중 키 명령어

- **q**: top 명령어를 종료한다.
- **P**: CPU 사용률 기준으로 프로세스를 정렬한다.
- **M**: 메모리 사용량 기준으로 프로세스를 정렬한다.
- **T**: 실행 시간 기준으로 프로세스를 정렬한다.
- **k**: 특정 PID를 입력해 프로세스를 종료한다.
- **1**: CPU 코어별 사용률을 개별로 표시한다.
- **h**: 도움말 화면을 출력한다.

## 6. 초보자 핵심 체크 포인트

- **CPU 병목 확인**: load average와 idle CPU 비율을 함께 확인한다.
- **메모리 부족 확인**: free·available 메모리 수치를 확인한다.
- **문제 프로세스 탐지**: %CPU 또는 %MEM이 과도한 프로세스를 찾는다.

## 7. 연관 명령어

- **htop**: top을 시각적으로 개선한 대화형 프로세스 모니터이다.
- **ps**: 특정 시점의 프로세스 상태를 조회하는 명령어이다.
- **vmstat**: CPU·메모리·IO 상태를 요약해서 보여주는 명령어이다.

kill 명령어는 이름 그대로 프로세스를 '죽이는(종료시키는)' 명령어입니다. 좀 더 정확하게는 실행 중인 프로세스에게 특정 '신호(Signal)'를 보내는 역할을 합니다.
기본적으로 아무런 옵션 없이 kill을 사용하면 프로세스에게 종료 신호를 보내고, 이 신호를 받은 프로세스는 정상적으로 종료 절차를 수행합니다.
1. kill 명령어 기본 사용법
kill 명령어는 종료하려는 프로세스의 PID (프로세스 ID)를 알아야 사용할 수 있습니다.
bash
kill [시그널 옵션] [PID]
PID 확인하기
프로세스 ID(PID)는 ps나 pgrep 같은 명령어로 확인할 수 있습니다.
bash
# 실행 중인 모든 프로세스 목록 보기 (많은 정보가 출력됩니다)
ps -ef 

# 특정 이름의 프로세스 찾기 (예: 'nginx' 프로세스)
ps -ef | grep nginx

# 'nginx' 프로세스의 PID만 깔끔하게 확인하기
pgrep nginx
2. 주요 시그널 (Signal) 알아보기
kill 명령어 사용 시 가장 중요한 두 가지 시그널이 있습니다.
시그널 번호	시그널 이름	설명
15	SIGTERM	정상 종료를 요청합니다. 프로세스가 스스로 종료를 준비할 시간을 줍니다 (기본값).
9	SIGKILL	강제 종료를 명령합니다. 프로세스가 무시할 수 없는 강력한 종료 명령입니다.
