리눅스 명령어 공부 note
======================

1\. rm(remove) : 파일/디렉터리 삭제
-----------------------
```
#### rm — 파일이나 디렉터리를 삭제하는 명령어(대상·옵션·영구삭제가 구성요소)
- 정의: `rm`은 대상 파일, 옵션(-r, -f), 영구삭제 동작을 포함하여 파일을 삭제하는 명령어.
- 사용 예시:
    - $ rm jscode-file # 현재 디렉터리에 존재하는 jscode-file을 삭제
    - $ rm -r apps # apps 디렉터리 삭제
        (= --recursive)
    - $ rm -rf apps # 파일이든 디렉터리든 파일 종류에 상관없이 삭제할 수 있는 실전용 명령어
        -f : 강제 삭제 (액세스 권한이 없는 파일도 강제로 삭제하는 옵션). 파일을 삭제하려고 하는데 권한 때문에 가로막히는 경우가 종종 있다.
             그래서 편의상 이 옵션을 추가해서 삭제 명령어를 입력하는 경우가 많다. 
    - 삭제에 대한 응답 필요
     - y(Yes) : 파일을 삭제합니다.
     - n(No) : 삭제하지 않고 취소합니다.
```

2\. rmdir   : 비어 있는 폴더만 삭제할 때 사용합니다. 폴더 안에 파일이 하나라도 있으면 에러가 납니다.
-----------------------
```
- 사용 예시:
    - $ rmdir 폴더명
```
