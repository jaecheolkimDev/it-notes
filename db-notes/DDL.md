DDL 공부 노트
=============

1\. DDL (Data Definition Language, 데이터 정의어)
--------
데이터베이스의 구조(껍데기)를 만들거나 수정하고 삭제할 때 사용합니다. 실행 즉시 DB에 반영(Auto-Commit)되는 특징이 있습니다.
```
명령어       의미      설명
CREATE      생성      테이블, 인덱스, 뷰 등 객체를 처음 만들 때
ALTER       수정      기존 테이블의 컬럼을 추가/수정하거나 이름을 바꿀 때
DROP        삭제      테이블이나 객체 자체를 통째로 지울 때
TRUNCATE    초기화     테이블의 구조는 남기고 데이터만 순식간에 싹 비울 때
```
