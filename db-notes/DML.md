DML (Data Manipulation Language, 데이터 조작어)
=============

1\. 개념
--------
DML은 생성된 테이블 내부의 실제 데이터(레코드)를 조회, 삽입, 수정, 삭제할 때 사용합니다. 실무에서 가장 많이 쓰는 명령어들입니다.
```
특징: DDL과 달리 명령을 내려도 바로 반영되지 않고, 내가 확정(COMMIT)하거나 취소(ROLLBACK)할 수 있는 트랜잭션의 대상이 됩니다.
```

2\. 주요 명령어
--------
```
SELECT: 데이터를 조회합니다. (가장 많이 사용됨)
INSERT: 새로운 데이터를 삽입합니다.
UPDATE: 기존 데이터를 수정합니다.
DELETE: 데이터를 삭제합니다. (구조는 남고 알맹이만 삭제)
```
