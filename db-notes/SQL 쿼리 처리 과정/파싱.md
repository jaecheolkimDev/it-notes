파싱
=============

1\. 정의
--------
```
- 파싱 : SQL을 실행하기 전에 SQL문을 구문 분석하고 실행계획을 수립하는 과정
  - 하드 파싱 : SQL이 처음 실행됬거나 Shared Pool에 동일한 SQL이 존재하지 않아 새로 실행 계획 수립해야하는 경우
  - 소프트 파싱 : Shared Pool에 동일한 SQL 존재해서 재사용
- 하드 파싱 개선 방안
  - 1) 바인드 변수 사용으로 동일 SQL로 인식
  - 2) SQL 텍스트 통일(*불필요한 공백, 대소문자 차이, 주석제거 등으로 동일 SQL 인식률 향상*)
    - 위와 같은 방법들을 통해 소프트 파싱으로 유도해서 성능 개선
```
