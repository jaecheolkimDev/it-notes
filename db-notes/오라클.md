오라클
=============

1\. 오류
--------
```
ORA-00907 : 누락된 우괄호
    - SUBQUERY 안에서 ORDER BY 사용하면 발생한다.(스칼라 서브쿼리에서는 단건만 나와야해서 ORDER BY가 의미없음.)
ORA-00911 : 
    - SQL 구문이 문법적으로 잘못되었을 때 발생하는 오류입니다. 특히 쿼리문에 부적절한 문자(주로 세미콜론;)나 홑따옴표(‘) 등의 
      특수문자가 포함되어 있을 때 발생하며, 쿼리문에서 해당 문자를 제거하거나, XML 등에서 홑따옴표를 이스케이프(escape) 처리하여 
      해결할 수 있습니다.
    - JAVA 데이터 DB 입력 시 '(홑따옴표)로 인한 오류 해결 방법
      Java 파일로 request한 데이터를 받아서 DB에 입력하는 과정에서 '(홑따옴표)로 인해서 DB에 입력 시 Syntax error가 발생하는 경우가 
      있다. 이러한 문제는 replaceAll로 '(홑따옴표)를 &#39로 치환해서 DB로 입력하도록 하면 해결 할 수 있다.
          String Data = request.getParameter(data);
          Data = Data.replaceAll("'","&#39;");
          '를 &#39로 치환해서 DB에 입력!
ORA-00918 : 열의 정의가 애매합니다
    - 똑같은 이름의 컬럼(예: ID, CREATE_DATE 등)이 존재하는데, SELECT절이나 WHERE절에서 어떤 테이블의 컬럼인지 명시하지 않았을 때 발생합니다.
ORA-01653 : 테이블스페이스에서 확장할 수 없습니다.
    - 테이블스페이스가 가득 찼을때 발생하는 오류.
ORA-01722 : 수치가 부적합합니다.
    - TO_NUMBER(1,200) : VARCHAR2로 저장된값을 변환하려고할때 콤마를 변환못할때 발생하는 오류.
ORA-01790: expression must have same datatype as corresponding expression
    - UNION연산을 수행할 때, 결과 테이블의 컬럼의 타입이 일치하지 않을때 발생하는 오류.
```
