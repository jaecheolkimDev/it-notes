SDM(Software Development Methodology) 공부 노트
================

1\. 애자일
-----------------------------
```
JIRA : 버그 추적, 이슈 추적, 프로젝트 관리 기능을 제공하는 소프트웨어이다.
지라는 애자일 개발방식에 가장 적당한 소프트웨어라는 말이 많았다.
```

2\. 데브옵스 (Development + Operation)
-----------------------------
```
목표 : 소프트웨어개발/품질보증/IT운영 과 같은 다양한 프로세스 모두를 하나로 통합해서 전반적인 효율성을 향상시키는 것.
즉, IT분야의 복잡한 사안들을 효율적으로 관리하는 동시에, 애자일기법에서 필요한 속도까지 유지시켜주는 역할을 함.

 - 개발담당자와 운영담당자가 연계하여 협력하는 개발 방법론
 - 신속한 고품질 서비스 제공을 통해 비즈니스 가치를 높이고 대응 능력을 개선할 목적으로 기업문화, 자동화, 플랫폼 설계에 접근하는 방식
 - 개발팀과 운영팀 차이를 이해하고 간극을 줄여보자

기존의 소프트웨어를 유지하면서 동시에 새로운 버전에 대한 수정 작업을 진행하기 위해서는, 다음과 같은 종합적인 도구들이 필요하다.
    깃허브, 젠킨스
```
