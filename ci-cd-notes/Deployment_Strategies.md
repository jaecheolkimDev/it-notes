배포 전략 공부 노트
=================

1\. 종류
--------
```
블루-그린(Blue-Green) 배포     : 똑같은 사양의 서버 그룹을 하나 더(Green) 통째로 만들어서, 한 번에 트래픽을 확 옮겨버리는 방식입니다. 
                              (가장 확실하지만 자원이 2배로 듭니다.)
카나리(Canary) 배포           : 아주 적은 인원(예: 5%)에게만 새 버전을 먼저 노출해보고, 문제가 없으면 전체로 확대하는 방식입니다. 
                              (탄광 속의 카나리아에서 유래했습니다.)
롤백(Rollback)               : 롤링아웃 도중에 문제가 생겼을 때, 즉시 이전 상태로 되돌리는 작업을 말합니다.
```
