미들웨어(Middleware)
======================

1\. 정의
--------------
```
서로 다른 소프트웨어 애플리케이션이나 시스템 사이에서 '중다리(중개자)' 역할을 하는 소프트웨어입니다.
```

1\. 식당에 비유한 미들웨어
--------------
```
1) 손님 (클라이언트/프론트엔드): 메뉴를 주문하는 주체
2) 점원 (미들웨어): 손님의 주문을 받아 주방에 전달하고, 음식이 나오면 손님에게 가져다주는 역할
3) 주방장 (서버/DB/백엔드): 주문을 받아 요리를 만들고 데이터를 처리하는 주체
```

1\. 주요 역할 및 기능
--------------
```
1) 통신 및 중계: 서로 다른 언어나 프로토콜로 만들어진 시스템끼리 메시지를 주고받을 수 있게 변환 및 전달
2) 트랜잭션 관리: 데이터 처리가 중간에 실패했을 때 안전하게 원상복구(Rollback)하거나 성공적으로 완료(Commit)되도록 관리
3) 부하 분산 (Load Balancing): 요청이 몰릴 때 여러 서버로 균등하게 나누어 안정성 유지
4) 보안 및 인증: 데이터 접근 권한을 확인하고 암호화 처리
```
