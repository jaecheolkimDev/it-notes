ESB (Enterprise Service Bus, 기업 서비스 버스)
======================

1\. 정의
--------------
```
기업 내 서로 다른 다양한 애플리케이션과 시스템을 하나의 중앙 통로(버스)로 연결하여 상호 연동 및 통합할 수 있도록 지원하는 미들웨어 
아키텍처 소프트웨어입니다.
```

1\. 핵심 특징 및 기능
--------------
```
1) 중앙 집중식 통합 통로: 각 시스템이 1:1로 직접 연결(Point-to-Point)되는 복잡한 구조를 해결하고, 버스(Bus) 형태의 중앙 통로를 
                      통해 메시지를 주고받습니다.
2) 프로토콜 및 데이터 변환: 서로 다른 프로토콜(HTTP, JMS, FTP 등)이나 데이터 형식(JSON, XML 등)을 사용하는 시스템 간에 중계 및 
                        변환 역할을 수행합니다.
3) 메시지 라우팅: 요청된 메시지를 목적에 맞는 올바른 서비스/시스템으로 안전하게 전달합니다.
4) 결합도(Coupling) 감소: 시스템 간 직접적인 의존성을 줄여, 특정 시스템을 수정하거나 교체해도 다른 시스템에 미치는 영향이 최소화됩니다.
```

1\. 장단점
--------------
```
장점  : 시스템 간 복잡성 감소, 유지보수 및 확장성 향상, 표준화된 데이터 연동 가능
단점  : 중앙 ESB 서버가 병목 현상이나 단일 장애점(SPOF)이 될 위험, 구축 및 관리 비용 증가
```
