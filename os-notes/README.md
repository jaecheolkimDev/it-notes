운영체제(OS, Operating System)
======================

999\. 코어
--------------
```
하이퍼스레딩(Hyper-Threading)은 Intel이 개발한 기술로, 1개의 물리적 CPU 코어를 2개의 논리적 코어(스레드)처럼 작동하게 하여 
        동시 작업 처리량을 높이는 기술입니다.
        코어의 유휴 시간을 활용해 멀티태스킹 성능을 약 15~30% 향상시키지만, 
        모든 작업에서 성능이 비례하여 증가하진 않으며 보안상 취약점이 보고되기도 했습니다.
```
