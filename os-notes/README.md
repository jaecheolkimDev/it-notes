운영체제(OS, Operating System) 공부 노트
======================


1\. 프로그램과 프로세스
--------------
```
1) 프로그램 : HDD 등과 같이 저장장치에 저장된 명령문의 집합체 (애플리케이션, 앱, .exe)
2) 프로세스 : 메모리에 올라가서 실행중인 프로그램
 2-1) 구조 : 코드 영역, 데이터 영역, 힙 영역, 스택 영역
  2-1-1) 코드 영역 : 실행 코드 저장
  2-1-2) 데이터 영역 : 전역 변수, static 변수
  2-1-3) 힙 영역 : 동적 메모리 할당
  2-1-4) 스택 영역 : 지역 변수, 함수 호출 정보
3) 유니 프로그래밍     : 오직 하나의 프로세스가 메모리에 올라와 단독 처리
4) 멀티 프로그래밍     : 여러 프로세스가 메모리에 올라와 각각 처리
5) 멀티 태스킹       : 각 프로그램을 짧게씩 실행하면서 모든 프로세스를 동시에 실행하는 것처럼 느끼게 하는 기술
7) 멀티 프로세서      : 작업을 처리할 CPU가 여러개 있는 것
6) 멀티 프로세싱      : 멀티 프로세서로 작업을 처리하는 것
7) 시분할 시스템      : 여러개의 프로세스를 돌아가면서 실행합니다.
8) 좀비 프로세스  : 자식 프로세스가 exit 신호를 보내지 못한 채 비정상으로 종료되거나 부모 프로세스가 자식 프로세스보다 먼저 종료되어
                  exit status를 읽지 못하면 해당 프로세스는 메모리에 계속 남아있게 됨
```

2\. PCB(Process Control Block)
--------------
프로세스의 정보 (프로세스와 생명주기를 같이함)
```
1) 포인터          : 효율적인 접근을 위해 포인터 사용
 - 부모와 자식 프로세스에 대한 포인터와 할당된 자원에 대한 포인터 등이 있음
 - 프로세스의 한 상태에서 다른 상태로 전환될 때 저장하는 포인터를 가지고 있음
2) 프로세스 상태      : 현재 프로세스의 5가지 상태(생성, 준비, 실행, 대기, 완료)
 - 생성(New)      : PCB를 생성하고 메모리에 프로그램 적재를 요청한 상태 (메모리에 적재를 승인 받으면 준비 상태로 넘어감)
 - 준비(Ready)    : CPU를 사용하기 위해 기다리고 있는 상태
 - 대기(Waiting)  : 프로세스가 입출력 요청을 하면 입출력 완료될 때까지 기다리는 상태 (인터럽트)
 - 실행(Running)  : 준비 상태에 있는 프로세스가 CPU 스케줄러에 의해 CPU를 할당받아 실행되는 상태 (부여된 시간만큼 사용 후 다시 준비 상태로 돌아감)
 - 완료(Terminated)   : 프로세스 종료 (사용했던 데이터를 메모리에서 제거하고 생성된 PCB도 제거)
3) 프로세스 ID      : 프로세스를 식별하기 위한 숫자
4) 프로그램 카운터     : 다시 실행상태가 됬을때 시작할 명령어의 주소를 저장
5) 레지스터 정보      : 프로그램 카운터와 마찬가지로 CPU를 뺏기고 다시 시작할 때 이전에 사용하던 값을 복구하기 위한 용도
 - 프로세스가 실행될 때 사용했던 레지스터 값들이 저장
6) 메모리 관련 정보    : 프로세스가 메모리에 있는 위치정보, 메모리 침범을 막기 위한 경계 레지스터 값 등이 저장
7) CPU 스케줄링 정보  : CPU 스케줄링에 필요한 우선순위, 최종 실행시간, CPU 점유시간 등이 저장됩니다.
```

3\. 컨텍스트 스위칭
--------------
```
1) 개념   : 다른 프로세스를 실행하기 위해 실행중인 프로세스의 상태를 저장하고 다른 프로세스의 상태 값으로 교체하는 작업입니다.
2) 발생 사유    :
 - CPU 점유시간이 다 되거나
 - I/0 요청이 있거나
 - 다른 종류의 인터럽트가 있을 때
```

999\. 코어
--------------
```
하이퍼스레딩(Hyper-Threading)은 Intel이 개발한 기술로, 1개의 물리적 CPU 코어를 2개의 논리적 코어(스레드)처럼 작동하게 하여 
        동시 작업 처리량을 높이는 기술입니다.
        코어의 유휴 시간을 활용해 멀티태스킹 성능을 약 15~30% 향상시키지만, 
        모든 작업에서 성능이 비례하여 증가하진 않으며 보안상 취약점이 보고되기도 했습니다.
```
