HBM (High Bandwidth Memory, 고대역폭 메모리)
=====================

1\. 개념
-------------------
```
데이터를 엄청나게 빠르고 많이 주고받을 수 있도록 만든 초고속 메모리
```

2\. 왜 AI 시대에 필수적일까?
-------------------
```
최근 AI(인공지능) 열풍과 함께 챗GPT 같은 서비스를 원활하게 구동하기 위해 필수적인 핵심 반도체로 주목받고 있습니다.
AI를 학습시키고 구동하려면 GPU(그래픽 처리 장치)가 핵심적인 역할을 합니다. 그런데 GPU의 연산 속도가 아무리 빨라도, 메모리에서 데이터를 제때 보내주지 
못하면 GPU가 놀게 됩니다.
HBM은 GPU 바로 옆에 바짝 붙어서 초고속으로 데이터를 공급해주기 때문에, 엔비디아(NVIDIA) 같은 회사의 최고급 AI 가속기(H100, B200 등)에는 반드시 
HBM이 세트로 탑재됩니다.
```

3\. 기존의 메모리(DDR, GDDR 등)의 문제점
-------------------
```
평면에 칩을 배치하고 선으로 연결하는 방식이었습니다. 하지만 AI 연산처럼 엄청난 양의 데이터를 한 번에 처리해야 할 때는, 데이터가 드나드는 길(대역폭)이 좁아 
성능이 떨어지는 '병목 현상'이 발생했습니다.
```

4\. HBM의 해결방식
-------------------
HBM은 이 문제를 "아파트를 높이 쌓는 방식"으로 해결했습니다.
```
D램을 아파트처럼 수직으로 쌓고 수천 개의 구멍을 뚫어, 데이터 전송 속도와 용량을 획기적으로 늘린 AI 시대의 필수 고성능 메모리입니다.
```

5\. 핵심 특징
-------------------
```
수직 적층 (3D Stacking) : D램(DRAM) 칩을 여러 층으로 높게 쌓아 올렸습니다. 공간을 적게 차지하면서도 용량을 극대화할 수 있습니다.
TSV (실리콘 관통 비아)   : 칩에 미세한 구멍을 수천 개 뚫어 상하층을 수직으로 연결하는 기술입니다. 기존 방식보다 데이터가 이동하는 통로(선)가 비교할 수 없을 
                        정도로 많아집니다.
압도적인 대역폭(속도)    : 도로로 비유하자면, 기존 메모리가 '4차선 도로'라면 HBM은 '1024차선 초고속 고속도로'인 셈입니다. 한번에 엄청난 양의 데이터를 
                        전송할 수 있습니다.
```

6\. 아이디어의 시발점
-------------------
```
1) AMD의 브라이언 블랙 (Bryan Black)
2) 그래픽 카드의 한계를 느끼던 설계 회사(AMD)와 이를 실제로 구현할 기술력이 있던 메모리 제조사(SK하이닉스)가 손을 잡고 만들어낸 합작품
3) 2013년 (공동 개발 및 표준화): AMD와 SK하이닉스가 공동으로 HBM 규격을 개발했고, 반도체 표준화 기구인 JEDEC에서 이를 공식 국제 표준으로 채택했습니다.
4) 2015년 (세계 최초 상용화): SK하이닉스가 세계 최초로 1세대 HBM을 양산하는 데 성공했습니다. AMD는 이 HBM을 최초로 탑재한 그래픽 카드인 
    '라데온 R9 퓨리(Fury)' 시리즈를 시장에 출시하며 세상에 HBM의 존재를 알렸습니다.
```
